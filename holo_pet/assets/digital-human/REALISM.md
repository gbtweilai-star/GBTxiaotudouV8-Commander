## §0 为什么先学再动手（本次的教训）

前面几轮把力气花在"网格能不能用"上（清洗、定向、减面、绑骨），每一步都过了读数，
但**绑完骨渲染出来仍是"CG 娃娃"**。原因不是哪一步写错了，而是**流程里缺了整段**：
逼真度不在"网格对不对"，而在**光照模型、皮肤着色、贴图分辨率、面部专件**这四件事上。
所以顺序必须是：**先按专业流程定验收标尺 → 再逐项补齐 → 每项都要有读数**。

## §1 第一性原理：真人皮肤为什么不能当"普通 PBR 材质"渲

皮肤是**多层半透明介质**（表皮 / 真皮 / 皮下脂肪），光会**渗进表面再散射出来**：

| 现象 | 不建模的后果 | three.js 里的对应做法 |
|---|---|---|
| 次表面散射（SSS） | 明暗交界线又硬又脏、像塑料 | `diffuseRoughness`（EON 保能量粗糙漫反射）；NodeMaterial 有 `sss` / `MeshSSSNodeMaterial`（本机 examples 里**没有**该文件，未验） |
| 绒毛/汗毛的边缘散射 | 逆光轮廓是"硬边剪纸" | `sheen` + `sheenColor`（本流程用它模拟 vellus hair） |
| 薄油膜（T 区/唇） | 要么全脸油光、要么全脸哑光 | `clearcoat` 少量（全脸加 = 塑料） |
| 折射率 | 默认 1.5 是"通用非金属"，不是皮肤 | `ior ≈ 1.4`（皮肤文献常见 1.33–1.44） |
| 镜面强度 | 默认 1.0 会给出"油光塑料壳" | `specularIntensity ≈ 0.4–0.5` |

**并且**：three.js 官方对 `MeshPhysicalMaterial` 明写
> "For best results, always specify an environment map when using this material."

没有环境贴图 ⇒ 皮肤只有方向光的镜面高光、**没有环境的漫反射包裹** ——
这是"看着像 CG"的头号原因，且**调任何材质参数都补不回来**。

## §2 可执行流程（八步，每步带读数）

| # | 步骤 | 工具 / 代码 | 判据（不达标就卡住） |
|---|---|---|---|
| 1 | **IBL 环境** | `RoomEnvironment` + `PMREMGenerator` → `scene.environment` | 无外部 HDRI 依赖；`scene.environment` 非空 |
| 2 | **光照配比** | 主光 1.1 / 辅光 0.30 / 勾边 0.65 / 半球 0.30 | 加 IBL 后方向光**必须压低**；否则过曝（实测：黑衣冲成灰褐、皮肤惨白） |
| 3 | **金属度归零** | 皮肤区 `metalness = 0` | 源模型实测金属度均值 **0.127** —— 真人必须 0；>0.05 即发灰发假 |
| 4 | **皮肤参数** | `ior 1.4` · `specularIntensity 0.42` · `diffuseRoughness 0.65` · `sheen 0.12` · `clearcoat 0.05` | 见 §1 逐条依据 |
| 5 | **色彩管线** | `outputColorSpace = SRGBColorSpace` · `ACESFilmicToneMapping` · `toneMappingExposure ≤ 1.0` | 高光不削顶；肤色不溢出 |
| 6 | **贴图分辨率** | 脸要单独 4K；全身 2K 只够"能看" | ⚠️ 现状 2048² 全身 ⇒ **脸只分到约 300²**，毛孔/唇纹/睫毛全部丢失 |
| 7 | **面部专件** | 眼球 / 睫毛 / 眉毛 / 牙齿 / 口腔 必须是**独立几何** | ⚠️ 现状：**一件都没有**，眼是贴图画的 |
| 8 | **微细节法线** | 皮肤毛孔 / 细纹独立的 normal（或 detail normal） | ⚠️ 现状：只有一张 1024² 全身 normal |

## §3 AI 味禁令（本项目的"像不像真人"负向清单）

- ❌ **全脸均匀油光** —— 真人只有 T 区/唇部反光
- ❌ **金属度非零的皮肤** —— 会发灰、失血色
- ❌ **无环境光的纯方向光打光** —— 阴影死黑、没有环境包裹
- ❌ **只有一张全身贴图** —— 脸必然糊
- ❌ **眼睛是贴图画的** —— 真人眼睛必须有角膜高光与折射
- ❌ **明暗交界线生硬** —— 缺 SSS 的直接表现
- ❌ **皮肤无毛孔纹理** —— 放大即"塑料感"

## §4 机检项（可复现的命令）

```powershell
# ① 材质读数：金属度/粗糙度/贴图尺寸
py -3.14 <读 GLB 材质与图片像素尺寸的脚本>
#   判据：金属度均值 < 0.05 · 贴图 ≥ 2048 · 脸区有效分辨率 ≥ 1024

# ② 渲染对照（真人化前/后）
py -3.14 plugins/gbt-master/tools/shot-turnaround.py <模型> --out 真人化-后 --views front,three-quarter
py -3.14 plugins/gbt-master/tools/shot-turnaround.py <模型> --out 真人化-前 --views front,three-quarter --extra "&real=0"

# ③ 覆盖度闸（防"全黑帧"冒充存证）：工具内置，覆盖 >95% 或 <1% 一律判坏读数退出 1
```

## §5 现状与差距（**诚实账**，2026-09-25）

**已做**：
- ✅ IBL 环境（`RoomEnvironment` + PMREM）· 光照配比 · ACES 色调映射
- ✅ 皮肤材质改为真人参数（金属度 0 · ior 1.4 · spec 0.42 · diffuseRoughness 0.65 · sheen 0.12 · clearcoat 0.05）
- ✅ 自研免费绑骨 22 关节 + 4 根头发弹簧链（共 26 关节），**0 积分**
- ✅ 渲染器带冷启动预热 + 覆盖度闸（不再"工具撒谎"）

**没做 / 到不了"真人逼真"的硬缺口**：

| 缺口 | 现状读数 | 到真人需要 |
|---|---|---|
| 面部几何 | 全身 28382 顶点，脸约 2–3k | 脸部单独 10k+ 顶点（眼睑/唇/鼻翼塑形） |
| 面部贴图 | 全身 2048²，脸约 300² | 脸单独 4096² |
| 眼球/睫毛/眉/牙 | **0 件** | 各为独立几何 + 独立材质 |
| 皮肤微细节 | 1024² 全身 normal 一张 | 毛孔/细纹 detail normal |
| 次表面散射 | 只有 `diffuseRoughness` 近似 | 真 SSS（`MeshSSSNodeMaterial` 本机 examples **无此文件**，未验） |
| 源图本身 | 是**光泽人偶**质感 | 需要按"真人皮肤"重新诠释材质，不能照抄源图高光 |

**结论（不许粉饰）**：靠当前这一件 Tripo 多视图产物 + 参数调优，
**只能做到"干净的 CG 角色"，做不到"真人逼真"**。
要过你定的线（真人且逼真），必须补 §2 的第 6/7/8 步 ——
即**面部专件 + 4K 面部贴图 + 皮肤微细节**这三件，且需要 DCC（Blender）或等价工具才能做。

### 没做到 —— 以及为什么（一句话）

**独立眼球**：5 次尝试全败（比例法 / 几何反查 / 连通域 / 人工给定 ×3）。
**根因不是位置，是没有眼睑几何**：球体直接凸在脸上，比贴图上画的眼睛更难看。
⇒ 已判定「**当前输入下不该做**」，全部标记 REJECTED。

**"真人逼真"这条线**：**天花板在输入**。
皮肤蜡感、额头高光冒充眼白、浓眼妆吃掉眼睑信号、理想化比例、无干净解剖信号 ——
这一路每一个卡点，追到底都是同一句话：**源图是「重妆光泽人偶」，不是真人照片**。
