# 数字人专业化流程（蒸馏 · 我们的执行口径）

> 来源：**How to Build Digital Humans? From Priors to Photorealistic Avatars**
> Zielonka, Kirschstein, Bolkart, Giebenhain, Sklyarova, Deng, Xiang, Saito, Liu, Nießner, Thies
> *Computer Graphics Forum, Vol. 45, No. 2, 2026（Eurographics State-of-the-Art Report）*
> <https://github.com/Zielon/how-to-build-digital-humans>
>
> 该文把可控数字人拆成三个阶段：**(i) 学习人体外观与动作先验 → (ii) 创建个性化 avatar → (iii) 驱动动画**，
> 并按**身体部位分层**（头 / 发 / 手 / 衣物 / 全身）给出分类学与代表方法。
> 本文只保留**能落成我们工程动作**的部分，并标注我们的现状与缺口。

---

## 一、专业流程的 8 个环节（标准口径）

| # | 环节 | 专业做法 | 关键量规 |
|---|---|---|---|
| 1 | **先验基底** | 用参数化人体（SMPL-X / FLAME / 头部先验）作形状与骨架底座，而不是从零生成网格 | 头身比 · 关节层级完整度 |
| 2 | **分部位分层建模** | 头-脸-眼-牙 / 发 / 手 / 衣物 / 全身**分层**，各自独立拓扑与材质 | 每层独立 UV、独立材质槽 |
| 3 | **面部表示** | FLAME 类头部 + **表情基（blendshapes，ARKit 52 或 FLAME 表达）** | 表情通道数 · 可动幅度 |
| 4 | **材质（皮肤/眼/发/布）** | PBR：albedo + **micro-normal（毛孔/细纹）** + **SSS 次表面散射**；眼=角膜高光+虹膜视差；发=各向异性；布=布 BRDF | 粗糙度分布 · specular 响应 · SSS 半径 |
| 5 | **绑定与驱动** | 身体骨架 + 面部表情基 + 手部关节 + **次级动力学**（发/布弹簧骨） | 关节数 · 权重归一 · 弹簧骨数 |
| 6 | **动画/重定向** | 动捕或视频驱动 → 重定向到标准人形 | 步幅/身高 · 循环闭合 · 脚不滑步 |
| 7 | **渲染** | HDRI 环境光 + SSS + 眼高光 + 胶片级色调映射 + AO/抗锯齿 | 边缘锐度 · 高光形态 · 无过曝 |
| 8 | **交付与 LOD** | 高模出图 / 低模实时，多档 LOD | 各档三角形数 · 实时帧率 |

## 二、我们的现状对照（诚实口径）

| 环节 | 我们已做到 | 缺口 |
|---|---|---|
| 1 先验基底 | ❌ 没用参数化先验（走的是 Tripo 图生 3D + 自建骨架） | 无 SMPL-X/FLAME 底座 |
| 2 分层 | ⚠️ 单网格（衣物/发/鞋都长在身上） | 无分层、无独立材质槽（仅 3 贴图：baseColor/normal/metalRough） |
| 3 面部 | ❌ 无表情基；头骨链只有 Head/Neck | 无 blendshape、无颚/眼/眉骨 |
| 4 材质 | ⚠️ 有 2048² baseColor+normal+metalRough；**无 SSS、无 micro-normal** | 皮肤像塑料、眼无高光 |
| 5 绑定 | ✅ **22 骨标准人形**（自建，四门全过）+ 权重归一 + 布料归髋 | 无次级动力学（发/裙弹簧骨） |
| 6 动画 | ✅ idle（8s）+ walk（1.10s，循环闭合 0.00000，根位移/步幅 0.550） | 无状态机交叉淡入、无脚部锁定 |
| 7 渲染 | ✅ IBL（RoomEnvironment）+ **PBR Neutral** + PCFSoft 接触阴影 | 清晰度不足（无超采样）、无 SSS/眼高光、无微法线 |
| 8 交付 | ✅ 高模 762k（出图）+ 低模 16k（实时）双档 | 无中间 LOD 档 |

## 三、我们的执行顺序（按"清晰逼真"收益排序）

1. **渲染端清晰度**（零依赖、立刻见效）：超采样 SSAA + 脸部/眼部专用补光 + 高分辨率出图 ⇒ 量规：**脸部梯度方差 ↑**、边缘宽度 ↓
2. **材质专业化**：皮肤 **SSS 近似** + **micro-normal**（从 albedo 高频提取毛孔级细节）+ 眼睛角膜高光 + 头发各向异性光泽 ⇒ 量规：specular 形态、粗糙度分区
3. **次级动力学**：给头发/裙摆加 2–4 根弹簧骨（复用我们的权重工具做区域重权）⇒ 量规：跟随延迟与回弹
4. **面部可动**：加颚/眼/眉 4–6 根骨 + 简单权重组 ⇒ 量规：眨眼/点头/张嘴幅度
5. **脸部保真（受源限制）**：源素材脸仅 ~200px ⇒ 需要①更高清脸照，或②本地人脸修复模型（onnxruntime + GFPGAN，约 365MB，需批准下载）
6. **状态机**：idle ↔ walk ↔ 说话 的交叉淡入（禁硬切）+ 脚部锁定（防滑步）

## 四、量规定义（我们会用到的读数）

- **清晰度**：脸部 ROI 的**梯度方差**（越大越锐）+ Laplacian 方差
- **循环连续性**：首末关键帧四元数最大差（须 ≈ 0）
- **步幅比**：根位移 / 模型身高（自然走路 ≈ 0.5–0.8）
- **权重**：和恒 1.0000；活跃骨数 2–4
- **门限四条**：关节 ≥20 / 骨名可映射 / 绑定姿势可判 / 权重归一
