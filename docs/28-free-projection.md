# 零成本投墙（不花钱的三条路）

> 2026-10-27 ｜ 主人令：不买设备。那就不买 —— 用手上已有的东西。
> 三条路，代价从"找一片放大镜"到"拆一台旧手机"，**都不花钱**。

## 为什么免费路能成：缺的从来不是"投影仪"，是"亮度 + 镜头"

手机上那块屏，本身就是**空间光调制器**（能决定每个像素透不透光）。
它唯一的毛病是**背光太弱**——屏幕亮度约 500 尼特，折算成光通量只有十几流明。

```
屏幕自身发光（十几流明） → 透镜 → 墙上：全黑房能看见，白天全白
换高功率 LED 背光（1000 流明） → 透镜 → 墙上：亮 50–70 倍
```

**两块钱的差距不是技术，是那颗 LED。** 所以：

| 路 | 光从哪来 | 亮度 | 代价 |
|---|---|---|---|
| A 屏幕 + 凸透镜 | 屏幕自己 | 低（25%） | ¥0（找片放大镜） |
| B 拆旧 LCD 手机 + LED | 外接大功率 LED | **高** | ¥0（用旧手机） |
| C 已有大屏 + 投屏 | 电视/显示器自己 | 最高 | ¥0（设备已有） |

## 路 A：屏幕 + 凸透镜（已实现，最省事）

```bash
gbt lens --f 20 --dist 1        # 生成透镜模式页 + 算距
```

- 凸透镜 f≈20cm、直径 ≥5cm（化妆镜放大片、单片放大镜都行）
- 屏幕到透镜 **16.7cm**，投 1 米 ⇒ 像 39×84 cm，亮度剩 25%
- 必须全黑；画面已做反色+镜像（透镜会再翻一次）

**适合**：晚上、小画面、看字。

## 路 B：拆旧 LCD 手机 + 大功率 LED（免费里最亮的）

原理来自 Hackaday 的 "Old Phone Upcycled Into Pico Projector"，中文同类项目 `songjian/diy-phone-projector`（★1，咖啡盒 + 望远镜筒 + 化妆镜搭光路）。

### 硬性前提（先确认，别白拆）

| 条件 | 怎么验 |
|---|---|
| **必须是 LCD 屏**（OLED 不行，不透光） | 关机状态下用强光照屏幕，能透出光的才是 LCD |
| 屏幕与触控能分离 | 老机型（如 iPhone 6s 之前、多数千元安卓）才有戏 |
| 你愿意毁掉这台旧机 | 拆背光层是不可逆的 |

### 步骤

```
① 拆屏：取下 LCD 面板（连偏光片一起，别刮花）
② 去背光：撕掉背光板/扩散膜，只留液晶层 + 两片偏光片
③ 装光源：10W 大功率 LED（暖白或 RGB）+ 匀光片，从背后均匀照亮
④ 加镜头：凸透镜 f=20cm，屏幕到透镜 16.7cm
⑤ 遮光：纸盒/黑卡纸做筒，漏光就废
⑥ 对焦：调 ③④ 之间的距离，直到墙上清晰
```

### 数学（照这个装就不会瞎试）

```
像大小 = 屏幕尺寸 × (投距 / 屏幕到透镜距离)
投 1 米、屏到透镜 16.7cm ⇒ 放大 6 倍
5.5 吋屏（12×6.5cm）⇒ 墙上 72×39 cm
亮度：1000 流明 LED × 透镜透过率(≈70%) ÷ 放大面积 ⇒ 比原背光高 50 倍量级
```

**风险**：拆坏、偏光片贴反（画面全黑）、漏光、散热不够烧 LED。**先拿最不心疼的旧机练手。**

## 路 C：已有的大屏 + 投屏（最稳，真的零成本）

如果你手上有：旧笔记本、显示器、电视、甚至另一台手机——

```bash
# 电脑端跑开源 AirPlay 接收端（UxPlay，免费）
git clone https://github.com/FDH2/UxPlay && cd UxPlay && mkdir build && cd build
cmake .. && make -j4 && ./uxplay -n "GBT-Screen" -nh

# 手机端：控制中心 → 屏幕镜像 → GBT-Screen
```

电脑接显示器/电视，就等于有了"投影"。**一分钱不花，画质最好。**

## 三条路的取舍

| 场景 | 选 |
|---|---|
| 晚上讲点东西，画面不用大 | **A**（5 分钟能用） |
| 有旧 LCD 手机，愿意动手，要亮 | **B**（一次投入，之后免费） |
| 白天、要大、要稳 | **C**（有设备就是最佳解） |

## 我不再提"买投影仪"

上一版手册里那三档预算作废——**只有当你需要"60 吋以上 + 白天能看"时才值得花钱**，否则 A/B/C 够用。
