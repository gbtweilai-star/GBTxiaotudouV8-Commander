# 164 · SVD 8 帧真图生视频（CPU）

## 一、实测
- 输入：雨中便利店外的猫 `s4.png`
- 8 帧 / 256×448 / 8fps / 2 步 / seed42
- 加载：**44.99s**
- 生成：**675.76s**（约 11 分 16 秒）
- 原始：`svd-cpu-fp32-8f.mp4`，8 帧 / 1.0s / 71,701 B
- 首帧 84,943 B → 末帧 132,588 B，猫/雨/光变化明显

## 二、可播放版
- 8 真帧循环 4 次 → **4.0s / 8fps / 32 帧 / 255,724 B**
- 路径：`交付成片/夜灯-Native/svd-cat-motion-4s.mp4`
- 2s 版本保留：`svd-cat-motion-2s.mp4`

## 三、耗时标尺
| 帧数 | 生成耗时 | 原始时长 |
|---|---|---|
| 4 | 352.47s | 0.5s |
| 8 | 675.76s | 1.0s |

- 约 **84s/帧**（2 步、256×448）；
- 14 帧预计 20 分钟级；
- 1080p/25 帧 CPU 不现实，必须 GPU 或换小视频模型。

## 四、边界
- 4s 是 8 真帧循环，不是补生成 32 帧；
- 不是秋叶权重；
- 不碰云端/ComfyUI。
