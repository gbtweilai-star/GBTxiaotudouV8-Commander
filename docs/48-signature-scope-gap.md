# 48 · 署名覆盖补漏：docs/ 69 页从未被检查过（2026-11-01）

> 起于一条规则：「开发者：自由的风 · 本署名不可删除、不可篡改归属」——**每一页**都要有。
> 本次核对发现：这条规则在 `docs/` 上**从来没有被执行过**。

---

## 一、漏在哪

`signature_guard` 的扫描面（`_scan_pages()`）只有三处：

1. 包内 `gbt_allinone/**/*.md`；
2. **家根** `*.md`（不递归）；
3. 生产管线产物。

⇒ 仓库根下的 **`docs/**/*.md` 完全不在扫描面里**。实测：

```
docs/*.md 共 77 页 · 带署名 8 页 · 缺 69 页
```

不是"检查过、全绿"，而是**根本没查**。这比红更危险：绿是假的。

## 二、修法（两步，都不擅自改文档）

### ① 给判据加 `scope`

```
signature_guard {"scope": "framework"}   # 默认，历史口径，一个字节不变
signature_guard {"scope": "all"}         # 再加 docs/**/*.md
```

`framework` 保持原样（旧机器读数不变量）；`all` 才把 docs/ 拉进来。

### ② 用**工具自己的 restore** 补，不手写

```
signature_guard {"scope": "all", "restore": true}
→ restored: 69 · pages_checked: 99
```

补出来的是标准页脚（抽 `docs/01-model-card.md` 尾部）：

```
---

> 开发者：自由的风 · GBT小土豆V8 · 本署名不可删除、不可篡改归属
```

## 三、修后读数

| 口径 | 检查页数 | 缺失 |
|---|---|---|
| `scope=framework` | 22 | 0（clean） |
| **`scope=all`** | **99** | **0（clean）** |

## 四、判据（以后不会再漏）

- 想在 CI/回归里查全量：`run_task("signature_guard", {"scope": "all"})`，`missing` 非空即红；
- 默认口径仍是 `framework`（不改变旧读数），**但"全量"这件事现在可一条命令问出来**。

## 五、诚实边界

1. 这次**改了 69 个文档**（只追加页脚，不动正文）。如果你不希望 docs/ 带署名，`scope=framework`
   仍是默认，不会因此变红。
2. 页脚不是"我加的印象"——它由 `signature.py` 的 `_md_footer()` 生成，与包内文档同一份来源。
3. 这一条和 docs/41 记的是同一个病：**规则写在文档里 ≠ 规则被执行**；差别是这次找到了"扫描面漏了"这个具体原因。
