> 主人 2026-11-01：「还有触手协作可视化面板，同样的风格做出来，以及思维导图任务指引」。
> 两个新视图接在同一套 3D 风格里（Three.js + Bloom + 拖动旋转 + 诚实标记）。

## 一、触手协作（`#team`）

| 视觉 | 对应真实结构 |
|---|---|
| 中心橙色核「共享任务」 | 当前要交付的那件事 |
| **8 根触手**（各自颜色 + 标签） | 8 个协作角色：感知·读架构/契约 · 规划·七步拆解 · 执行·run_task 派单 · 验证·真跑读数字 · 审计·留痕对账 · 固化·五处落位 · 报告·给数字 · 协同·交接回喂 |
| 触手之间的弧线 | 协作链（相邻 + 隔一个，共 16 条） |
| 弧线上流动的光点 | 协作消息（双向流动，不是单向箭头） |
| 底部三层同心环「共享账本」 | orchestration-ledger / audit：所有协作必须留痕 |

- 标记：`data-team3d = ok:8臂+16协作链`
- 交互：整块可拖、滚轮缩放、自转、Bloom

## 二、思维导图任务指引（`#mind`）

中心「任务指引」→ **6 分支 × 每支 3 叶 = 18 条具体动作**，内容就是这套框架真在跑的流程：

| 分支 | 叶子（18 条） |
|---|---|
| 理解需求 | 读架构/契约 · 危险=终端·转账 · 先定验收数字 |
| 拆解计划 | 套七步链 · 写任务账本 · 排好依赖 |
| 执行落地 | run_task 派单 · 五处落位 · 可用即测 |
| 验证取证 | 真跑读数字 · 截图/哈希 · 失败即修 |
| 留痕固化 | orchestration-ledger · docs 编号 · CHANGELOG |
| 交付报告 | 给数字不空话 · 说清差距 · 写剩余阻塞 |

- 标记：`data-mindmap = ok:6支+18叶`
- 交互：整块可拖、滚轮缩放、自转、Bloom

## 四、边界（如实）

- 触手协作的"消息"目前是沿弧线的示意光点，**还没接真实事件**（下一步可复用 `/api/events` SSE：哪个角色在跑就亮哪根 + 消息从真实 audit 走）；
- 思维导图内容是按本项目流程写死的指引，不是从文档自动解析（要自动可加 doc 索引解析）；
- 两者都用 canvas HUD 提示，不做 2D 重叠面板（避免又回到"面板堆叠"）。
