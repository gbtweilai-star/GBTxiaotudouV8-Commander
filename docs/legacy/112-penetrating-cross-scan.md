# 112 · 原生穿透式交叉扫描（每次扫描都看得见她怎么扫）

> 主人 2026-11-01 发来红绿交叉网图：「原生穿透式交叉扫描可视化，每次扫描不管扫什么都要看她是怎么扫的，
> 她有大脑，眼睛，耳朵，嘴巴，手；遇到扫描疑点她会考虑会反思穿透。」
> 再加一句纠正：「她的视觉可不是只有 OCR 哦。」

## 一、节点是真实数据，不是随机点

| 视觉 | 真实来源 |
|---|---|
| **385 个节点** | `state/console-data.js` 的 `caps.items` —— 全量能力位，一个不少 |
| **绿点 300 个** | `safe=true` 只读/安全位 |
| **红点 85 个** | `safe=false` 需授权位 = **疑点** |
| 交叉边 | 相邻位 + 对角 + 同域跨行远连（红绿交错的"穿透网"） |
| 扫描线 | 自上而下扫，扫过即亮；到边界反向，重新一轮 |

## 二、她怎么扫：五感分工（这是**过程**，不是结果动画）

| 感官 | 触发时机 | 表现 |
|---|---|---|
| **眼睛** | 每轮开始 / 扫过节点 | 看**视觉全谱**，不是 OCR（见下） |
| **耳朵** | 疑点出现 | 听异常（和眼睛同时亮） |
| **大脑** | 扫到红点（疑点） | 反思：红点处炸红色冲击波环 |
| **手** | 疑点确认 | 穿透：疑点位置起纵深束 + 扫描速度当场降到 25%（停下来想过再继续） |
| **嘴巴** | 一轮扫完 | 报结论（HUD 状态转"本轮扫完 · 疑点已全部穿透"） |

HUD 实时数字：`扫过 N/385 · 疑点 · 反思 · 穿透`，每项都写 `data-scan3d-*` 属性可巡检。

## 三、她的视觉不是只有 OCR（11 个真实能力位）

眼睛在面板里明写 **「视觉全谱 · 不止 OCR」**，对应真实注册能力：

```
vision_loop · vision · vision_grounding · vision_print · body_see · gods_eye
screen_sniff · video_intel · image_scout · zimage_rewash · chart_html
```

即：视觉闭环、视觉理解、视觉定位、视觉打印、身体视觉、上帝视角、屏幕嗅探、
视频情报、图像侦察、图像再生、图表渲染 —— OCR 只是其中很小一块。

## 五、边界（如实）

- 疑点=需授权位，是按 `safe` 字段算的（85 个），不是现场跑扫描器；下一步可接真实 `penetrating_cross_scan` 结果替换 `safe` 判定；
- 冲击波并发上限 24（再多会糊成一片）；
- "停下来想"只是局部放慢 0.8s，不是真推理链可视化（真推理要接 chain_kernel 的 step 事件）。
