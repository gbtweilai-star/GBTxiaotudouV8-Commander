## 二、3D 触手星图（照主人参考图重做）

| 层 | 数量 | 含义 |
|---|---|---|
| 域核心 | **30** | 每个域一颗黄色发光球（大小=域内能力数） |
| 能力位节点 | **385** | 簇内小节点，按域色相分布 |
| **触手（视觉）** | **15,400** | 每个能力位展开 40 根弯曲细线+端点（`385 × 40`）——**示意"亿万根"的密度，不代表真实调用数** |
| 域间弦线 | 若干 | 域与域之间成网 |
| 外圈球壳 | 2,000 点 | 冷蓝/暖黄交替（参考图外层点云） |
| 深层星尘 | 3,000 点 | 背景纵深 |

**口径诚实**：
- 真实触手 = 每个能力位在 `run_task` 调用时按需展开，审计落 `audit.jsonl`；视觉触手只是"密度示意"；
- 页面写死标记：`document.documentElement.dataset.space3d = "ok:385+30+15400"`（巡检可查，不靠嘴）；
- WebGL 不可用 / import 失败 / file:// 直开：都有明确兜底文案（不假装有 3D）。

## 三、验证（刚跑）

```
http://127.0.0.1:8766/console/index.html#space
data-space3d = ok:385+30+15400          ← 能力位 385 / 域 30 / 视觉触手 15,400
功能表行数：385  技能卡数：23  视图页签：对话/功能表/技能栏/3D 星图/仪表盘
截图：assets/panels/console-caps.webp · console-skills.webp · console-dash.webp · console-space.webp
```

修过的一个真 bug：console-server 原来把 `/` 直接当页面返回，导致页面里的 `./app.js`、`./app.css` 解析成根路径 404
（http 打开时整页无 JS）。已改成 `/ → 302 /console/index.html`，相对路径全部正确。

## 四、和参考图的差距（如实）

- 参考图是"多簇 + 长触角 + 大量小节点"的有机形状，我们已做到：385 节点分簇、15,400 根触手、外圈点云；
- 仍差：**后处理辉光（Bloom）**、更细的线宽层次、按能力位真实调用的动态触手（现在只有静态示意）。
