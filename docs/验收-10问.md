## 补记 2026-10-24：算术短板用「计算器两趟」修好了

### 做了什么

1. 桥新增 `POST /v1/calc`：只认四则/括号/百分号/乘方（AST 白名单，`__import__` 之类一律拒）；
2. 页面遇到像数学题的问题（含数字 + 多少/几/平均/找零…）先跑**第 1 趟**：让模型只吐算式（max_tokens 24）；
3. 算式交给 /v1/calc 算；
4. 把 `（计算器： 100 - 3 * 18 = 46 ）` **前置到用户那句话开头**，再跑第 2 趟正常回答。

### 关键发现（踩了才知道）

| 注入方式 | 找零题结果 | 结论 |
|---|---|---|
| 放 system 消息里 | 16 元（错） | 无效 |
| 放 system + 「必须原样使用」 | 16 元（错） | 无效 |
| 只给正确结果 | 16 元（错） | 无效 |
| **前置到用户消息** | **46 元（对）** | 唯一有效 |

细调模型会把 system 段当背景噪音，**只有用户这一轮里的内容它真当约束**。
