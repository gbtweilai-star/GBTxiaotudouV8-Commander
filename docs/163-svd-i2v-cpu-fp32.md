# 163 · SVD 图生视频 CPU fp32 跑通（真 4 帧）

## 一、修复
- SVD 权重是 fp16 分片；CPU 不支持 fp16 推理；
- 改为 `torch.float32` 加载 fp16 文件（`variant="fp16"`），CPU 可跑；
- 不再出现 `float16 cannot run with cpu`。

## 二、实测
- 输入：`film-nightlight/images/s4.png`（雨中便利店外的猫）
- 4 帧 / 256×448 / 8fps / 2 步 / seed42
- 加载：**70.14s**
- 生成：**352.47s**（约 5 分 52 秒）
- 原始输出：`svd-cpu-fp32-4f.mp4`（4 帧，0.5s，54,227 B）
- 真帧差异：0 帧 93,787 B → 3 帧 154,569 B，猫/雨/光有变化，不是静帧轮播。

## 三、可播放版
- 4 帧真实结果循环 4 次 → **2.0s / 8fps / 16 帧 / 212,757 B**
- 路径：`交付成片/夜灯-Native/svd-cat-motion-2s.mp4`
- 说明：2s 是重复真帧，不是补生成帧；不冒充 14 帧。

## 四、边界
- CPU 太慢：4帧约 6 分钟；8 帧预计约 12 分钟，14 帧约 20+ 分钟；
- 分辨率 256×448，非 1080p；
- 这是 SVD 图生视频，不是秋叶权重；
- 不碰云端/ComfyUI。
