# 116 · 位置前馈 vs 动态外力：峰值反而冲到 6.68

> 上一步：力变化率前馈在静态接触下不触发。
> 这一步：用 external 正弦变化 + 下一帧位置前馈，试图提前收力。

## 一、实测（120 帧 / external=0.2 + amp0.2 正弦 / limit=0.5）
| 项 | 数值 |
|---|---|
| moved | 120/120 |
| fps | **43.95** |
| force_peak | **6.68（超过 limit 13 倍）** |
| pre_clamped | 120 |
| adjustments | 108 |
| stiffness | 100→81 |
| realtime_ok | true（按速度判据） |

## 二、结论
- “按下一帧外力位置前馈”在**外力模型不精确**时会把目标推错；
- 力峰值 **6.68 > 0.5**，不安全；不能因为 fps 高就说过关；
- 当前最稳的仍是**纯 pre-clamp 保底**（force_peak=0.5，但 ff_hits=0）；
- 前馈必须建立在**可信的外力/接触模型**上，否则会放大风险。

## 三、下一步
1. 前馈只在 **pre-clamp 之后再小步修正**，不能替代主保护；
2. 没有真实力传感器时，前馈只做离线研究，不进实时写路径；
3. 真机接传感器后再验证。
