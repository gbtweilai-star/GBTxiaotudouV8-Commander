# 112 · 自适应刚度优化：compliance 降频 + 接触防抖，42fps

> 上一步：自适应刚度每帧调用 compliance，fps 掉到 14.8。
> 这一步：compliance 每 10 帧一次、接触事件 2 帧防抖，把 fps 拉回 42。

## 一、做法
- `compliance_every=10`：不是每帧写柔顺参数；
- `debounce=2`：接触 on/off 连续 2 帧才切换，防抖；
- 刚度变化仍按接触状态：触 limit 时 `k*=0.9`，离触 `k*=1.02`；
- 力预判/限幅逻辑不变。

## 二、实测（60 帧 / limit=0.5 / external=0）
| 项 | 旧（每帧 compliance） | **新（每10帧 + 防抖）** |
|---|---|---|
| moved | 60 | **60** |
| fps | 14.81 | **42.33** |
| force_peak | 0.5 | **0.5** |
| stiffness | 100→10 | **100→53.14** |
| compliance_calls | 60 | **6** |
| contact_events | 1 | 1（`contact_on`） |
| realtime_ok | true（勉强） | **true（余量足）** |

## 三、结论
- 降频 + 防抖后 fps **14.8 → 42.3**；
- 力峰值仍 = limit，不超；
- 刚度不再一触到底，100→53.14，有恢复空间；
- 仍是虚拟弹簧模型，不是真手传感器。

## 四、边界 / 下一步
- 摄像头未通；真机需标定 + 力传感器；
- 下一步：compliance_every 自适应（接触瞬间加密、稳态降频）；
- 力事件接导纳参数，不只改刚度。
