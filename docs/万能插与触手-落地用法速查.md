## 0. 一句话结构（先认清，别用错）

- **本体是触手**：触手不是键盘鼠标手指，是每根都持有本体全部能力 + 自带认知包 + 走自己大模型权重的智能执行体（10 域 133 方法）。
- **万能插是触手衍生的能力位**：动态接口融合层 `gbt_allinone/universal_plug.py`，没有固定插座——给一个连接点（路径/URL/命令/CDP 端点）→ 自动识别 → 生成接口 → 插上 → 调用。
- **门不绕**：万能插本层零作用域（只登记），真执行转 `run_task("omni_plug")`，由 `security/policy.py` 现场判类挂作用域。

```powershell
python tools/codex-scripts/five-dim.py cap tentacle '{"action":"list_windows"}'
python tools/codex-scripts/five-dim.py cap tentacle '{"action":"type","kwargs":{"text":"你好"}}'
```

**Python 直调**（脚本里）：
```python
from gbt_allinone.tentacle.omni_tentacle import get_omni
om = get_omni()
cap = om.see(incremental=False)      # 取整帧（非增量碎片）；返回 image_base64 原样
print(cap["ok"], cap["size"], len(cap["image_base64"]))
```

### 六条铁律（动手必守，代码强制一部分）
1. 先看再动（`see` 会对动作类自动先取帧，返回 `saw_first: true`）
2. 动后等稳定（动作后 sleep 0.5~2s 再截下一帧）
3. 找不到就滚（`scroll_find`）
4. 遇弹窗必关（`detect_dialog` 可能漏，视觉看到才算——见下）
5. 每步亲眼验证（前后帧指纹对比 / 视觉读回）
6. 不确定就对比前后截图

### 采图 → 大模型秒理解（原样 base64，契约传输）
```python
from gbt_allinone.tentacle.brain import visual_cortex as VC
frame_b64 = om.see(incremental=False)["image_base64"]   # 原样，不转像素统计
u = VC.get_cortex().understand_screen(frame_b64=frame_b64)  # base64 → cloud_recognize → agnes
print(u["description"], u["fingerprint"], u.get("cached"))
```
- 云端三要素（DPAPI 保险箱 + base_url + model）：`cloud_recognize` 走保险箱 profile=agnes。
  查状态：`python -c "from gbt_allinone import vision_cap as v; print(v.run('status'))"`；
  `cloud: false` 就是缺 key，用 `deepseek_key.store_key(key, "agnes")` 存入。
- 指纹缓存：同画面重复 `understand_screen` 命中缓存（零成本）；帧变则重新理解。

## 3. 万能插（gbt_universal_plug）怎么用

```powershell
python tools/codex-scripts/five-dim.py cap gbt_universal_plug '{"op":"schema"}'   # 看契约/支持的 kind
python tools/codex-scripts/five-dim.py cap gbt_universal_plug '{"op":"ports"}'    # 列已插连接点
python tools/codex-scripts/five-dim.py cap gbt_universal_plug '{"op":"plug","target":"<路径/URL>","name":"<小写名>"}'
python tools/codex-scripts/five-dim.py cap gbt_universal_plug '{"op":"invoke","name":"<名>","verb":"<动词>","args":{...}}'
python tools/codex-scripts/five-dim.py cap gbt_universal_plug '{"op":"verify"}'
```

**支持的 kind → 动词**（`schema` 现读为准）：
```
http:get · tcp:probe · path:read/stat/view · dir:list/stat · bin:exec/stat
cmd:run · scheme:open · unix:connect · image:view · browser:open/click/type/scroll/key/drag/wait/script
mcp:call · ws/remote/unknown:not_wired（如实标，不冒充）
```

**Python 直调**：
```python
from gbt_allinone import universal_plug as up
up.plug("C:\\path\\to\\img.jpg", name="myimg", replace=True)
r = up.invoke("myimg", "view")
print(r["result"]["via"], r["result"]["evidence"])
up.unplug("myimg")
```
name 规则：小写字母开头 + 小写字母数字下划线，2~48 位（`_x` 不合法）。

## 4. 万能插接管浏览器（2026-11-26 新增，人类级操作）

### 前置：CDP 端口（9222）

```python
import subprocess, os, time, urllib.request, json
CHROME = r"C:\Program Files\Google\Chrome\Application\chrome.exe"
UDD = r"C:\Users\ADMIN\AppData\Local\Temp\gbt-cdp-profile"
subprocess.Popen([CHROME, "--remote-debugging-port=9222", "--user-data-dir="+UDD,
                  "--no-first-run", "--no-default-browser-check", "about:blank"],
                 stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL)
# 验证：urllib 开 http://127.0.0.1:9222/json/version
```

### 授权（必须人亲手发，AI 不自授）
```powershell
python -m gbt_allinone auth grant --scope browser_control --ttl 600 --purpose "万能插接管浏览器"
# 提示输入 YES 回车
python -m gbt_allinone auth status   # 看 grants_available
```
⚠️ 浏览器管控走 `browser_control`（不是 process_execute）——policy 的 kind→socket 映射已把 `browser` 接到 browser 插座。

### 完整闭环（照抄就能跑）
```python
from gbt_allinone import universal_plug as up
CDP = "http://127.0.0.1:9222"
up.plug(CDP, name="webtest", replace=True)   # kind=browser, ops=[open,click,type,scroll,key,drag,wait,script]

def inv(v, **kw):
    r = up.invoke("webtest", v, kw)
    res = r.get("result") or {}
    return res.get("result") or res

inv("open",   url="https://example.com")
inv("script", script="document.title")                          # 参数名是 script（adapter 内部转 js）
inv("type",   selector="#q", text="GBT-OK", clear=True)
inv("click",  selector="#b")                                    # click 会先 bringToFront + 探针验证，无效自动降级 JS
val = inv("script", script="document.title+' | '+document.querySelector('#q').value")
assert "GBT-OK" in val
up.unplug("webtest")
```

**动词 → native_browser 动作映射**（`tools/omni_adapter.py` 的 `_verb_map`）：
```
open→navigate · click→click_element · type→type_text · wait→wait_for
scroll/key/drag/script→execute_script（script 键自动转 js）
```

### 已知坑（都已修，记在这里防回归）
1. `classify` 顺序坑：`http://127.0.0.1:9222` 曾被 SCHEME_RE 先吞成 http → browser 判断必须排在 scheme 之前。
2. `execute_script` 形参是 `js` 不是 `script` → adapter 转交前改键。
3. CDP Input 在非活动 tab 静默无效（报 clicked:true 但页面没反应）→ click_element 已加 `Page.bringToFront` + click 探针读回 + 自动降级 JS 事件。
4. 外层 `ok` 曾掩盖底层失败 → 现以底层 `r.ok` 为准。

## 5. 授权作用域速查

| 动作 | 作用域 | 发放 |
|---|---|---|
| see / list_windows / tentacle_manifest / tentacle_status / web_read | 零 | 直接跑 |
| click / type / focus_window / domain_act（桌面） | `desktop_control` | 人亲手发 |
| 浏览器 open/click/type/script（CDP） | `browser_control` | 人亲手发 |
| 起进程 / MCP / 连终端 | `process_execute` | 人亲手发 |
| 写盘 / 移动 / 删除 | `filesystem_write` | 人亲手发 |
| 转账 / 总控 / 远程设备 | 一次性 | 人亲手发，用完即删 |

```powershell
python -m gbt_allinone auth grant --scope <作用域> --ttl 600 --purpose "<用途>"
```
时段授权 600s 内可反复用（用一次记一次）；授权只能人亲手在终端发，`run_task` 无任何自授分支。
