# 110 · 长视频链 + 力限幅：150帧 40fps / 力峰值=limit

> 下一步：把力限幅接进 chunked 长视频链，不只做位置。

## 一、实测
| 场景 | frames | moved | fps | 力峰值 | 预限幅 | realtime_ok |
|---|---|---|---|---|---|---|
| 150帧 / 无力限 | 150 | 150 | **40.74** | 1.005 | 0 | true |
| 60帧 / limit=0.5 | 60 | 60 | **42.0** | **0.5** | **60** | true |

- chunk 视觉 p95：17–19ms；
- IK mean 0.08–0.19ms；
- 力限幅：先预判，目标夹到 `external + limit/k`，实测峰值**正好等于 limit，不超**。

## 二、链路
```
chunk 子进程视觉（进程回收，模型一次）
→ 父进程 IK
→ 力预判/夹取
→ loopback.move + contact
→ read_state
```

## 三、结论
- 长视频进程回收 + IK + 力限幅，150/60 帧均跑通；
- 流程顺序：**先预判力，再动；不是撞了再退**；
- 力峰值=limit 是仿真弹簧模型结果，不是真手传感器。

## 四、边界
- 仍离线视频；摄像头未通；
- loopback 仿真，不驱动真手；
- 真机需标定 + register_map + confirm + 力传感器。
