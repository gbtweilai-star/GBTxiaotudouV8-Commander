### 踩到的坑（值得记）

桥的目录读的是 `data/capabilities.json` **快照**，不是注册表本身。
加了能力位不刷新快照，桥会说「目录里没有这位能力位」——即使注册表里明明有。

## 二、多轮上下文：做了，但默认关

实测（同一个模型、同一条系统提示）：

| 场景 | 回答 |
|---|---|
| 带 1 轮历史问「我叫什么名字？」 | 我叫**本源台**。（把自己的名字当答案） |
| 带 1 轮 + 「禁署名」提示 | 我叫**本源人生**。 |
| 带 2 轮历史 | 我在任何时候都该叫自己**主人的名字**… |
| 不带历史 | 我在任何时候都不能告诉你「我的名字是…」 |

**结论：这个细调模型不会用上文。**所以：

- 页面把历史存起来（最多 8 轮），但**默认不带**；
- 勾上「带上下文」才注入最近 2 轮；
- 旁边有「⟲ 清」一键清空。

写出来是为了让后来人别以为「加了历史就变聪明」——它不会，实测更糟。

## 三、界面上真能动手了

聊天输入框旁边多了三个键：

| 键 | 做什么 | 走哪个能力位 |
|---|---|---|
| 👁 看屏幕 | 截一张 | `body_see` |
| 🗣 说一句 | TTS 念「主人，我在」 | `body_say` |
| ⟲ 清 | 清空上下文 | — |

两个动作都走 `/v1/dispatch`（**同一道门**），不是直连 body 接口。
没票时页面会如实显示：

```
⛔ 看一眼屏幕 需要授权：filesystem_write
（在终端发一次票：python -m gbt_allinone auth grant --scope filesystem_write --ttl 600）
```

## 四、边界（不知道就别说知道）

- `body_type` / `body_click` / `body_open` **没真跑过**（需要 `desktop_control` / `process_execute` 票）；
- 截图/发声是**真跑通**的（`body_see` 落了 634 KB 的 png，`body_say` 念了 12 个字）；
- 多轮是**能开但没用**，不是「已支持」。
