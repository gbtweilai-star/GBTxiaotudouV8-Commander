# 本地修复手册（图像）· 一页纸

> 2026-10-26 ｜ 适用：`tools/batch_polish.py` / `reframe.py` / `declutter.py` / `polish2.py` / `taste_gate.py`
> 结论先说：**本地能修 5 条判据，其中 3 条互斥；构图本体修不了。**

## 一、四条路线（全跑，整体择优）

```
候选 0  原图
候选 1  降杂乱 → 扩留白        (dc → rf)
候选 2  扩留白 → 降杂乱        (rf → dc)
候选 3  提亮主光 → 扩留白      (bf → rf)
候选 4  提亮主光 → 降杂乱 → 扩留白 (bf → dc → rf)
```

每条候选都过一遍精修（局部对比 + 边缘锐化 + 分离色调），再判；
择优规则：**不过项最少 → 同分取高频更高**。

**为什么不能逐步贪心**：每步只比"当前更好"会丢掉整体最优组合。
实测 P1：先降杂乱后，扩留白不再"更优"被拒 ⇒ 丢掉了一个能 PASS 的组合。

## 二、五个可修轴（方法与副作用）

| 轴 | 手段 | 参数 | 副作用 |
|---|---|---|---|
| 边缘密度 | 梯度分档软化（强边保留 / 中纹理削弱 / 弱噪抹平） | `lo=12 hi=45 amount=0.7~0.75` | 主体边缘若梯度不足会被一起软化 |
| 留白占比 | 向主体相反侧扩画布（主色填充） | `target_void=0.16` | **拉低整体对比（sd↓）** |
| 焦点块数（亮图） | 只提亮最大高光块 | `gain=1.35 feather=8` | 无（对比不降） |
| 焦点块数（暗图） | 压暗次要高光（羽化） | `darken 自适应 0.55–0.90` | **对比一起被压掉** |
| 对比 | 局部对比 + S 曲线 | `lc=0.22` | 会让更多高光越阈值 ⇒ 焦点块数↑ |

**阈值（来自 `taste_gate.py`，photo 档）**：色数≤16 · sd≥28 · 焦点占比 0.0004~0.05 · 焦点块 1–2 · 边缘 0.006~0.05 · 留白 0.12~0.62 · 渐变不判。

## 三、冲突矩阵（这是本地修复的真天花板）

```
扩留白 ──拉低对比──▶ 补对比 ──抬高更多高光──▶ 焦点块数↑ ──压暗──▶ 对比↓
   ▲                                                                  │
   └────────────────────── 回到起点（闭环）───────────────────────────┘
```

**实证（tz_A）**：

| 组合 | sd | 留白 | 焦点块 | 结果 |
|---|---|---|---|---|
| 只提亮 | 30.6 | 0.088 ❌ | — | 不过 |
| 提亮 + 扩留白 | 25.5 ❌ | 0.381 ✅ | — | 对比不过 |
| 再补对比 ×1.16 | 30.3 ✅ | 0.381 ✅ | 3 ❌ | 焦点不过 |
| 再补对比 ×1.24 | 34.7 ✅ | 0.381 ✅ | 3 ❌ | 仍不过 |

⇒ **三条同时要 ⇒ 无解**。不是参数没调好，是这张图的动态范围撑不住。

另一个死结：**bf 与 converge 目标相反** ——
提过亮（bf）就不能再压暗（converge），否则刚提的那块又被压回去（实测 P2 从 PASS 打回 FAIL）。
代码里的护栏：`if "bf" not in order[:i]: converge(...)`。

## 六、怎么跑

```bash
# 只修 + 判 + 报告
python3 tools/batch_polish.py --glob '/var/minis/attachments/tz_*.jpg' \
        --out /tmp/out --reframe --declutter --maxw 900

# 连出片
python3 tools/batch_polish.py --glob '…' --out … --reframe --declutter \
        --video /var/minis/attachments/reel.mp4
```

单件调用：

```bash
python3 tools/reframe.py  in.jpg --out out.png      # 焦点收敛 + 扩留白（带自检回退）
python3 tools/declutter.py in.jpg --out out.png      # 压边缘密度（带自检回退）
python3 tools/polish2.py  in.jpg --out out.png       # 局部对比 + 边缘锐化 + 分离色调
python3 tools/taste_gate.py --judge x.png --profile photo
```

## 七、边界（别越界）

- **修不了**：主体姿态、机位、景深、脸的结构、材质纹理 —— 这些要重新生成。
- **不要用**：把缩放放大当"变清晰"（我们量过：同尺寸高频不升反降，是假细节）。
- **不要用**：LAB 的 a/b 通道平移做色彩匹配（会撞极值出紫绿噪斑，v5 已证）。
- **必须留**：每步的自检回退 —— 更差就输出原图，别把图越修越坏。
