# 111 · 触手协作的脉冲特效（真实事件 → 可见冲击波）

> 主人 2026-11-01：「把脉冲的特效做出来」。上一轮触手协作只有静态弧线 + 小光点；
> 这一轮做的是**看得见的脉冲**：真实事件到达时，对应角色尖端炸出扩散冲击波环，
> 消息点拖着辉光飞向共享任务核，核被点亮时整体闪一下。

## 一、特效构成

| 层 | 做法 | 生命周期 |
|---|---|---|
| **冲击波环** | 环形径向渐变 Sprite，从角色尖端扩散：scale 1.2 → 10.2，透明度 0.95 → 0 | ≈0.63s（speed 1.6） |
| **消息拖尾** | 角色 → 中心反走曲线，主点 + 跟随辉光 Sprite | 走到中心即回收 |
| **核心闪光** | 共享任务核 scale 1 → 1.6 → 1，颜色 `#ff9f1c → #ffd166` 闪 | ≈0.5s（coreFlash 衰减） |
| **角色亮灯** | 对应触手尖端 emissiveIntensity 1.0 → 2.2、辉光 0.8 → 1.0 | 6s 后回落 |
| **巡检标记** | `data-team3d = ok:8臂+16协作链+脉冲N`（实时活动脉冲数） | 实时更新 |

事件→角色映射是**真实映射**：守卫/账本类事件（selfscan / inventory / signature_guard / legacy_guard / cap_self）→ 审计；
run/denied → 执行/协同；report → 报告；recon → 感知；未知事件按名字哈希固定落到同一角色（不会随机跳）。

## 二、实测

```
?selftest=1（模拟两条：inventory、selfscan）
  data-team3d = ok:8臂+16协作链+脉冲2        ← 两道冲击波同时在扩

?pulse=1（连续打点，验收/截图用）
  data-team3d = ok:8臂+16协作链+脉冲16
  data-team3d-pulses = 16                     ← 上限 16 后回收最早的，不堆内存
截图：assets/panels/console-team-pulse.webp（多环同时扩散 + 核心闪光）
```

## 三、边界（如实）

- 冲击波只在**事件到达**时出现（SSE 或 selftest/pulse 触发），不是无脑常驻动画；
- 这一刀没做屏幕空间后处理（radial blur / lens flare），用的是几何 Sprite 环 + Bloom，加后处理会更贵；
- 消息拖尾是单点 + 单辉光，没做多段拖尾粒子流（下一步可换 `Trail` 式多段）。
