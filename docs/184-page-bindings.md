# 184 · 页面 ↔ 触手双向绑定（唯一真源）

> 主人：**触手必须和所有页面双向绑定，不许漏网**。
> 之前 `state/page-bindings.json` 缺失，`page_scan` 自然扫出大面积缺口；这次补上**生成器 + 唯一真源 + 测试**，不再手写、不再让页面自己编。

## 一、真源与生成

| 件 | 落点 |
|---|---|
| 生成器 | [`tools/bind_pages.py`](../tools/bind_pages.py)：`--apply` 生成 / `--check` 判据 |
| 唯一真源 | `state/page-bindings.json` |
| 消费者 | `page_scan`（只读这份文件） |
| 验收 | [`tests/test_page_bindings.py`](../tests/test_page_bindings.py) |

## 二、口径

- 页面 = console 当前 **20 个视图**（含 `/teardown/` 数字人页）；
- 每页按**域**从注册表现算能力位，不手写能力名；
- **正向**：页 → 能力位；
- **反向**：能力位 → 页，与正向**同一次生成**；
- 每页至少 1 根；每根能力位至少落 1 页；未覆盖的补到 `dash`；
- 落点必须真在盘；能力位必须在注册表。

## 三、真机读数

```json
{"页数":20,"绑好":20,"未绑好":0,"能力位落页":410}
```

`page_scan op=status` → `页数=20 · 绑好=20 · 未绑好=0`。

不再有“某页没有触手 / 某根触手没有页”的漏网。`page_scan scan` 的绿/黄/红是**运行时**分类，不是绑定缺失；绑定缺失只看上面四个数。

## 四、边界

1. 这是**页面 ↔ 能力位**的绑定；不是 3D 触手渲染；
2. 能力位按域落页，不代表该页真的调用了每个能力；
3. 运行时红/黄仍由 `page_scan` 实测；本文件只保证“绑定关系无漏网”；
4. 旧页面（`dh-live`/Salticus/归档面板）不在当前 20 页内，不参与绑定。
