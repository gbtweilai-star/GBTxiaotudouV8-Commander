# 72 · 蓝图模板库：落地即沉淀，相似架构复用（2026-11-01）

> 每次从零拆任务既慢又容易漏。落地过的蓝图是**已验证资产**，应该沉淀下来。

---

## 一、规则

1. **只有落地的才存模板**（`save_template` 先查 `status.landed`）—— 不把失败经验当资产；
2. **模板按架构关键词签名**（`ARCH_HINTS` 命中的词），存任务图 + 验收口径；
3. **复用要够像**：关键词重合 **≥2** 才复用（宁可不用，不用错）；
4. **复用后仍补专项**：模板给已验证任务，新架构的关键词再补专项任务。

## 二、实测

```
造蓝图（21 任务）→ approve → land → landed=True
  → 自动沉淀模板 "上下文-不打扰-主干-吞-93816"（21 任务，keys 11 个）

再造相似架构 → from_template = 同名模板 → tasks=26（21 模板 + 5 新专项）
```

## 三、边界

- 模板**不是免检**：复用后的蓝图仍要 `approve`（这是唯一允许的交互）；
- 模板任务里若含写盘/发布类，仍要走门；
- 模板会累积，`state/blueprint-templates/` 可人工清理；
- 判据测试会**清掉自己新建的模板**，不留垃圾。

## 四、判据（`test_blueprint` 第 [13] 组 4 条）

- 落地后自动沉淀模板
- 相似架构复用模板
- 复用后任务数 > 0
- 模板列表可读
