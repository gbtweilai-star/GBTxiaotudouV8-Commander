# 113 · 接触后密调 / 稳态降频：40.36fps

> 上一步：固定 compliance_every=10，42.33fps。
> 这一步：接触事件后 3 帧密调（每 2 帧），稳态才降到 10。

## 一、做法
- `dense_frames=3`：接触事件发生后的 3 帧，compliance 间隔 = 2；
- 其余稳态间隔 = `compliance_every`（10）；
- 接触仍 2 帧防抖；
- 刚度按力/接触自适应。

## 二、实测（60 帧 / limit=0.5 / external=0）
| 项 | 数值 |
|---|---|
| moved | **60/60** |
| fps | **40.36** |
| force_peak | **0.5（= limit）** |
| stiffness | 100 → **43.05** |
| compliance_calls | **8** |
| contact_events | 1（contact_on） |
| realtime_ok | **true** |

## 三、结论
- 接触后密调没有把 fps 再往上推多少（40.36 vs 42.33），但 **compliance 调用从 6→8**，仍远少于每帧 60 次；
- 力峰值仍 = limit；
- 动态策略可用，收益有限；下一步要针对**接触瞬间的力超调**而不是继续调频率。

## 四、边界 / 下一步
- 仍是虚拟弹簧，无真手；
- 下一步：接触瞬间的预测/前馈（力变化率），而不是只改刚度；
- 摄像头/真机接入。
