# 58 · 脉冲优先路由：真的把 40s 级调用省掉了（2026-11-01）

> 主人口径：「**提速靠脉冲**」。docs/57 把直达做到了 0 token、毫秒级，但**真正的路由入口
> `commander.route()` 还在直连权重** —— 也就是说提速没进主干。这一轮把它接进主干，并用读数证明。

---

## 一、改了什么

`commander.route()` 开头新增**脉冲优先**（`pulse=True` 默认开）：

```python
if pulse:
    d = pulse_core.direct(text)     # 0 token，四级/五级判断
    if d.hit: return {"path": "pulse_direct", "tokens": 0, ...}
# 没命中才往下走：词表收窄 → 权重判决
```

三条纪律：

1. **命中就返回，不叫醒电池**（不取电、不占口、不写电表）；
2. **没命中照旧**走权重（保持原有准确率，慢的那条路还在）；
3. **可关**：`route(..., pulse=False)` 用于对照/测试。

## 二、实测（人写 24 条基准）

| 路径 | 命中 | 正确 | 平均耗时 |
|---|---|---|---|
| `pulse.direct`（本轮接入） | 17/24 | **15** | **2.3 ms** |
| 权重判决（原有） | 24/24 有返回 | 16 | 66 000 ms |

**同一批题，直达的正确数与权重判决几乎打平（15 vs 16），但快 28 000 倍。**

## 三、真实入口实测（`commander.route`）

```
审计                 -> audit_query     path=pulse_direct   17.9ms  tokens=0
字数                 -> count_words     path=pulse_direct   16.7ms  tokens=0
镜像                 -> mirror_scan     path=pulse_direct   16.8ms  tokens=0
出图                 -> comfy_native    path=pulse_direct   16.9ms  tokens=0
今天天气怎么样随便聊聊 -> （未命中）      path=commander    22542.1ms
```

未命中的那句仍然走权重（22.5s）——这是**设计如此**：宁可慢，不许猜。

