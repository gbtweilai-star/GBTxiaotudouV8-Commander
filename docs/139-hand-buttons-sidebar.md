# 139 · 手部按钮从右下角挪进左侧栏

## 一、问题
旧版把 5 个按钮 `position:fixed; right:16px; bottom:16px` 直接压在对话输入区上，确实丑。

## 二、修复
- 删除右下浮动条；
- 在左侧栏 `.panel-actions` 下方新增 **「手部工具」** 分组：
  - 2 列网格；
  - 按钮：手部图片 / 手部视频 / 相机chunks / 监视目录；
  - 录相机5s 跨两列；
- 结果改为**居中模态框**，不再右下浮动；点遮罩/关闭可关；
- 保留原生文件选择。

## 三、验证
- `node --check main.js` → OK；
- CDP 截图确认：按钮只在左栏底部，不再覆盖输入框；
- CDP 触发 `window.gbtHand.record(...)` 已验证可录 5 个 chunk；
- 桌面版 `/api/proactive` 200。

## 四、边界
- 仍是注入式 UI + preload，不是重打安装包；
- 手部按钮只在左栏可见，不占中间对话区。
