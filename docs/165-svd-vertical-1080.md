# 165 · SVD 真运动竖屏版 1080×1920

## 一、产物
- 源：8 个 SVD 真实生成帧（256×448）
- 输出：`交付成片/夜灯-Native/svd-cat-1080x1920-8s.mp4`
- 画幅：**1080×1920**
- 时长：**8.0s**
- 帧数：64（8 真帧循环 8 次）
- 帧率：8fps
- 大小：**4,336,662 B**

## 二、说明
- 8 个真帧被放大到 1080×1920，用 lanczos/裁剪填满竖屏；
- 8s 是循环播放，不是 64 帧全新生成；
- 未做“AI 超分”冒充新细节；
- 运动来自 SVD 真帧，不是 Ken Burns。

## 三、耗时
- 8 帧生成 675.76s；
- 4 帧生成 352.47s；
- 竖屏封装仅 ffmpeg，秒级。

## 四、边界
- 1080p 是放大，源细节仍是 256×448；
- 8fps 偏低，长片/25fps 需 GPU 或更小视频模型；
- 不是秋叶权重，不碰云端/ComfyUI。
