# A19 常驻：还差的那一环与补法（2026-10-31）

## 实测事实（本机）
```
apple-open lmpocket:// → ok:true 但 opened:false（多次）
唤醒后 15 秒：/v1/models = False
MemFree 415 MB ⇒ App 根本没被拉起来/没载权重
之前成功那次（13.6s 起来）是在主人手动操作过 App 之后
```
**⇒ 我们这侧唯一的前台触发器 `apple-open` 不可靠**：它返回 ok，但系统没有真的把 App 切到前台。

## 为什么这件事必须由系统层补
iOS 不允许第三方进程（iSH、Minis 的 shell）后台拉起别的 App 并保持前台。
真正可靠的触发器只有 **快捷指令（Shortcuts）自动化**——它是系统级、可在后台执行。

## 一次性设置（30 秒，做完永久生效）
1. 打开「快捷指令」→ 自动化 → 新建
2. 触发条件选 **时间**：每 15 分钟重复（或「App 关闭时」= 你离开 LM Pocket 就自动拉回）
3. 动作选 **打开 App** → 选 **LM Pocket**
4. 关掉「运行前询问」
5. 保存

之后：LM Pocket 会被系统周期性拉到前台 → Auto-Start 会起服务（你已打开）
→ 我们的 `a19_brain` 每 6 秒探活，一旦 200 就立刻把队列里的活算完
→ 结果落 `state/local_results.jsonl`，桥按 id 取回，你在 Minis 里看到答案。

## 我们这侧已经就绪（不需要再改）
```
桥 default = selfhost（A19 主脑），挂起时入队
a19_brain：每 6s 探活 → 活的就消费队列 → 写完交回
weights.py 主干：只用我们自己的权重，不换外部模型
```
