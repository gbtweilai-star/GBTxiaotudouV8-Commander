# 02 · 架构：为什么它敢叫"总指挥"

> "总指挥"不是形容词，是**结构**：模型只负责判断，执行只有一个门，账本只追加。

## 一、一条链，五个环节

```
人话 / 需求
   │
   ▼
① 总指挥模型（本仓库的主角）
   判断：这件事落到哪个能力位？要什么参数？会不会写盘/花钱/出网？
   │
   ▼
② 唯一门 run_task(kind, payload)
   唯一入口。没有旁路：不经过它，任何动作都到不了底层。
   │
   ├── 只读位（262 位）──────────────► ③ 直接执行
   │
   └── 写口位（79 位）──► ④ 人工授权门（时段票）
                             ├─ 放行 ─► ③ 执行
                             └─ 拒绝 ─► 如实报缺（**绝不静默换道**）
   │
   ▼
⑤ 审计账本（append-only）
   每次调用落一行：谁调的、调的哪位、成没成、耗时多少、用的哪把钥的指纹
```

## 二、四条硬约束（写在代码里，不是写在文档里）

### 1. 只有一个门

所有能力调用都走 `run_task`。想写生产、想出网、想花钱，**只能从这里进**。
绕过它直接调模块函数 = 违规，且会被审计层发现（账本里没有那条记录，却真动了东西）。

### 2. 门自己知道"这一位要不要票"

每个能力位在注册表里带 `safe` 标记：

- `safe=true`（262 位）：只读、不出网、不改状态 → 直接放行；
- `safe=false`（79 位）：会写盘 / 花钱 / 把数据发到外部 → **必须由人发一张时段授权票**。

票是**人**在终端发的（`auth grant --scope <名> --ttl <秒>`），**AI 无权给自己发票**，
也**不许改策略文件**来绕过。

### 3. 拒绝必须是"带原因的拒绝"

被门挡下时，回执里必须有：缺哪个作用域、怎么发这张票、上游原话是什么。
**"安静"和"坏了"和"被拒"是三种状态**，不许合并成一句"失败了"。

### 4. 点名车道不许静默换道

当调用方明确点名"就走这个模型/这条车道"时，如果它不可用，必须**如实报错**，
不许偷偷换到另一个模型顶上 —— 否则你问的是"她"，答你的却是别人。

> 这一条有真实血账：曾经因为静默换道，问"自我介绍"答出了别家模型的名字。

## 三、能力位是怎么组织的

```
caps_registry（唯一真源）
├── 341 位 × 30 域
├── 每位：name / domain / desc / handler / safe / requires_params
├── 分型：只读（直接跑） / 写口（过票） / 未实现（只有名字，调用如实报 unknown）
└── 派生：图鉴、触手库、绑定账、授权表、本仓库的 capabilities.json
```

**唯一真源原则**：本仓库的 `data/capabilities.json` 是**从注册表现读生成**的，
不是手抄的 —— 手抄的表一定会和代码漂移，而漂移过的表比没有表更危险。

## 四、一次真实调用的完整回执长什么样

只读位（`codex_status`）：

```json
{
  "gate": "run_task",
  "kind": "codex_status",
  "status": "ok",
  "stamp": true,
  "denied": false,
  "result": {"ok": true, "running": false, "concurrency": 1, "...": "..."}
}
```

写口位缺票（`llm_chat`）：

```json
{
  "gate": "run_task",
  "kind": "llm_chat",
  "status": "denied",
  "denied": true,
  "reason": "需要人工授权（external_llm）：把当前任务数据发送到外部大模型服务",
  "missing_scopes": ["external_llm"],
  "how_to_grant": ["终端运行: python -m gbt_allinone auth grant --scope external_llm --ttl 600"]
}
```

> 注意：**被拒也是"有读数的"**。回执告诉你缺什么、怎么补，而不是一句"失败"。

## 五、为什么这套结构值得开源

| 常见做法 | 这里怎么做 |
|---|---|
| 模型给建议，代码各自调工具 | 模型给**落点**，代码只有一个门 |
| 权限散落在各个模块 | 权限是**注册表上的一个字段** |
| 出事了翻日志猜 | 账本 append-only，逐条可回溯 |
| 不允许的动作靠"提示词求它别做" | 靠**门**：AI 在结构上做不到 |

一句话：**安全不该靠模型自觉，该靠结构。**
