# 原生视觉实时链路（默认主流）

> 主人令 2026-11-07：**万能插直接看图片/视频并回传大模型看**，不是截图后转文字再操作；
> 原生能力是**脑·眼·手同步的实时执行链路**。
>
> 机器策略源：`state/vision-policy.json`（唯一口径，改口径先改它）
> 机器判据：`tools/codex-scripts/native-vision-policy-check.py`

## 一句话

不是「截一张图 → 转成文字 → 模型猜 → 盲点一下」，
而是「**采集不停 → 原生层看 → 帧原样给模型 → 动作 → 下一帧帧差校验**」，眼、脑、手在同一拍里。

## 默认链路（五段，缺一段就是降级）

| 段 | 名字 | 做什么 |
|---|---|---|
| ① | `continuous_capture` | 持续抓帧（采集线程不停），不是「截一张、进程退出」 |
| ② | `native_observe` | 原生层同时给：UIA 控件树 + Windows OCR 文字 + 视觉块（坐标/密度） |
| ③ | `model_sees_frames_directly` | 帧或视频片段**原样**交给多模态模型看；不先转成 OCR 文本再让模型猜 |
| ④ | `action_via_omni_plug` | 动作只走万能插（`input_click / input_type / input_keys`），授权与审计在门里 |
| ⑤ | `frame_diff_verify` | 动作后立刻取下一帧，用帧差/节点集合确认「真变了」；没变就如实说没动成 |

## 入口速查

| 要什么 | 入口 |
|---|---|
| 一次原生观察（窗口 + 控件 + 文字 + 视觉块 + 截图） | `omni_observe` / `vision_scene` |
| 只看画面结构（零权重） | `vision_blocks` |
| 找控件 / 找文字坐标 | `omni_locate` / `vision_ground` / `omni_ocr` |
| 动手 | `input_click` / `input_type` / `input_keys` |
| 动完校验 | `vision_diff`（帧差） |
| 四步闭环（看→判→动→验） | `vision_loop`（`look / think / act / verify / loop`） |
| 连续伺服（采集线程 + 小步闭环） | `body_realtime`（`status / servo`） |

## 硬规矩

1. **新鲜度 400 ms**：`vision_loop.STALE_MS = 400`。观测超过 400 ms 就不许动手；
   取不到新鲜帧就拒动，不许拿旧画面操作。
2. **动作后必须验**，且只认三态：`按预期生效` / `没动成` / `变了但非预期`。
   只有「按预期生效」能算成功。
3. **降级必须标**：原生层不可用时才允许单帧兜底，回执必须带 `degraded=true`，
   并写清缺的是 UIA、OCR 还是采集。
4. **单帧不许叫实时**：实时 = 动作期间采集不停 + 每步由新帧反馈驱动。
5. **不许拿模型描述当观测**：模型可以看帧、可以决策，但「看到的坐标」必须来自原生层，
   或来自模型对帧的直接判读并标明来源；不许把文字转述当像素证据。
6. **不许静默退回截图串行**：执行器或能力不可用就停下，说清哪一环缺，再问主人。
7. **视频按时间序抽帧，不转文字**：一轮最多 **4 帧**、合计 **≤ 6 MB**，帧原样送模型；
   只送了前 N 帧就标 `degraded=true`，`why_degraded` 写清「前 N/M 帧」，**不许**说整段视频都看过了。
8. **帧必须有地址**：`see` 的帧在内存 `image_base64` 里，万能插取帧时落一份有界缓存
   （`state/vision/frames/obs-*`，保留最近 200 帧）并回传 `path` —— 否则按路径取帧的调用方
   （对话层 / 视觉链）只能拿到 `fmt/size`，等于没帧。
9. **已经取到帧就不再让 pulse 重复决策**：看屏成功后跳过 `tactile pulse` / `method lane`，
   不然「看看屏幕」会被判成 `body_eye`（不在只读白名单）回一句 denied，帧永远到不了模型。
10. **推理型模型空正文要重试一次并如实报错**：实测 `content=null` + `finish_reason=length`
   + `reasoning_tokens≈535` = 预算全花在思考上。加一次预算重试；仍无正文就报
   「模型把 token 全花在思考上」，**不许**把思考内容当回答。
11. **问「屏幕上有什么」= 要一帧给模型看**（只读取帧，隐私门照旧）；问「你会看屏幕吗」是在问
   能力，**仍不动手**。两者只靠词面分开（`_ASK_SCREEN_RX` / `_ASK_ABILITY_RX`），不做语义猜测。

## 和传统跑法的区别

| 传统跑法（禁止当默认） | 原生实时链路（默认） |
|---|---|
| 截一张图 → 子进程退出 → 再点 | 采集线程持续跑，动作期间不停 |
| 把画面转成一段文字描述 | 帧原样给模型看，文字只做定位补充 |
| 点完就当成功 | 下一帧帧差校验，没变就报没动成 |
| 「截图 → 推理 → 盲点」三步断点 | 眼→脑→手→验同一拍闭环 |

## 验收

```powershell
.\pyembed\python.exe tools\codex-scripts\native-vision-policy-check.py
```

必须全绿（PASS）。它检查：策略文件字段、AGENTS 硬口径、`vision_loop` / `body_realtime` 是否在册、
`STALE_MS` 是否仍为 400、单帧看屏是否已标 `single_frame_fallback`；
对话层声明 `done` 时，还会核对 `console-server.py` 里**帧直送模型 + 降级标记**的代码证据
（`_image_data_url` / `image_url` / `image_path=_screen_path` / `_mark_frame_degraded` / `why_degraded`），
只改状态不接线会被当场判红。
