# 微型投影仪：买与装（给 iPhone 用）

> ⚠️ **2026-10-27 主人令：不买设备。** 本文件仅作参数参考，**不要按它花钱**。
> 零成本方案见 `docs/28-free-projection.md`（屏幕+透镜 / 拆旧 LCD + LED / 已有大屏投屏）。


> 2026-10-27 ｜ 前提：iPhone **不能**内置投影光机，只能外接。
> 这份讲三件事：**怎么接、买什么、到货怎么验收**。

## 一、三种接法（按省事程度）

| 接法 | 需要 | 优点 | 缺点 |
|---|---|---|---|
| **A. AirPlay 直投** | 投影仪自带 AirPlay（或 Apple TV） | 一根线都不用 | 贵；延迟 0.2–1s；必须同 WiFi |
| **B. 无线投屏器** | 投影仪（任意）+ HDMI 投屏棒（如无线同屏器） | 便宜；老投影也能用 | 多一个设备，多一层延迟 |
| **C. 有线 HDMI** | 投影仪 + Lightning/USB-C 转 HDMI 转接头 | **最稳、零延迟、不掉线** | 拖一根线 |

**给演示用，我推荐 C**：讲 PPT / 放视频，稳定比无线重要。
**给看电影，推荐 A**：躺着看，不接线。

## 二、买之前只看四个数（其它都是营销）

| 参数 | 怎么看 | 及格线 | 说明 |
|---|---|---|---|
| **亮度** | 认 **ANSI 流明**，不认"光源流明""XX 流明" | 演示 ≥300 ANSI；观影 ≥500 ANSI | 标"5000 流明"却只写光源的，实际可能只有 150 ANSI |
| **原生分辨率** | 认 **原生 720p / 1080p**，不认"支持 4K 解码" | 原生 720p 起 | "支持 4K"只是能解，投出来还是 720p |
| **投射比** | 1.2:1 常见 | 1.2:1 或更小 | 1.2:1 ⇒ 投 60 吋需 1.6 m，80 吋需 2.1 m |
| **接口** | 有没有 HDMI（含 MHL/ARC）+ 是否支持 AirPlay | **必须有 HDMI** | 只有 USB 的不要买，iPhone 接不进 |

## 三、三档预算（够用的钱花在哪）

| 档 | 价位 | 典型规格 | 适合 |
|---|---|---|---|
| 入门 | ¥300–500 | 480p–720p · 150–250 ANSI · HDMI | **暗房间**投 40–60 吋，看片够 |
| 主力 | ¥800–1500 | 1080p · 400–600 ANSI · 有时带安卓系统 | 演示 + 观影，小会议室可用 |
| 进阶 | ¥2000+ | 1080p 激光 · 700+ ANSI · 低噪音 | 白天拉窗帘也能看 |

**我的建议**：先买 ¥800–1500 档的 1080p + 400 ANSI 以上 + 有 HDMI。
理由：我们的片子是 **1920×1080**，投影仪原生分辨率不匹配就白瞎了高清字幕。

## 四、iPhone 这一侧要准备什么

```bash
# 内容：演示片（1080p 横屏 + 硬字幕 + 旁白）
gbt deck --spec deck.json --images assets/ --script --mp4 --narration-audio --burn-subs --review

# 验收：自动八项
gbt deckcheck <目录> --expect-audio --expect-subs

# 播放：原生播放器起片（AirPlay 按钮在里面）
gbt cinema <目录>/deck.mp4

# 自检：当前能投什么、不能投什么
gbt project
```

有线 HDMI：插上即镜像，无需任何设置。
无线 AirPlay：`控制中心 → 屏幕镜像 → 选投影仪`（这一步只能人手点，系统不开放 API）。

## 五、到货验收（10 分钟，别等用时才发现）

| # | 检查 | 合格标准 |
|---|---|---|
| 1 | 白场 | 纯白画面四角不发黄、不偏色 |
| 2 | 对焦 | 四角都能对清（只有中心清 = 镜头差） |
| 3 | 亮度 | 白天拉窗帘能看清字幕 |
| 4 | 分辨率 | 放 `deck.mp4`，小字（字幕）边缘不糊 |
| 5 | 延迟 | 镜像鼠标指针，肉眼判断 < 0.3 s |
| 6 | 风扇噪音 | 安静房间听不到明显嗡声（< 30 dB） |
| 7 | 过热 | 连续 1 小时不降亮度、不花屏 |
| 8 | 梯形校正 | 侧投能校正成正矩形（自动校正即可） |

任何一项不过，7 天内退货 —— **别想着"凑合用"**，投影的短板会在演示当天暴露。

## 六、一句话

**这不是"安装"，是"外接"**：iPhone 出画面，投影仪出光。
买之前只记四个数：**ANSI 流明、原生分辨率、投射比、有没有 HDMI**。
