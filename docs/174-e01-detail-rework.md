## 二、这轮修掉的细节
1. **cut3 老船夫镜头**

   - 用 SVD 生成 **4 帧 / 256×448 / 2 步** 真运动（原版只有 2 帧/128×256）；
   - 成片 t=7s 可见老船夫全角站在船头。
2. **台词/字幕**
   - 从 `渡口-script.json` 取 E01-01 覆盖的两句：
     - 6.00s 老周：「上船喽——过河的抓紧，雾要变天。」
     - 10.00s 胡二爷：「等等二爷我！这雾天赶船，命都得跑掉半条。」
   - Hanhan zh-TW PowerShell SAPI 进程内合成，非 Python 子进程；
   - 3 条字幕，最长 16 字，白字黑边，底部；
   - 环境音 + 人声固定增益混音，不动态 loudnorm。
3. **音频时长/响度**
   - E01-01-audio.wav：15.000s / pcm_s16le / 44.1kHz / mono；
   - I=-21.7 LUFS，true peak=-1.5 dBFS。
