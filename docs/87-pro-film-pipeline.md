# 87 · 专业成片步骤（项目制设计，不是套模板）

> 主人令：「每一个细节必须按照专业成片步骤来实现；所有东西都是设计出来的，不是规定出来的。」
> 本页是**方法**：每一步都给出“为什么这样设计”，而不是固定参数表。具体项目见 `projects/<片名>/design.md`。

## 一、先定“这部片是什么”，再谈参数
专业流程不是先跑图，而是先回答 7 个问题：

1. **Logline**：一句话故事（谁、要什么、阻力和代价）。
2. **观看场景**：竖屏手机 / 首屏 3 秒 / 有无声音；决定景别和字幕。
3. **视觉母题**：一个可重复的视觉意象（例：雨、玻璃、手机冷光），不是“好看就行”。
4. **色彩策略**：冷/暖各代表什么；谁在冷里、谁在暖里；转折时怎么变。
5. **镜头语言**：为什么这个镜头用近景/特写/空镜；为什么推、为什么停。
6. **声音策略**：环境声、静默、旁白、音乐各承担什么；不是全程铺 BGM。
7. **交付规格**：画幅、帧率、时长、字幕、响度、片头片尾；由发行场景决定。

## 二、本项目（夜雨 / NIGHT RAIN）的设计
| 阶段 | 设计 | 理由 |
|---|---|---|
| 格式 | 1080×1920，24/30fps，约 30s | 竖屏首屏；短、狠、留钩子 |
| 视觉母题 | 雨夜玻璃 + 手机冷光 + 钨丝灯暖光 | 冷=隔阂，暖=回忆；同框对冲 |
| 镜头 1 | 雨窗特写，静置 3s，无旁白 | 先让观众“听见”雨，建立空间 |
| 镜头 2 | 中景，男子坐沙发，缓慢推近 | 不急着给脸；先给距离 |
| 镜头 3 | 手机插入特写，冷光打脸 | 信息点；光的方向改变情绪 |
| 镜头 4 | 近景，侧光，雨影在脸上移动 | 让“雨”参与表演，不靠台词 |
| 镜头 5 | 空镜走廊，门缝暖光，留 2s | 不解释结局；把问题留给下一集 |
| 声音 | 雨声铺底；手机震动；旁白只在 2/4；结尾静默 | 声音有层次，不靠配乐硬推 |
| 字幕 | 只压旁白，不压环境声；片尾留标题/署名 | 竖屏可读性 + 作者性 |

> 这些是**这部片的选择**，不是全局规定。下一部片会重新设计；参数跟着故事走。

## 三、制作流水线（本地）
1. **Pre-production**：logline → 分镜表（镜号/景别/机位/运动/光/声/时长/戏剧功能）。
2. **Look development**：ComfyUI 本地文生图，先出 3-5 张 look frame；只选与母题一致的。
3. **Keyframe**：固定 seed + prompt + 构图；需要构图锁定时用 **ControlNet Canny** 从参考图提取边缘，保留姿态/构图。
4. **Refine**：图生图/局部重绘（下一步）；只改需要改的区域，不整张重抽。
5. **Upscale**：Real-ESRGAN 4x 本地放大，再裁 1080×1920；不用云。
6. **Editorial**：按分镜时长装配；J/L cut、留白、转场由节奏决定。
7. **Sound**：雨声/手机/环境先铺，再上旁白；旁白不盖环境；结尾可静默。
8. **Subtitles**：与旁白同源，逐镜校对；不机翻。
9. **Color**：统一冷/暖策略；不套滤镜，按镜头设计调。
10. **QC**：每项按项目验收表（时长、画幅、音轨、字幕、响度、首屏、连续性、版权/署名）。
