## 0. 开工读数（每次接到「上 AI」的活，先答四问）

**不要一听到「用 AI 搞一下」就开干。** 入门课第一周就在讲这个：AI 不是万能锤，
它是**有明确适用面**的工具。派错活的代价不是"没效果"，是**白烧一遍算力和信任**。

先答四问，缺一不可：

1. **有没有数据？**（历史记录 / 样本 / 语料 / 规则文档）
   —— 没有数据的"AI 需求"是幻觉需求。数据是燃料，不是配角。
2. **有没有清晰的目标？**（对/错、贵/贱、像/不像、走/停）
   —— 目标越模糊，越不是 AI 活，是"人的判断活"。
3. **反馈回路够短吗？**（单轮秒回 vs 几个月才知道对不对）
   —— 回路短 = 技术可行；回路长 = 先做**小试点**，别全押。
4. **错了的代价能回滚吗？**（草稿 vs 对外交付 vs 不可逆操作）
   —— 不可回滚的一律先进**镜像**（生产面红线第一条：镜像多维度是唯一试验场）。

**判定出口**：
- 四问全过 → **派单**（进 §3）
- 缺数据 → 先补数据（`recon` / `devour` 域）
- 回路太长 → 缩小试点，先做**人机协同**版本
- 代价不可回滚 → 镜像里先跑，过了镜像才谈生产

## 1. 术语地图（四个词治住 90% 的糊涂账）

入门课第一周花整整一周讲术语，因为**术语乱 = 派单乱**。指挥官只需要四个词：

### 1.1 AI ⊃ ML ⊃ DL（包含关系，不是并列）

| 词 | 是什么 | 指挥官怎么用 |
|---|---|---|
| **AI** | 目标：让机器干"要人脑"的活 | 谈战略、谈方向时用 |
| **ML**（机器学习） | 手段：从数据里**学规则**，而不是人写死规则 | 谈"要不要喂数据"时用 |
| **DL**（深度学习） | 当下最猛的 ML 手段：多层神经网络 | 谈"选什么架构"时用（→ `gbt-dl-101`） |

**一句话判据**：规则能写清楚 → 写代码就行（别上 AI）；
规则写不清楚但**例子多** → 这才是 ML 的地盘。

### 1.2 数据科学 vs 机器学习（两条出口，别混）

| | 数据科学（DS） | 机器学习（ML） |
|---|---|---|
| 出口 | **洞察**：给人看，帮人做决策 | **动作**：给系统用，自动决策 |
| 例 | 「上季度流失集中在 X 类用户」 | 「检测到流失风险 → 自动触发留客动作」 |
| 我们仓 | `data` 域（audit_query 等） | 能力位 + 产线触手 |

同一批数据可以两条出口都走；**混用 = 报告写成动作、动作写成报告**，两头不讨好。

### 1.3 训练 vs 推理（贵的那半和便宜的那半）

- **训练** = 学：贵、慢、一次性或周期性（GPU 拉满）
- **推理** = 用：便宜、快、常驻（指挥官的日常 99% 在这侧）

指挥官的资源直觉：**训练是项目，推理是运营。** 别拿运营的预算去干项目的事，反之亦然。

### 1.4 模型 ≠ 产品（引擎 vs 整车）

- 模型 = 引擎（`gbt-potato-v8` 是模型位）
- 产品 = 整车（`run_task` 万能插 + 能力位 + 验收标准才是整车）

**最贵的错**：以为"模型好 = 产品好"。产品好 = 模型 × 数据管道 × 验收闸 × 交付面。
（我们的实战证据：序章成片不是"模型生得好"，是**装配线 + 审计标准 + 五条 ffmpeg bug 修复**一起到位的。）

## 2. 能力边界表（今天能派 / 今天别派）

入门课第二/四周反复强调：「知道 AI 能做什么」和「知道 AI 不能做什么」一样重要。

### 能派（窄 AI 的强项）

| 类型 | 判据 | 我们的实例 |
|---|---|---|
| 单域重复判断 | 同一判断重复上千次 | 抓取过滤、字幕对齐 |
| 分类 / 打分 / 抽取 | 有明确目标维度 | 素材分镜匹配 |
| 模式识别（海量数据） | 人看不完的量 | 全仓扫描、台账核对 |
| 生成**初稿** | 文 / 图 / 音 / 视频草稿 | filmkit 三镜试片 |
| 不知疲倦的批处理 | 24h 重复 | 负载闸 `--batch` 分批跑 |

### 别派（今天仍不稳，必须加人闸）

| 类型 | 为什么 | 兜底 |
|---|---|---|
| 跨域常识推理 | 会一本正经地编 | 人验 + 台账留痕 |
| 小样本新领域 | 冷启动，没燃料 | 先收数据，别硬上 |
| **无核验**直接对外交付 | 错就是事故 | 出货前亲眼验收（我们的铁律） |
| 需要担责的最终决策 | 责任不能外包给模型 | 指挥官签字 |

**指挥官总判据**：**「这活错了，代价能不能被一次性验收挡下来？」**
能 → 派；不能 → 缩小范围、加人闸、或先镜像。

## 3. 派单流程（书里的「ML 项目工作流」→ 我们的派单制）

入门课讲的经典 ML 项目工作流是四步：**收集数据 → 训练模型 → 部署 → 监控**。
指挥官版把这四步**落到本仓的实物上**：

| 书里的步骤 | 指挥官动作 | 本仓落点 |
|---|---|---|
| 收集数据 | 抓取 + 消化 | `recon` / `devour` 域；skills 装外部能力 |
| 训练 / 选模型 | 不一定要训——**优先选现成** | LLM 链（`cloud_llm._KEY_CHAIN`，agnes 首位契约） |
| 部署 | 走**唯一入口** | `run_task` 万能插（写生产/镜像**一律**走它，绕过去就是违规） |
| 监控 | 台账 + 回归 | `tentacle_bind` ledger（追加式）；回归走四元组印章 |

**关键差别（这是我们的护城河）**：
书里的流程是**一次性项目**——做完交付就散场；
我们的流程是**常驻触手**——每个能力位自带绑定、自带台账、自带验收。
（实测读数：触手绑定 276 条 · 断连 0 · 穿透率 97.1%。）

## 4. 机会识别（哪块活先上 AI）

入门课第三周给了「选择 AI 项目」的排序法。指挥官版按 ROI 三条，**从上往下**：

1. **有把握、影响小的**先做 —— 快速见效，建立信任（不是技术选型，是组织选型）
2. **重复度高、人力贵的**先做 —— ROI 最直观
3. **数据已经躺在盘上的**先做 —— 零前置采集成本

**反面清单（血的教训）**：
- ❌ 一上来啃「全自动全流程」→ 半成品不上线（生产只收成品）
- ❌ 只为"酷"选型 → 炫技不是产能
- ❌ 跳过试点直接规模化 → 生产面红线第二条

## 5. 买 / 造 / 派 —— 三选一，别倒着走

入门课第二/三周的核心商业判断：**自建 vs 买**。我们多一档，是三选一：

| 路线 | 何时用 | 本仓对应 | 门槛 |
|---|---|---|---|
| **派**（组装触手） | 任务可拆、要落产线 | 能力位 + n8n 桥（178 位 · 30 域） | 最低 |
| **买**（调 API） | 通用能力强、自己无数据 | 云 LLM 链（agnes / deepseek / kimi / …） | 低（按量花钱） |
| **造**（自训） | **有独家数据**、通用模型覆盖不到 | potato 位（8111 假端点 → GPU 到位即真脑） | 最高（数据+算力+评估） |

**指挥官默认顺序：先派 → 不够再买 → 最后才造。**
倒着走的典型翻车：还没数据就想训模型（没燃料）；还没跑通就在想自建（重复造轮子）。

**纪律**：本地非标端口一律走可信会话判定（`allow_private=_policy.is_trusted()`）；
假端点必须**如实标注**（8111 现在就是假端点——诚实是读数纪律，不是选项）。

## 6. 组织面（课的「AI 团队角色」→ 我们的触手分工）

书里 AI 团队的角色：ML 工程师 / 数据工程师 / 数据科学家 / 产品经理 / 研究员。
在我们的仓里，**对应的不是人，是触手簇**：

| 书的角色 | 我们的触手簇 | 干什么 |
|---|---|---|
| ML 工程师 | `creation` / `video` / filmkit 产线 | 把模型变成产物 |
| 数据工程师 | `data` / `recon` | 管道与读数 |
| 数据科学家 | `data` / `finance` | 洞察出口 |
| 产品经理 | **三板块总监令**（审计标准） | 定验收线 |
| 运维 / 平台 | `automation` / `tentacle` / 网关 | 常驻与连通 |
| 研究员 | `devour` / `brain` | 蒸馏与消化 |

**指挥官职责**：分派到触手 + 看读数验收。
**不亲自下场干每一环**——否则又变回"手工作坊"，触手白长。

## 7. 社会面红线（课的「AI 与社会」→ 我们的政策）

入门课第四周讲四个议题，我们逐条**有落地**（不是口号）：

| 议题 | 我们的落地 |
|---|---|
| 偏见 / 歧视 | 数据来源留痕（ledger 追加式）；不许把偏见当事实输出 |
| 对抗攻击（adversarial） | `security` 域 + redteam + 自检链；**外部数据 = 不可信数据**（提示注入防护） |
| 恶意使用 | 红线：不代持账号 / 不批量注册 / 不改第三方平台数据（主人 9·23 定） |
| 就业影响 | 我们的立场（承 Elements of AI）：**赋能，不是威胁**——触手干活，指挥官决策 |

**两条铁律绑死**：
- **AI 永远无权给自己发授权**——缺授权就如实报缺什么，不许找旁路。
- **未验 = 未验**——不假装查过；mock 必须标 mock。
