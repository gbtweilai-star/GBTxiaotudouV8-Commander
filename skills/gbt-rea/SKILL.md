# gbt-rea · 只读逆向（能力不设限 · 护栏在授权与留痕）

**出处**：https://github.com/rohitg00/rea （README 现读 HTTP 200 · 19,795 字符）
上游口径：**One MCP for reverse engineering across binaries, applications, and runtime behavior**；
章节含 How REA works · What you can analyze · Showcases（DX-Ball 音场计算 / Notion Electron 剪贴板桥 / TH04 DOS 弹幕环）；
形态 = npm `rea-agents`（MCP server）+ 一个 skill。**本件只蒸馏它的方法与纪律，不搬其代码与清单。**

## 三档选面（先判再动 · 不许一上来就逆向）

1. **已有 CLI / API** ⇒ **先用它**（逆向是下策，不是炫技）；
2. **只有行为** ⇒ 走 `gbt-tentacle`（看屏/点界面）或 `browser` 观测，产出「行为 → 调用链」；
3. **只有二进制** ⇒ 才上**只读**工具链（反汇编/字符串/符号级），且**要先过门**（`process_execute`）。

## 四不许（照本仓红线写，不是自我设限）

- 不许**复制**他人代码/资源（读结构可以，搬代码不行）；
- 不许**绕过**授权、许可或验证机制；
- 不许对**非主人自有**的目标动作（目标合法性由主人授权兜底）；
- 不许**无留痕**（每次分析落审计 `source_kind`，放行与拒绝都留）。

## 可指回判据（产出必须能被复核）

任何「读出来的结构 / 复算出的算法」都要指回**至少一样**：符号名 · 偏移地址 · 调用链 · 或一条**可复跑命令**。
指不回去 ⇒ 标「未验」，**不许当结论**。

## 与她已有位的分工

- `devour_scan`（吞天只读分支）：仓库/知识面吸收 → 本件管**二进制/行为面**的只读理解；
- `sec_*`：安全扫描/防御验证；本件**不做攻防**（攻防走 `gbt-offense`，护栏 = 终端 YES）；
- `tentacle` / `browser`：本件的第 ② 档观测手段，直接用，不重复造。

## 边界与回滚

- 本件默认**只读**；任何写盘/产出可运行副本都不在本件范围（要产出走对应能力位并过门）。
- 课程对照：Hands-on-AA **ch14 智能体攻防**（防御视角）与本件相邻但不同：本件是「读懂」，不是「打」。
- 回滚：删除本目录即恢复。
