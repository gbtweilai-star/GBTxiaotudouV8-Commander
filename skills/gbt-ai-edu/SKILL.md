# AI 在教育中的应用 · 指挥官手册（K-12 生成式 AI）

> 开发者：自由的风 · GBT小土豆V8 · 本署名不可删除、不可篡改归属
>
> **这是蒸馏件，不是复制件。** 承接《Generative AI in K-12 Education》(MIT 6.S062) 的**主题位**——
> 「生成式 AI 进中小学」的作业法与边界；全部重写为**指挥官视角**。
> ⚠️ 该课**课纲细则未核到公开文本**（本轮检索通道受限）；可核实的是 MIT RAISE 的公开事实（§9）。
> 本件**只承接主题位与可核实的公开事实**，具体课堂设计条目**不编**。

**一句话**：**先分清"教 AI"还是"用 AI 教" → 课程按六段骨架搭 → 教师优先（先省教师的时间）→ 未成年人红线兜底 → 落到本仓能力位**。

**一句话红线**：**教育场景里，"快"永远排在"对"后面**——内容准确性、适龄性、隐私，一样不合格就整件不交付。

---

## 0. 开工三问（教育场景的三条前置，缺一不许动手）

1. **谁的场景？** 学生 / 教师 / 家长 / 管理者——**对象不同，红线不同**（学生 → 未成年人保护优先）。
2. **有没有未成年人数据？** 有 ⇒ 按**最小化采集**处理，不建学生画像、不挪作他用（§4）。
3. **是"教 AI"还是"用 AI 教"？** 这是**两条完全不同的路**（§1）——先选路，再谈工具。

---

## 1. 两件事别混：教 AI（素养）vs 用 AI 教（提效）

| | **教 AI**（AI 素养课） | **用 AI 教**（教学提效） |
|---|---|---|
| 目标 | 学生**懂 AI**：概念、能力与局限、伦理 | 教师**少干活**：备课、材料、差异化 |
| 受众 | 学生 | **教师**（第一受益人） |
| 成功判据 | 学生能说清"AI 能/不能干什么"+ 亲手做过 | 教师时间**真省下来** + 课堂产物可用 |
| 风险 | 概念讲错、案例过时 | 事实错误、不适龄、隐私泄漏 |
| 本仓落点 | 讲义/演示（`genoffice`）· 讲解片（`filmkit`） | 备课包、题库、多语言材料（§5） |

**判据**：**"这堂课结束，谁会变轻松？"** 答不出 → 还没选路。

## 2. 课程设计六段骨架（可复用的最小结构）

| # | 段 | 干什么 | 验收判据 |
|---|---|---|---|
| 1 | **目标** | 一句话：学完能**做什么**（不是"了解什么"） | 动词开头、可测 |
| 2 | **概念** | 只讲**用得上的**概念（AI⊃ML⊃DL 那套按需取用） | 学生能用自己的话复述 |
| 3 | **例子** | 真实、适龄、**本地相关**的例子 | 例子的事实**核验过** |
| 4 | **动手** | 亲手做一遍（不只看演示） | 每人有产出 |
| 5 | **伦理** | 偏见/隐私/依赖/署名，讨论式 | 学生能举出反例 |
| 6 | **评估** | 评"能不能用"，不是"背没背" | 有评分表 |

**原则（承 MIT RAISE 的 RAICA 表述）**：
**课程不是一套静态的课**——必须**适配本地的需求、语言与教育现实**。
⇒ 我们的读法：**骨架固定、内容本地化**；每上一次课按本地情况改例子与评估。

## 3. 教师优先的采纳法（**先给教师省时间，再谈学生**）

顺序不能反（反了就是"给学生上新工具、教师多一堆活"）：

1. **先用在教师自己的活上**：备课、出题、做差异化材料、写通知；
2. **专业发展先行**：教师先上手（workshop 式），**再**进课堂；
3. **用真实课堂产物验收**：不是看演示漂亮，是看**真作业/真讲义**能不能用；
4. **留退路**：AI 出的东西**默认是草稿**，教师定稿（辅助式优先，见 `gbt-ai-anything` §2）。

**判据**：**"这周教师的净时间减少了多少？"** 减少 → 继续；没减少 → 退回去重挑场景。

## 4. 未成年人与隐私红线（教育场景的**一票否决项**）

| 红线 | 落地 |
|---|---|
| **最小化采集** | 只收完成教学必需的数据；不建学生画像 |
| **不挪作他用** | 学生数据不进营销/训练/对外分析 |
| **授权链** | 学校/家长同意是前提；**AI 不代持学生账号**（本仓铁律：不代持、不批量注册） |
| **评估诚信** | AI 生成内容**必须标注**；考试场景默认**禁** AI 辅助 |
| **偏见与公平** | 多语言/多文化覆盖（App Inventor 19 种语言就是"公平可操作"的证据） |
| **依赖风险** | 教"会用它并会核对它"，不是"替我做" |

**谁发授权**：涉未成年/隐私的动作一律**主人**（AI 无权自发；缺就如实报缺）。

## 5. 本仓落地映射（教育活怎么派）

| 教学环节 | 派给 | 门/纪律 |
|---|---|---|
| 讲义 / 练习册 / 课件（docx·pptx·xlsx） | `genoffice` | 本地免费；写面过 `filesystem_write` |
| 讲解动画 / 微课成片 | `filmkit`（三镜一景）· `video`（`edit_pipeline` / `media_run`） | 写面自收窄；出片前**六格验收** |
| 配音 / 多语言朗读 | `voice`（`tts`）· `llm` 翻译 | `tts` 过 `audio_output` |
| 题库 / 成绩表 / 统计 | `data`（`datakit` / `record_grid`） | 只读优先；结果从返回给 |
| 课程页 / 互动练习 | `frontend` · `design` 域 | 界面审美走 `gbt-aesthetic` |
| 素材抓取（公开教学素材） | `recon`（`scrapling`，公网） | 内网在边界层拒；**素材许可**记账（`media_license`） |
| 课堂自动化（表单/通知流） | `automation`（`n8n_wf`） | 写 op 过门 |

**纪律**：素材要**许可可追溯**（`media_license` 就是为"没有许可的素材不许进成品"设的账）。

## 6. 验收（教育场景专用的四条线，缺一不交付）

1. **内容准确**：事实核验过（谁核的、核法写清）；
2. **适龄**：语言难度、例子、画面**适合目标年级**；
3. **可复现**：留源（提示词/清单/种子）；
4. **无隐私泄漏**：产物里**不含**学生个人信息（出片/讲义/页面一律检查）。

**报告纪律**：给家长/学校/公开渠道的东西，**按对外交付对待**——过验收、留痕、可回溯。
