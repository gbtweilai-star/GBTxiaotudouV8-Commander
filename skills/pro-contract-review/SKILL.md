# 合同审查 · 专业包

## 0. 先判要不要接

| 情形 | 动作 |
|---|---|
| 涉诉/仲裁在办、股权、担保、跨境、知识产权转让、金额 > 约定阈值 | **停**：只做要素提取，结论写「须执业律师」 |
| 标准服务/采购/保密/劳务（金额在阈值内） | 可做全流程 |
| 对方给的是扫描件/图片 | 先 OCR，再让用户确认关键数字（金额/日期/主体） |

> 红线：**不臆造法条**。引用法律必须能指到具体条文；指不到就写「需律师确认」。

## 1. 抽要素（八项，缺一不可）

1. 主体（全称、统一社会信用代码、签约资格）
2. 标的（做什么/交付什么，可验收的定义）
3. 价款与支付（金额、税费、发票、付款节点）
4. 期限（生效、履行、续约、终止）
5. 验收（标准、期限、不验收的后果）
6. 违约（违约金比例、赔偿上限、解除权）
7. 知识产权与保密（归属、许可范围、期限）
8. 争议解决（管辖法院/仲裁机构、适用法律）

缺项不是"没写"，是**风险**：逐项标 `缺失`，并在第 3 步给补写建议。

## 2. 扫红旗（逐条给原文引用）

| # | 红旗 | 为什么危险 |
|---|---|---|
| R1 | 无责任上限 / 无限赔偿 | 一次事故吃掉全部利润 |
| R2 | 单方解除权只给对方 | 你随时被踢出且无补偿 |
| R3 | 自动续约 + 无退出窗口 | 忘记通知就再锁一年 |
| R4 | 付款与"甲方满意"挂钩 | 验收标准主观，等于不付款 |
| R5 | 知识产权全部归对方（含背景技术） | 你的既有资产被一并拿走 |
| R6 | 保密义务无期限 / 单向 | 永久负担，对方却不保密 |
| R7 | 管辖地在对方所在地且涉外 | 维权成本高于标的额 |
| R8 | 不可抗力条款缺失或过窄 | 疫情/断供时仍算你违约 |
| R9 | 转包/分包需对方书面同意但无时限 | 对方拖答复即违约 |
| R10 | 违约金过高（> 合同额 30%）或过低（< 5%） | 过高可能不被支持，过低没有约束力 |

每条必须带：**条款号 + 原文摘录（不超过 60 字）**。没有原文引用的红旗一律删掉 —— 那是猜的。

## 3. 给替代文本（每个红旗一条）

格式：
```
原条款（第 X 条）："……"
风险：R3 自动续约无退出窗口
建议改为："……（可直接粘贴的完整句子）"
理由：一句话说明为什么这样改能消除风险
```

只给建议、不替用户拍板；改写文本要能被直接复制进合同。

## 4. 风险分级（只用三级）

| 级别 | 含义 | 动作 |
|---|---|---|
| 阻断 | 不改就不签 | 必须改，否则建议不签 |
| 议价 | 可谈，谈不下来要留书面记录 | 列出让步底线 |
| 接受 | 行业惯例/影响可控 | 记录即可 |

## 5. 输出：审查备忘录（一页）

```
# 合同审查备忘录
- 文件：<文件名> · 版本：<日期/哈希前 8 位>
- 主体：甲方 / 乙方
- 标的与金额：
- 结论：阻断 N 条 / 议价 M 条 / 接受 K 条
- 是否建议签署：建议签 / 改后签 / 不建议签
- 未覆盖事项（本包没能力判的）：<逐条列>
- 下一步：<谁在什么时间前做什么>
```

## 判据（缺一条就算没做完）

1. 八项要素表齐全，缺项明确标 `缺失`；
2. 每条红旗都有条款号 + 原文摘录；
3. 每条红旗都有一条可直接粘贴的替代文本；
4. 风险等级只用 `阻断/议价/接受` 三值；
5. 结论含「未覆盖事项」，不许把"我没看"写成"没问题"；
6. 触发第 0 节红线的，结论必须出现「须执业律师」四个字。

## 不做

- 不代签、不盖章、不出具法律意见书；
- 不评价对方人品/动机，只评价条款文本；
- 不把"行业都这样"当理由放过阻断项。
