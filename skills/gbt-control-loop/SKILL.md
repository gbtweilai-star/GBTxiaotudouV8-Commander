## 1. 它到底做了什么（架构事实，逐条可复核）

1. **动作是枚举**：`CLICK · TYPE_TEXT · SELECT · SCROLL_UP · SCROLL_DOWN · WAIT · DONE · BLOCKED`
   —— 只有这些；**枚举之外的动作不存在**。
2. **两个头、一次往返**：一次观测同时算「操作」与「目标」；目标是**推测式**问的，只有匹配的那个执行。
   实测收益：浏览器协议调用 **1,092 → 101（−91%）**；中位任务时间 **9.450s → 7.092s（−25%）**；
   个别任务 1.896s（酒店筛选）· 2.798s（打开维基文章）· 7.1s（谷歌机票）。
3. **只为"要文本"的动作叫生成模型**：只有 `TYPE_TEXT` 需要文本，且**文本必须先解析成 JSON 才准输入**
   （宁可 BLOCKED，也不乱打字）。
4. **执行前两查 + DONE 独立验证**：落点动作执行前查**新鲜度**与**遮挡**；**`DONE` 必须独立验证结果**
   （仓库自己的 limitation 原文："A DONE choice still requires independent outcome verification."）。
5. **等待纪律**：输入后等 200ms；其他交互最多两帧或 50ms（不盲等、不空转）。

## 2. 为什么这能突破我们的瓶颈

我们过去的电脑操控是**每步一次大模型**：慢（秒级）、贵、且返回自由文本要再解析 —— 一个 10 步任务
就是 10 次大模型往返。Jev 那条路的本质是**把"决策"从"生成"里拆出来**：

```
慢脑（LLM：定计划、定规则、处理异常）     ← 便宜、可慢，一步算清
   ↓ 下发：目标 + 动作空间 + 当前观测
快脑（类型化决策：枚举 op + 目标 + 置信度） ← 70–500ms 级（官方口径）
   ↓ 置信度低于阈值才回升慢脑
执行器（两查后落点） → 结果进审计链
```
⇒ **省的是往返次数**（它 −91% 的协议调用就是这来的），不是省脑子。

## 3. 我们的落位（`tools/control_loop.py`，已跑通）

| 它 | 我们 |
|---|---|
| 枚举动作空间 | 同一套 8 个 op（**多一个都没有**）＋我们的门：危险动作**不在空间里** |
| 两个头一次往返 | `fast_policy(obs) -> {op, target_index, confidence}`（一次观测同时出两个头） |
| 仅为文本调生成模型 | `TYPE_TEXT` 才需要文本，且文本来自观测里的 `text_hint`（要解析才用） |
| 两查 | `guard()`：**新鲜度**（`age_ms` 超 1500 拒绝）· **遮挡**（`occluded` 拒绝）· 目标必须真在观测里 |
| DONE 独立验证 | `DONE` 无 `evidence` 一律拒（**不许自己宣布成功** —— 这正是我们的"假绿"防线） |
| 低置信度 | `< 0.60` 升级慢脑；**没配慢脑就如实 `BLOCKED`**（不许硬猜） |
| 成本口径 | `Budget`：单次时延上限 + 每分钟调用上限；**记我们自己的账**，不按它的宣传价目表折算 |
| — | **审计链**：每次决策写 `state/control_loop.jsonl`（一次写入不回改 = Raw 层） |

**它不自己动手**：本工具只产出决策与审计；真正的动作仍走既有授权门（`desktop_control` 等作用域），
与"写生产必须走 `run_task`"是同一条纪律。

## 4. 怎么用

```powershell
python tools/control_loop.py selftest          # 判据自检（6 路反向自检，全过才算数）
python tools/control_loop.py demo              # 五个脚本化场景（不碰真实桌面）
python tools/control_loop.py decide --obs <观测.json>   # 单次决策（干跑）
```

**接真机时的下一步**（按顺序，别跳）：① 用现有视觉触手产"带索引元素表"作观测；
② 快脑先用规则/本地小模型；③ 只在 `TYPE_TEXT` 接生成模型；④ 落点前把两查接到真实像素/无障碍树；
⑤ 全部动作过 `desktop_control` 门；⑥ 每次决策进审计链。

## 5. 诚实边界（照抄它的，也加我们的）

- 只在**常见 HTML/ARIA** 上验证过；Shadow DOM / frame / canvas / 上传 / 弹窗**都没验**；
- 基准是**小样本**（一个任务三次重复）⇒ **不许外推**成"通用可靠性"；
- 我们对"电脑操控"的验收标准仍是**亲眼验收**（截图比对 + 独立验证），
  **不因为决策快了就降低验收**；
- 它的性能数字是**它的**；我们的业绩只认我们自己的读数（本仓规矩：读数带印章，跨口径不许比）。
