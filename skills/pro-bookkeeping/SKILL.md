# 记账与对账 · 专业包

## 0. 先划边界

| 能做 | 不能做 |
|---|---|
| 按给定科目表录凭证、对账、出试算平衡与三张表 | 出具审计意见、代办纳税申报 |
| 指出差异并归因 | 替客户决定收入确认/折旧年限等会计政策 |
| 提示"这里可能需要专业判断" | 用"调平"把差额抹掉 |

> 红线：**不许两套账**。同一笔业务只有一个真相；发现两套账立即停手并报告。

## 1. 科目表（先立，后记）

最小集（按需扩展，扩展要写进记忆）：

```
1001 库存现金   1002 银行存款   1122 应收账款   1123 预付账款
1405 库存商品   1601 固定资产   2001 短期借款   2202 应付账款
2211 应付职工薪酬 2221 应交税费  4001 实收资本   4103 本年利润
6001 主营业务收入 6401 主营业务成本 6601 销售费用 6602 管理费用 6603 财务费用
```

判据：**每一笔分录用到的科目都必须在科目表里**；不在就先加科目（并记录为什么加）。

## 2. 录凭证（一条业务一条凭证）

```
日期 | 摘要 | 借：科目 金额 | 贷：科目 金额 | 附件（发票/回单/合同号）
```

三条硬判据：
1. **借贷合计相等**（差 1 分也不许过）；
2. **摘要能独立看懂**（不许写"杂费""其他"）；
3. **有附件**（无票无回单的，标 `待补附件`，不许当作已入账）。

## 3. 日清：流水归因（逐笔，不许抽样）

对每一笔银行/平台流水：

| 状态 | 处理 |
|---|---|
| 匹配到凭证 | 标 `已核`，记凭证号 |
| 有流水无凭证 | 开**差异单**：金额/日期/对方/推测原因/待补材料 |
| 有凭证无流水 | 开差异单：可能是未达账项，记预计到达日 |
| 金额不一致 | 不许改流水，不许改凭证；开差异单，两侧都保留原值 |

判据：`已核 + 差异单 = 流水总笔数`，一条都不许"跳过"。

## 4. 月结（四步，按序）

1. **计提与摊销**：工资、房租、折旧、摊销（写清依据与期间）；
2. **结转成本**：收入与成本配比，口径与上月一致（变了要写原因）；
3. **试算平衡**：全部科目 借方合计 = 贷方合计；差额必须为 **0.00**；
4. **出表**：资产负债表、利润表、现金流量表（直接法），三表勾稽。

三表勾稽判据：
- 资产负债表 `未分配利润` 期末 − 期初 = 利润表 `净利润`（无分红/调整时）；
- 现金流量表 `期末现金` = 资产负债表 `货币资金` 期末；
- 任一条不成立，**先查再出表**，不许带病出表。

## 5. 差异单（唯一允许的"不平"出口）

```
差异单号 | 发现日期 | 金额 | 方向 | 对方 | 现象 | 初步归因 | 待补材料 | 责任人 | 期限
```

判据：超过 `N` 天未闭环的差异单要升级（N 由用户设定，默认 30 天）。

## 6. 权限：三人分离

录入 / 复核 / 批准 三个动作**不许同一个人**全做。做不到就明写「本账未分离职责」，不许假装有内控。

## 判据（缺一条就算没做完）

1. 每张凭证借贷相等；
2. 每笔流水要么 `已核` 要么有差异单，总数对得上；
3. 月末试算平衡差额 = 0.00；
4. 三表勾稽三条全成立；
5. 会计政策变更都有书面原因；
6. 输出的每个数字都能指回凭证号或流水号。

## 不做

- 不"调平"、不轧差、不把差异藏进"其他应收/其他应付"；
- 不代替客户做税务判断；
- 不在没有附件的情况下把支出记为已发生。
