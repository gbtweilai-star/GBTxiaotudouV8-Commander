## 二、抽走的机制（17 点清单里对 §4 有增量的那几条）

来源把它叫 **Terminal Blandness Syndrome（TBS）**：界面"技术上没问题，但没人记得住"。
判别症状它写得很具体：**所有卡片同一个圆角**、`#000` 配 `#fff`、**hover 只是变暗**、
以及**"一眼看出是让 AI 做的"渐变**。

| # | 它的问题（❌ slop） | 它给的方向（✅ fix） | 我们落到哪 |
|---|---|---|---|
| 1 | 纯白 / `#f9fafb` 底 | 暖白底：`#fafafa` / `#f7f7f5` / `#f5f2f0` / `#fbfaf9` | §4 配色 |
| 2 | 全站一个字体（`Inter, sans-serif`） | **display 字体 + 中性正文字体**成对（它点名 PP Neue Montreal / Geist / Söhne / Instrument Serif） | §4 排版 |
| 3 | 大标题没有字距处理 | 48px 以上 display：`letter-spacing: -0.035em` 起 | §4 排版 |
| 4 | 60px 标题用 `line-height:1.5` | display `1.0–1.1`；正文 `1.3–1.5` | §4 排版 |
| 5 | 正文 400/500 | 正文 **300** 配标题 **500–600**（最大优雅反差） | §4 排版 |
| 6 | `rgba(0,0,0,.1)` 中性黑影 | **阴影染色**：暖向 plum `rgba(45,32,50,..)` / rose `rgba(100,63,63,..)`；冷向 blue-gray `rgba(34,42,53,..)` | §4 材质（新增） |
| 7 | 单层 `shadow-lg` | **多层栈**：ring + 短接触 + 中环境 + 长环境 + inset 高光 | §4 材质（新增） |
| 8 | 1px `#e5e7eb` 硬边 | **发丝描边**：主题色 4–10% alpha（下限 `rgba(0,0,0,.06)`） | §4 材质（新增） |
| 9 | 每节 `py-12`/`py-16` | 纵向节距 **80–160px**（`py-24` 起，hero `py-32`，编辑向 `py-40`） | §4 布局（新增） |
| 10 | `transition: all 300ms ease-in-out` | **命名 cubic-bezier** + 按时长分级：按下 75ms / hover 200ms / 揭示 600ms | §5 动效纪律 |
| 11 | hover 只变颜色 | 加 **`:active { transform: scale(0.95) }`** 按下反馈 + 阴影增量 | §5 动效纪律 |
| 12 | 卡片 hover 位移 + 大阴影 | **卡片不动**，改阴影环权重（8%→10% alpha）+ 加深接触阴影 | §5 动效纪律 |
| 13 | 所有元素同一个 `rounded-md` | **圆角架构**三选一：二元（0/pill）· 非对称咬合 · 分元素（pill 按钮 + 12–20px 卡 + 2px chip） | §4 材质（新增） |

**它自己的做法也值得抄**：`de-slopify-audit` 的**输出形态**是"逐点 ❌/✅ + 指向修它的兄弟技能"
（`typography-that-sells` / `soft-gradient-dreamy` / `spatial-rhythm-and-whitespace` /
`motion-and-micro-interactions`）—— 这正是我们 §3 审计器 + §5 索引的分工方式。

## 三、与本件第 1 批的关系（不是替换）

- 第 1 批管**禁令**（什么不许出现），这一批管**手感**（该长成什么样）；
- **两者冲突时以第 1 批为准**：例如第 2 批说"渐变要有氛围"，而第 1 批
  P0-2 禁掉紫→蓝信任渐变 —— **先过禁令，再谈氛围**；
- **品牌优先仍然最高**：这些数值是"没有品牌约束时"的起手值；
  **有品牌资产时，品牌色/字/圆角优先**（照 §0 读数第 5 条）。
