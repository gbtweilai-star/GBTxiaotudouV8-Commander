## 1. 这条线是什么 / 边界

**一句话**：L4「动效与合成」管的是**把时间轴变成画面**——动效怎么做（缓动/时间线/关键帧/滚动联动）、
以及这些动效怎么被**合成为一段成片**（HTML 合成渲染 / React 渲染）。

它与相邻两条线的分界，就一条：

| 线 | 它管什么 | 一句判据 |
|---|---|---|
| **L2 界面实现** | 页面**本身**：结构、组件、布局、能不能跑、结构对不对 | 交付物是**活着的界面**（用户滚动/点击它）。**L2 管"静态就位"，"动起来"那部分归 L4，但 L4 不重新决定版式。** |
| **L4 动效与合成** | **时间轴**：元素随时间怎么变，以及怎么把这些变化**渲成帧序列/视频文件** | 交付物要么是**带时间轴的画面**（网页里的动效层），要么是**一个 mp4/webm**（由代码或 HTML 合成而来，没有拍摄素材）。 |
| **L7 视频与成片** | 已有**素材**的剪辑/字幕/配音/调色/导出（口播、录屏、B-roll） | 起点是**已经存在的媒体**。**L4 的起点是代码或 HTML，不是媒体。** |

**最容易混的两处，先钉死**：

- **L4 出片 ≠ L7 出片。** L4 的 `hyperframes render` / `remotion render` 是"**从合成渲出成片**"；
  L7 的 `chengfeng-export` / `video-use` 是"**把已有素材剪成成片**"。同是 mp4，两条线的起点、工具链、
  授权门都不同，**读数不许互相当证据**。
- **L4 动效知识 ≠ L2 界面能力。** GSAP 那套缓动/时间线/ScrollTrigger 的判断是在 L4 里做的；
  做完交回 L2 的页面去落地。**在 L2 里"顺手调个动画"是常见的越界。**

## 6. 报告层红线

1. **读数先问"这是事实，还是我读错了地方"。**
   同一个命令在不同目录/不同旗标下会给**看起来一样、意义完全不同**的返回。本线已踩四例（§7）。
   报出任何数字前，先回答："这条命令的**落点**是哪、它**默认**读的是谁？"
2. **"能调" ≠ "能用"。**
   `hyperframes --help` 跑通了、`--version` 打出 0.8.60 了 —— 这只证明 **CLI 二进制能启动**，
   **不证明**这台机器出的了片（`doctor` 的 `.ok`、内存、Docker、Chrome 才决定）。
   `remotion-*` 更极端：**12 条原文 241 万字节全在盘上**，但 `require.resolve('remotion')` = `MODULE_NOT_FOUND`
   —— **"原文在盘" 与 "能跑" 是两件事，必须分开报。**
3. **桩 ≠ 能力不存在。**
   `gsap-*` 四条是桩，但 **(a)** GSAP 这门技术没消失，只是本机没 vendored 上游包；
   **(b)** 实现知识**换了个地方存在**（`adapters/gsap*.md`）。
   **报"能力不存在"和报"这一条是桩、真知识在别处"是两个完全不同的结论，不许混。**
4. **不许拿别人的读数当自己的证据。**
   `~\.hyperframes\config.json` 里 `renderSuccessCount: 1` + 一条 `ok:true` 的 `recentRenders` 是**真文件事实**，
   但它是**别人**（更早的会话/子代理）跑出来的。**本件没有验过出片** —— 这两句必须同时说，少一句就是虚报。
   同理：`doctor.ok=false` 本件**未复核**（出网闸），只能标"引自 `gbt-hyperframes` 规程的实测"。
5. **同是 mp4，起点不同就是两条线。**
   L4 出片（从代码/HTML 合成）与 L7 出片（从素材剪辑）**工具链、授权门、失败模式全不同**。
   **不许用 L7 的"能剪"去证明 L4 的"能合成"，反之亦然。**
6. **`exit 0` 不是判据。**
   `doctor --json` 官方写法是**永远 exit 0**，必须读 payload 的 `.ok`。
   `info` 在非项目目录**也会成功**。**报"命令成功了"之前，先确认它成功的含义是什么。**
7. **形态判定必须现读。**
   `state/design_dimension.json` 的 `desc` 字段是**编目描述**，不是形态判定。
   **判形态要 `dir` 一遍**：几个文件、多少字节、有没有 `references/`/`scripts/`。
   本件 §2 的 24 条形态**全部是 `-Recurse` 数出来的**。
