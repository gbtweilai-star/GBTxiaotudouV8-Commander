# gbt-terminology · 术语口径词典（说话不跑偏）

> **口径**：本词典只收**在本仓有强制处**的词 —— 每个词都指到"哪一行/哪个工具在管它"。
> 没有强制处的词不收（那是形容词，不是术语）。**词条按"最容易被念错"排序。**

## 一、架构层

| 术语 | 准确含义 | **最容易念错的样子** | 强制处 |
|---|---|---|---|
| **触手** | 一个**能力位**（`caps_registry.BENIGN_CAPS` 里的一员），是"手"的最小单位 | 把"工具/脚本"都叫触手 | `gbt_allinone/caps_registry.py` · 判据 `test_cap_bind_bidirectional` |
| **万能插** | `run_task` —— **唯一门**。所有写/跑动作都从它进 | 当成"随便调用的入口"，绕过它直连模块 | `gbt_allinone/api.py` · 红线："绕过关卡的成功 = 事故" |
| **绑定**（资产↔触手） | 资产（文件/目录）↔ 产生它的能力位，**双向**：资产能查到触手，能力位也得在触手字典里叫得出 | 只绑一个方向就说"接通了" | `tools/tentacle_bind.py` · `state/asset_bindings.jsonl` |
| **断连** | 只有两种：① 资产缺失 ② 触手不在册 | 把"没绑"也算断连（那是"缺口"，另一个判据） | `tentacle_bind scan`（断连必须 0）· `gaps`（漏绑缺口） |
| **唯一真相**（源↔装） | 仓内 `skills/` 是**源**；`~/.agents/skills/` 是**装**（运行时读的那份）。源为真 | 以为"盘上对"就是"生效了" | `tools/skills_sync.py` · 判据 `test_skills_install_sync` |
| **镜像 / 生产面** | 镜像多维度是**唯一试验场**；生产只收成品、零修改 | 直接把东西写进生产 | AGENTS.md 生产面红线 · `deploy_publish` 作用域 |

## 二、判据层（这一层错一个词就白干）

| 术语 | 准确含义 | **最容易念错的样子** | 强制处 |
|---|---|---|---|
| **判据** | 一句**能红能绿**的机器判定（不是"我觉得行"） | 把"注意事项/原则"当判据 | `gbt_allinone/tests/test_*.py` · 开机自检 23 条 |
| **反向自检** | **故意造一处缺陷，看判据逮不逮得住** | 判据绿了就宣布判据有效 | 每个新判据都要做（本仓惯例） |
| **假绿** | 结论说"好了"，而实际没做/没跑/只验了一部分 | 把"文件存在"当"做成了" | 血账：`memory/2026-09-22-假绿与自伤清单.md` · P002 同型 |
| **口径** | 这个读数**到底在量什么**（同型血账：GitHub 趋势榜实为"近 24h 有推送按总星排"） | 拿存量榜当热点榜；跨解释器/跨 store 比红集 | 探针工作区 README §三 · AGENTS.md 四元组印章 |
| **印章**（四元组） | `(解释器版本, store, 身份, 命令)` 一起记；跨口径须打 `not_comparable` | 换了解释器还直接比红集 | `gbt_allinone.tools.regression_stamp` |
| **未验** | 没跑过就是没跑过 | 把"设计上应该行"说成"已支持" | 全仓口径：**未验 = 未验**；mock 必须标 mock |
| **防复发锁** | 坑册里那条"下次怎么不再犯"的硬约束 | 只写"注意点" | `store/pit_log.json` |
| **封存集**（holdout） | 只在晋升/发布时跑的判据；日常迭代**不许**据其反馈调参 | 拿验收判据当开发反馈（"记住答案"） | `state/holdout.json` · `selfgrowth check` 判据 5 |
| **未实现登记** | "有名字没东西"必须在册：where/missing/reason/**谁有权修**/evidence | 让它无声挂着 | `state/unimplemented.json` · 判据 C |

## 三、本轮新增（Jev/自生长 蒸馏进来的词）

| 术语 | 准确含义 |
|---|---|
| **快脑 / 慢脑** | 快脑＝类型化决策（枚举 op + 目标 + 置信度，毫秒级、便宜）；慢脑＝LLM（定计划/处理异常）；**低置信度才升级** |
| **两查** | 落点前查**新鲜度**（观测过期即拒）与**遮挡**（目标被挡即拒） |
| **DONE 独立验证** | `DONE` 不许自己宣布成功，必须有验证证据 |
| **枚举动作空间** | 动作只有 8 个；**枚举之外的动作不存在**（这是安全第一层，不是限制） |
| **Raw / Wiki / Skill** | Raw＝不可改的执行迹 · Wiki＝长期知识（提案失败**也不回滚**）· Skill＝可执行且**必须能回滚** |
| **三段隔离** | Train（提假设）/ Validation（反驳）/ Test（只对过门版本开放）—— 混用就会"记住答案" |
| **审计链** | 一次写入不回改的追加式记录；**无痕即未发生** |

## 四、用词纪律（三条）

1. **说数字必须带口径**（在量什么 + 什么时候 + 哪个口径）；说不清口径的数字**宁可不报**。
2. **"接通了"= 三处齐 + 双向绑定 + 判据绿**，缺一处只能说"登记了"。
3. **不确定的词不许模糊带过**：写成"⛔未验（缺什么/谁有权给）"，而不是"应该差不多"。
