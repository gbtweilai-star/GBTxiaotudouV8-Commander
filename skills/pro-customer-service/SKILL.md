# 客服与工单 · 专业包

## 1. 先分级（每条会话第一步，不许跳过）

| 级别 | 判定 | 首响目标 | 动作 |
|---|---|---|---|
| P0 | 资金异常、账号被盗、数据泄露、人身安全、法律威胁、媒体曝光 | 15 分钟内 | **立即升级给人**，同时回执"已升级+工单号" |
| P1 | 核心功能不可用、批量影响、已付款未交付 | 30 分钟内 | 定位 + 给临时方案 + 升级 |
| P2 | 单点功能异常、可绕过 | 2 小时 | 定位 + 给方案 |
| P3 | 咨询、建议、文档问题 | 1 个工作日 | 直接答复 |

P0 判据：**升级动作先于解释**。先升级，再问细节。

## 2. 首响模板（三段，不超过 4 行）

```
收到，<复述对方的问题一句话>。
我这边先<正在做的动作>，<时间点>前给你下一步。
如果影响到<具体后果>，请先<止损动作>。
```

判据：首响必须含 **复述 + 动作 + 时间点**；三样缺一不算首响。

## 3. 定位：只问需要的，一次问全

一次性收集（不要挤牙膏）：

1. 账号/订单号（不要密码、不要验证码）
2. 发生时间（精确到分钟）+ 时区
3. 操作步骤（1-2-3）
4. 报错原文/截图
5. 已尝试过的办法

判据：**同一问题不许问第二轮相同信息**。第二轮还缺，说明第一轮没列清单。

## 4. 给方案（三件套）

```
方案：<做什么>
时限：<什么时候完成 / 什么时候再同步>
兜底：<如果方案不成立，退到哪一步>
```

判据：方案不能只有"已反馈/请耐心等待"；必须有一个**可验收的结果**。

## 5. 升级（交接不丢信息）

升级时必须带：分级、已做动作、当前判断、客户情绪、期望、工单号。
判据：接手人**不需要再问客户一遍**。

## 6. 回访与归档

- 解决后 24 小时内回访一次（问"是否恢复"，不问"是否满意"）；
- 归档字段：分级/根因/耗时/是否升级/是否复发；
- 复发两次以上的问题，升级为**产品缺陷**，不是客服问题。

## 7. 禁语表（命中即改写）

| 禁语 | 为什么 | 改成 |
|---|---|---|
| "这是系统问题" | 甩锅，客户不关心谁的问题 | "我这边查到的现象是…，我来处理" |
| "我这边显示正常" | 否定客户体验 | "你那边看到的是…，我们一起对一下" |
| "请你理解" | 要求对方让步 | "给你造成的影响我记下了，补偿口径我去确认" |
| "没办法" | 关闭对话 | "目前能做到的是…，做不到的部分我给你时间点" |
| "稍等"（无时限） | 无限期拖延 | "X 分钟内给你回音" |
| "按规定" | 不解释规则 | 说清规则内容 + 例外通道 |

判据：**禁语命中数 = 0** 才算过。

## 8. 红线

- 不承诺任何未授权的赔付、退款、折扣、延长服务期；
- 不索要密码、验证码、完整卡号；
- 不评价同事、不透露内部系统名与内部编号规则；
- 不删除/修改客户原始描述，引用要原样。

## 判据（缺一条就算没做完）

1. 每条会话有分级（P0-P3）；
2. P0 的升级动作发生在解释之前；
3. 首响三段齐全（复述/动作/时间点）；
4. 方案三件套齐全（方案/时限/兜底）；
5. 禁语命中 0；
6. 未解决的会话有工单号与下次同步时间；
7. 归档含根因，不只含"已解决"。
