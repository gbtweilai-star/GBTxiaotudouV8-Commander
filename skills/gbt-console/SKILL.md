## 一、页面清单（**单一真相**：`console_hub.PAGES`）

> 规矩：**清单只有一份**（`console_hub.PAGES`）；上帝之眼的"眼睛"也读它。
> 血账：`gods_eye` 原来自带 7 页硬清单，而盘上其实有 **20 个独立页** —— 各维护一份必然看不见新增的页。

| 类 | 页面 | 说明 |
|---|---|---|
| 枢纽 | `workbench` · `entry`(index.html) | Bento 自定义工作台 / 总入口 |
| 全景 | `tentacle3d` · `capabilities` | 触手 3D 全景 / 旧能力球 |
| 工作流 | `wf-film` `wf-movie` `wf-music` `wf-short-video` | 每条产线一页（阶段按**真实目录**现读） |
| 执行台 | `console3d` `automation` `structure` `music` `brain` `media-console` | 各自的执行面 |
| 决策台/监控/门面/原型 | `godview` · `health-panel` `task-manager` · `skin-preview` · `v22-prototype` `v22-canvas` | 原有交付件，全部登记在册 |

**「不能遗漏」是机检的**：`run_task('console_hub', {'op':'scan'})`
= 盘上现读（`holo_pet/assets/*/index.html` + 仓根 `*.html`）**双向比对**登记表：
`unregistered`（盘上有而清单无）**必须为 0** —— 那就是盲区；`broken` 是"登记了但还没建"。

## 二、数据只有一个来源（页面不许自己编数）

```
run_task('console_hub', {'op':'pages'})     # 页面登记表（含 workflow/kind/exists/kb）
run_task('console_hub', {'op':'graph'})     # 3D 图：30 域 → 211 能力 → 绑定弧 → 运行脉冲（真台账尾）
run_task('console_hub', {'op':'widgets'})   # Bento 九部件（**每个数带 src**）
run_task('console_hub', {'op':'layout'})    # 布局记忆 get/save
run_task('console_pages', {'op':'render','target':'all'})   # 渲染六页（快照内联，file:// 直开）
```

**数字纪律**：页面上的每个数都来自上面这些 op 的**一次真读数**，并在界面上显示 `源：<哪个文件>`。
判据 `test_console_workspace` C/D 两条盯着它（页面里没有来源标记、或页上数字与现读不一致 ⇒ 红）。

## 三、设计契约（按 `gbt-aesthetic` 定档，改版要走它的重设计协议）

- **读数**：为「主人 + 内部操作者」做的**数据台** + 一页**门面级 3D 全景**；氛围=深空仪器感。
- **品牌三色白皮书冻结**：土豆金 `#F5B041` / 赛博青 `#00E5FF` / 深空紫 `#7C4DFF` —— **不引第四强调色**。
- **三档转盘**：数据台 `变奏4 / 动效3 / 密度6`；3D 全景 `变奏5 / 动效4 / 密度5`。
- **§1.5 血账（本仓实测）**：`数据页绝不整板自转、字必须正` —— "3D 冲击"只花在**签名元素**上。
- **签名元素**（3D 页）= **触手全景球**：中心是 **`run_task` 核心**（唯一门），30 个域从核心长出手臂，
  每条臂上挂着该域的能力位，绑定弧在域内发亮，**运行脉冲沿着臂飞**（真台账事件，不是装饰动画）。
  自检四条：占首屏 ≥1/5 · 有光（自发光 + 地面光晕 + 纵深环）· 删掉有损失 · 换标测试不成立。
- **§3 禁令**：无 indigo 系 · 无 emoji 当图标（一律 SVG 描边 + `currentColor`）· **无编造指标**（每数带 src）·
  无外链图床。**§5 动效纪律**：尊重 `prefers-reduced-motion`（3D 页在该偏好下**默认不自转**）。

## 五、诚实边界（说清没查的，别用"已全面检查"盖过去）

1. **只有暗色一套**：品牌是深空色（白皮书冻结），**没有亮色模式** —— 所以"两模式都测"这条只测了暗色。
2. **M1–M4 人判**（display 字体是否被硬写成 Inter/Roboto、骨架是否照抄模板、配色是否一眼像模板）：
   我按"换标测试"自评过一次（换标不成立：数字是它自己的 211/6479），但**这仍是主观判断**，
   审计器也如实标"未实现"。
3. **3D 是 canvas 2D 手写投影**（不用外链库，离线可跑）：有透视、深度排序、发光与纵深；
   但**不是 WebGL**，没有阴影贴图/后期辉光那一套。
4. **浏览器只测了 headless Chrome**（截图口径）；Firefox/Safari 未测。
5. **`绑定 6479` 是"资产↔触手绑定条数"**（口径写死在页面上），不是"连接速度/吞吐"这类指标。

## 六、血账（这轮踩的，写下来免得重犯）

1. **阶段名写死 ⇒ 假红**：`01-剧本` vs 真实目录 `01-screenplay` 匹配不上，页面把"有产出"报成"暂无产出"。
   ⇒ **阶段一律从真实目录现读**，别名只做显示。
2. **判据抓到自己过期**：注册两个能力位后 209→211，页面还是旧渲染 ⇒ 判据 E 红。
   ⇒ **改了数据源就要重渲染**（`console_pages render` 是流水线的一步，不是一次性动作）。
3. **0 字节占位件混进"近产出/交付物"**：`.gitkeep` 不是产出 ⇒ 一律按 `size > 0` 过滤。
4. **页面清单不能有两份**：gods_eye 的 7 页硬清单 vs 盘上 20 页 ⇒ 眼睛改读 `console_hub.pages`。
5. **`Math.random` 抖位置**：被安全钩子按"弱随机数"点名。虽非加密用途，但改成**确定性抖动**
   （按名字哈希）反而更好 —— **同一份数据每次画同一张图**，签名元素稳定、截图可复现。

## 七、视觉冲击体系（主人令 2026-09-28：「这种视觉冲击效果做出来就好了，每一个页面都需要有视觉感」）

**读数**（按 `gbt-aesthetic` §0）：参考图是一套**同一视觉语言的卡库** ——
深空底 → **一张电影感主视觉** → 小号彩色**类目签** → 大号粗体**标题** → 一两行摘要 → 「阅读文章 →」；
圆角 14–16px、发丝描边、单一强调色，主视觉里有英文技术小字（`SYSTEM MAP 02` 那类）。

**落地成两件**（都在 `console_pages` 渲染产物里，数据仍只来自 `console_hub`）：

| 件 | 是什么 | 你自己看 |
|---|---|---|
| **每页一条 hero 带** | 主视觉 + 类目签 + 大字标题（品牌三色渐变）+ 摘要 + CTA 按钮 | `holo_pet/assets/<页>/index.html` 打开即见 |
| **卡库页 `gallery`** | **全部 21 个页面**排成卡片（参考图那个版式），点卡即开 | [gallery](holo_pet/assets/gallery/index.html) |

**主视觉怎么来的（诚实说）**：参考图里那些 3D 是**模型生成的图**。本机 ComfyUI（966 节点，**CPU**）
能生成但每张要等很久 ⇒ 现在用**程序化主视觉**：确定性 SVG（透视地面 + 地平线 + 分层辉光 +
扫描线 + 暗角 + 几何主体），**六个原型**（`orb` / `racks` / `cubes` / `highway` / `graph` / `wave`）
按页名哈希分配 —— **同名同图**（截图可复现）、**零外部依赖**（无外链图床，过审美禁令）。
想升级成真渲染图：`console_hero.plan_batch([...])` 出批量生图计划（真跑要 `filesystem_write` + ComfyUI）。

**§3 血账（第二轮才修对）**：第一版主视觉**主体太小、画面 80% 是空黑** ⇒ 一眼像"小挂件"，
不是参考图那种**被填满的场景**（签名元素死法①）。修法四条：① 主体放大 2–3 倍；
② 加**透视地面 + 地平线**把空间撑起来；③ 辉光更大更强（光是立体感的一半）；
④ 叠**扫描线 + 暗角**做仪器质感。**这条对任何"加视觉冲击"的活都适用：先问画面填满了没有。**

**纪律不变**：品牌三色**白皮书冻结**（不引第四强调色）· 尊重 `prefers-reduced-motion` ·
数据页**字必须正、整页不许摇** · 每个数字仍带 `源：` · 审计器 **P0 必须 0**（含新卡库页）。
