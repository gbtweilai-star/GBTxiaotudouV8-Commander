## 二、两条真红

### R1 · `edit_pipeline` 默认 op=status 崩（契约违例）—— **已修，复检转绿**

- 症状：`{}` 与 `{"op":"status"}` 都返回 error：`[WinError 2] 系统找不到指定的文件`；`page_scan` 红名单唯一一条。
- 根因：`gbt_allinone/tools/edit_core.py:898` 在 status 分支**无兜底**地 `subprocess.run(["ffmpeg","-version"])`；本机 ffmpeg 不在 PATH（仓内也无 `ffmpeg*.exe`），`FileNotFoundError` 把只读 status 整个炸掉。
- 修法（本目录 `edit_core.py`）：新增 `_bin_ok(name)`，`except (FileNotFoundError, OSError): return False`，status 改用它；**只兜探测，不动执行路径**（真渲染缺 ffmpeg 仍会如实报错，不假装能跑）。
- 复检：`run_task("edit_pipeline", {"op":"status"})` → `ok=true`，`ffmpeg: false`，不再 error。

### R2 · `capability-audit.py` 缺 `_taste_inline`，整器不可运行 —— **第二轮已补齐并转绿**

- 原症状：`tools/codex-scripts/capability-audit.py:75 from _taste_inline import site_root_block`，全仓 `_taste_inline*` **0 文件**；同族缺失还有 `_page_emit` / `_page_text` / `_engine_gate`，共影响 **8 个脚本**。

- **处置（2026-11-01 第二轮）**：按**调用方契约 + 仓内注释 + 已生成页内联产物**重建 4 个模块（逐份在文件头写明"重建件"与依据，不伪造行为），并补 `page-skins.css` / `theme/taste-tokens.css` / `deploy/cloud-10/mesh.json` / `docs/待授权清单一页.md`；同时修正 349 个能力页的 boot 链接深度与 2 处工具真缺陷。
