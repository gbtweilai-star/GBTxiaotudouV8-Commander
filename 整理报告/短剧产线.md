## 一、它替掉了哪些手搓

| 手搓环节 | 现在 |
|---|---|
| 剧本拆镜、数时长 | 复用 `drama.parse_timed`（既有链头）自动切分镜 |
| 逐镜写旁白/配音 | PowerShell SAPI 本地离线 TTS（每镜一条 wav） |
| 字幕对时/手抄 | 与旁白同源生成 SRT，烧进画面 + 软字幕轨 |
| 找画面 | 给了 `assets_dir` 用自有图；没给就渲**分镜卡 animatic**（明标，不冒充 AI 成片） |
| 竖屏装配 | ffmpeg 1080×1920 / 30fps / H.264 + AAC |
| 验收 | ffprobe 五项（MP4/竖屏/时长/音轨/字幕轨）逐条判 |

## 二、怎么用（一条命令）

```powershell
# 剧本写时间码：0s – 4s（标题）大特写 黑屏里浮起一行字：醒来 …
powershell -NoProfile -ExecutionPolicy Bypass -File tools\drama-build.ps1 `
  -ScriptFile .\script.txt -Name 醒来E1 -MinDur 5 -MaxDur 60
# 有自有图时加 -AssetsDir .\assets （01.png/02.jpg… 按镜序）
```

输出：`outputs/drama-forge/<name>/` → `cards/`、`audio/`、`episode.srt`、`episode.mp4`、`report.md/json`。

## 三·五、接 AI 画面（适配器已就位）

```powershell
$env:GBT_T2I_CMD = '你的生成器 --prompt "{prompt}" --out "{out}"'
powershell ... -File tools\drama-build.ps1 -ScriptFile .\script.txt -Name 醒来E1 -Gen
```
- 配了 `GBT_T2I_CMD`：逐镜真调外部生成器，产物落 `assets-gen/`，`visual_mode=generated_assets`；
- 没配：`gen.status=needs_model`（本机 AMD 无 CUDA/无 Qwen 权重），自动回退分镜卡，**不假装出图**；
- 也可直接 `-AssetsDir` 给自有图，跳过生成。
## 四、边界（必须看）

- **不生成 AI 画面/视频**：没有 `assets_dir` 时是分镜卡 animatic；要真画面，用自有图（或后续接 comfy_native/comfy_cloud 生成）。
- 不下载/不复制/不发布；TTS 本地离线；只写 `outputs/`。
- 旁白自然长度会重排镜头；与剧本声明时长不同不藏（分镜 `dur_ok` 会如实报）。
- 正片时长建议 `-MinDur 60 -MaxDur 180`；测试/预告可用 5–60。
- 没有情感/角色位置线索的镜头，`drama.parse_timed` 会如实进 `lack`，不补默认值。
