主路（GBT 自家对话面）：不耍 token、不依赖第三方——直接用我们自己的大模型链路 （potato · gbt-potato-v8），经面板桥 :8765 的 /api/message 幂等受理。

面板桥没起就先跑： py -3.14 holo_pet/panel_server.py --host 127.0.0.1 --port 8765

高级 · DSH 对话面（自动接上中…；起不来才手贴）：本窗一开，壳就会 自己拉起 dsh web 并自动接上（auto_dsh，2026-10-07 起）—— 接上后本窗会直接切到官方界面，那时你根本看不到这一页；一直停在本页，才需要下面这条手贴兜底。
为什么平时必须带 token：这不是壳坏了，是 DSH 的设计 —— 实测（2026-09-23）：GET http://127.0.0.1:3080/ 回 HTTP 401，正文原文 ——
dsh web authentication required; reopen the URL printed by dsh web.
  1. 先等自动接：壳替你把 dsh web 拉起来（3080 已被占就另起一个端口，绝不打扰已有进程）， 就绪行里带 token 的 URL 只在内存里交给本窗 —— 你什么都不用做。
  2. 起不来才手贴：去看 启动 dsh web 的那个终端，复制它打印的带 token 的完整 URL， 粘进下面这个框，按「接上对话面」。
  3. URL 只留在内存，壳不落盘、不回显 —— 返回值只给你 host。

本页故意不提供「自动找到 token」的功能：那等于替你翻凭据（自动接上走的是 壳自己拉起的那条就绪行，不是替你翻任何东西）。

在此之前，对话面照常在浏览器里用 —— 本壳没有动过 DSH 一个字节（有守卫脚本为证）。
