一槽 = 一个独立 Cloudflare 账号 = 一个云插件。粘贴该账号的 cfat_… 令牌 → 点「安装」→ 壳会用这把令牌问出账号、把网格节点 gbt-mesh-10 部署进去，并回填地址。 令牌必须带 Workers Scripts:Edit 权限（Cloudflare → My Profile → API Tokens）， 否则会报「No access to the specified resource」（本机实测原文）。 十槽都装好后，节点之间用 KV 登记表两两互通（10 节点 = 90 条有向边）。
