## 三 · 三闭环进化

```
① 感知闭环：采集热门渲染项目/论文/指标/硬件动态 → 蒸馏成"可组合的渲染原语" → render_primitives.json
② 实验闭环：同一内容跑多个管线（基因）→ 各测 逼真 + 流畅 → render_experiments.jsonl
③ 进化闭环：按适应度打分 → 胜出晋级 / 失败回滚 → 每轮留痕 + 独立复核 + 人审 → render_genome_evolved.json
```

## 四 · 指标必须分两层

| 层 | 逼真 | 流畅 |
|---|---|---|
| **机器客观** | PSNR / SSIM / LPIPS · FID / FVD · 时序一致性（flicker、warping）· 光照材质一致性（relighting error） | FPS / frame time / 1% low · 掉帧率 / 卡顿率 · 首帧时间 / 编码延迟 · VMAF / BD-Rate · VRAM / GPU 利用率 |
| **人审主观** | 盲测 A/B（1–5 分） | 有没有卡顿感 |

🔴 **机器不许替人下结论**：主观分只能人给。

## 五 · 六条红线（写死 · 已做成机械闸）

| # | 红线 | 机械形态 |
|---|---|---|
| 1 | **无基线不许进化** | `propose(base_id, …)` 找不到基线 ⇒ 拒（`no_baseline`） |
| 2 | **无种子不许复现** | 基因没有 `seed` ⇒ `record_experiment()` 拒（`seed_missing`） |
| 3 | **未测不按绿** | `promote()` 缺客观指标 ⇒ 拒（`metrics_missing`） |
| 4 | **机器不替人判** | 缺人审分 ⇒ 拒（`human_verdict_missing`） |
| 5 | **不许单目标牺牲** | 与基线比：任一维下降超容差 ⇒ 拒（`single_objective_sacrifice`） |
| 6 | **每轮可回滚** | `rollback()` 恒可用；晋级/回滚都留历史 |
