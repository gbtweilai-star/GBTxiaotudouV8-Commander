# 元认知律（Meta-Cognition Law）· R-H200 · 2026-09-20

> **一句话**：**知道自己不知道，比什么都知道更重要。**
> 系统从"会干活"推到"**会学习**"：知道自己不会 → 先查 → 再问 → 沉淀 → 进化。
> **同一个坑，不静默再踩。大脑也要自省，不只触手。**

---

## 一 · 四件事 ↔ 四个机械动作

| 要求 | 机械动作 | 落点 |
|---|---|---|
| **时刻自我认知不足** | 每次任务后自检：这次**哪里卡住了**？**哪里靠猜了**？ | 自省日志（**引用** `root_fix.work_log` → `store/work_log.jsonl`） |
| **自我进化** | 短板登记 → 绑定打磨任务 → 循环改进 | 短板台账（`coverage_auditor.gaps_ledger`，挂**原生面**） |
| **不懂就要问** | 缺参 / 缺上下文 / 不确定 ⇒ **停下上报**，不硬做 | 认知包（`tentacle_cognition`） |
| **先查资料再做普及** | 遇到未知 → 先查**内部知识库** → 再查**外部资料** → 消化后再输出 | 调研循环（本模块） |

🔴 **四件缺一不可**：少了"查资料"就是瞎问；少了"问"就是硬猜；
少了"自省"就永远不知道自己不会；少了"进化"就永远在同一个坑里摔。

---

## 二 · 元认知循环（机械 · 不靠记住）

```
执行任务
  ↓
自检：我哪里不会？我哪里靠猜了？          ← 自省（记录事实，不记录情绪）
  ↓
有缺口 → 先查**内部**知识库               ← 内部没有才往下走
  ↓
内部没有 → 查**外部**资料（**需授权**：network_private / external_llm / data_export）
  ↓
还是不够 → **向主人提问**（不懂就问，不许硬猜）
  ↓
得到答案 → **沉淀**进知识库 + 更新认知包    ← 下次不用再问
  ↓
短板登记 → 绑定打磨任务 → 循环进化
```

## 三 · 五条红线（写死 · 已做成机械闸）

| # | 红线 | 机械形态 |
|---|---|---|
| 1 | **自省不是自责** | `reflect()` 的条目里出现自责词（"我太差 / 我真笨 / 我完蛋"）⇒ **拒**；**情绪归导演，自省归系统** |
| 2 | **不懂就问，不许硬猜** | 有 gap 无 resolution ⇒ `need_owner_input`；显式 `guess=True` ⇒ **拒**（`no_guessing`） |
| 3 | **先查后问，不许瞎问** | `ask_owner()` 之前**必须**有 `look_up()` 记录（内部查过）；没查就问 ⇒ `must_look_up_first` |
| 4 | **问完必须沉淀** | 拿到主人答案后**必须** `deposit()`；同一问题二次提问 ⇒ `already_asked_deposit_first` |
| 5 | **大脑也要自省** | `reflect(scope=…)` 必须覆盖 `brain` 面；只记触手不记大脑 ⇒ `brain_not_covered` |

## 四 · 先取证（R-H200 实测 · 三条）

| # | 取证项 | 读数 |
|---|---|---|
| 1 | 盘上有没有现成的"自省记录"？ | **没有专门的**；但载体已在：`store/work_log.jsonl`（`root_fix.work_log` 写入）· **`pit_log.json` 44 条坑册本身就是最接近自省的东西**（坑 + 根因 + 教训 + 守护） |
| 2 | 知识库在哪里？结构是什么？ | **没有单一目录**，三处分散：`store/devoured/<主题>/knowledge.json`（25+ 份，~700–950 B）· `store/pipeline/records/absorbed_knowledge.md-*.json`（几十份，~3.3 KB）· `gbt_allinone/brain_vault.py`（脑库模块） |
| 3 | 外部查证要授权吗？ | **要**：`network_private` / `external_llm` / `data_export` 三个作用域（`security/policy.py`） |

### 4.1 由取证定下的两条判定（**引用 ≠ 复制**）

1. **自省不另造存储** —— **引用** `root_fix.work_log`（唯一真相源）；坑册（`pit_log`）继续承担"教训沉淀"。
2. **"查内部知识库"先查那三处现成结构**，不假设存在统一 KB；三处口径不统一本身就是**待收口的死角**（登记在册）。
