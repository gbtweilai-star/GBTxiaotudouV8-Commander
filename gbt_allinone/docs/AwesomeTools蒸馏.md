## 〇、一句话命题

```
这个仓库不是「代码」，是「地图」。

它告诉你：有哪些工具可以用。
我们要做的：把这些工具接进万能插，变成能力位。

地图上的每一个工具，都是一条潜在的触手。
—— 关键是：**不照搬，只引用；不复制，只映射。工具可以换，身份不变。**
```

## 三、技能命名与四原语

```
技能命名：awesome_tools_index（domain=tools, type=external）

四原语（**全部只读，不写盘、不出网、不装东西**）：
```
