# 全链路细节清单（创作 → 发布 · **状态默认全标"未核实"**）

> **一句话**：**细节遗漏是顶尖作品变垃圾的唯一原因。不是 AI 不够，是清单不全。**
> 纪律：**每一格都能追到出处；跑通一个，标一个。** 默认状态一律 **未核实**（不许把"知道"写成"能做"）。
> 状态口径与本仓一致：`未核实` → `已核实` 需**真跑过 + 独立复核**；工具"没有"就标 **待接**。
