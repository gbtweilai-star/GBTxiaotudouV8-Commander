# 净化刀设计（报警根治 · 排队第一 · 2026-09-19）

> **为什么它排第一**：不先把 `anomalies 20 / runtime_faults 15` 那堆噪声理干净，
> 后面开的面一上盘就顶着 20 条假报警 ⇒ **人对报警麻木** ⇒ 真故障来了也看不见（"狼来了"的镜像面）。
> **先清底噪，再上新面。这个顺序不能反。**

## 二、根治三件事（**不合并、不顺手改**）

### ① 共用排除表（**唯一真相源**）

```
落点：trace_store.SELFTEST_HINTS / trace_store.DRILL_KINDS（已有）
     → selfscan 直接 import 引用，**不另抄一份**
内容：
  测试件    _def_probe · bo.txt · t-bad.txt · t-dead · fb.txt · probe_name · _probe_lock_test · test_* · fixture · dummy
  演练类    keylogger · screen_sniff · device_takeover · pentest · social_eng ·
           credential_steal · data_hijack · remote_domain · onboarding_gate · paywallbuster · asset_vault_freeze
```

**红线**：`selfscan` 与 `trace_store` **共用同一张**（引用共用，不各写一份）——否则又是"两处真相"。
**排除表本身要带用例**：证明它排的是**测试件**，不是真故障。

### ② `svc_inspect` 的 `legacy` 档

- V5 遗留服务标 **`legacy`** 后 **不再以 `svc_down` 报警**；
- 但 **仍可被显式查询** —— **`legacy` ≠ 删除，是"已登记为未迁移"**；
- 与 §① 的区别：测试件是"**根本不该进账**"，legacy 是"**进了账但不该报警**"。

### ③ 前后对比读数（**必须带分母**）

```
净化前：anomalies 20 / runtime_faults 15
净化后：anomalies __ / runtime_faults __
目标：降到 0，或只剩真故障。
🔴 不许用"排除了多少"代替"剩下多少"。
```

## 三、三条带牙用例（断言形状不许软化）

1. **排除表是同一张**：`selfscan.SELFTEST_HINTS is trace_store.SELFTEST_HINTS`（`is` 断言，不是"内容相等"）；
2. **测试件不进报警**：造一条 `_def_probe.txt` 的 `pipeline_blocked` 账目 ⇒ `check_audit` **不许把它算进 anomalies**；
3. **legacy 不报警但仍可查**：造一条 V5 服务名的 `svc_down` ⇒ ① 不计入 anomalies；② 显式查询**仍能查到它**（`legacy` 档）。

## 五 · 读数口径（R-H167 定清 · **别用错尺子**）

> 口径不是文字游戏：口径错了，"净化成功"就会变成一句没有分母的话。

```
anomalies      = 窗口内 _ANOMALY_EVENTS 的**全部事件条数**
               = runtime + guard + trace + legacy + recovered
               ⇒ **含"已恢复"** ⇒ 它是"报警源总量"，**不是净化成绩**
               ⇒ 实测：净化前后**都是 20**（净化刀不动它，因为它只数事件类型，不看分级结果）
runtime_faults = 真正要追的病 ⇒ **净化成绩只看这一个**
```

⚠️ **一处草稿口径的现场修正**：立项时写的是"anomalies 含 guard/trace/legacy，所以永远是**非 recovered 总数**"。
实测对账：`20 = runtime 0 + guard 0 + trace 10 + legacy 8 + recovered 2` ⇒
**它连 recovered 也含在内**，不是"非 recovered 总数"。口径以本节为准。

### 五条带牙用例（`tests/test_selftest_exclusion.py` · 断言形状不许软化）

| # | 断言 | 防什么 |
|---|---|---|
| ① | 排除表**是同一张**（引用，不是另抄） | 两处真相 |
| ② | 测试件 `runtime == 0`（**逐件查桶**） | 净化吃掉真故障 |
| ③ | V5 遗留服务不报警但 `legacy` 档仍在 | 把"未迁移"当成"没有" |
| ④ | `reading_scope.scoreboard == "runtime_faults"` 且 `anomalies == Σ各档` | 拿错尺子 |
| ⑤ | 真账本 `runtime_faults == 0` | 净化成绩倒退 |

> 🔧 顺带修了一条**没牙的用例**：② 的旧写法是 `assertNotIn('"' + hint + '"', str(r))`——
> 而 `str(dict)` 的键用**单引号**渲染 ⇒ 那条断言**永远为真**。现已改成逐件查桶。

## 六 · 第三小刀落刀记录（R-H167 · 2026-09-19 16:0x）

| by_signal | runtime 15 · guard 1 · trace 2 · recovered 2 | runtime 1 · guard 7 · trace 2 · legacy 8 · recovered 2 | **runtime 0 · guard 0 · trace 10 · legacy 8 · recovered 2** |

### 6.2 这一刀改了什么（三处，都有读数背书）

1. **补全共用排除表**：`trace_store.SELFTEST_HINTS` 加 `t-dead`、`_probe_lock_test`
   —— 设计 §① 列了这两件、**落地漏了** ⇒ `t-dead` 一直在冒充唯一的"运行故障"
   （它是 `tests/test_framework.py:771` 以 `owner="test"` 注册的测试夹具）。
2. **口径写进代码**：`check_audit` 的 docstring + 返回体新增只读字段 `reading_scope`
   （机器可读：`scoreboard = runtime_faults`）。**给"接面板第二刀"取数用，避免把错口径接上界面。**
3. **档位语义对齐**：测试件（命中共用排除表）**从 `guard` 挪到 `trace`** ——
   `guard` 的含义是"护栏在正常工作"，测试件是"根本不该进账的测试噪声"；挤在一格，
   读数就会被读成"护栏忙了 7 次"（实测 7 条测试件 pipeline_blocked 正是如此）。
   顺手退役最后一个前缀判例 `startswith("t-")`（R-H157 的本意就是"不再靠前缀猜"）。

### 6.3 顺带发现（**另立一刀，不混刀**）

`root_fix.patch_debt()['selfscan_判例行']` 现在读 **0** —— 但它的正则是从注释 `# 信号分级`
到**第一个** `sig = `，而第一个 `sig = ` 就在 `if meta.get("probe")` 里 ⇒ 这段区间**不含**
真正的分级链 ⇒ **这个指标已经量不到它名字所指的东西**（判据与实物脱钩，又是一次"判据挂在旧口径上"）。
