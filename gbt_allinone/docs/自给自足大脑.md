# GBT小土豆 · 自给自足本地大脑

> **没有外部密钥，不等于能力缺失。**
> 本地模型 = 思考　本地数据库 = 记忆　本地工具 = 行动
> **三件齐全，就是一台完整的本地超级大脑。**

---

## 一 · 蒸馏：只做三件事

```
① 本地思考（本地模型群，**无需密钥**）
② 本地记忆（数据库，**无需密钥**）
③ 本地行动（工具 + 触手，**无需密钥**）

外部模型 / 外部 API / 外部密钥 —— **全部降级为「可选增强」**：
有则更好，**无则照跑**。
```

---

## 二 · 无外部密钥下的**十个缺口**与补法

| # | 短板 | 补法 |
|---|---|---|
| 1 | 模型能力不足 | 多模型投票 + 思维链 + 工具辅助 |
| 2 | 上下文窗口有限 | **本地检索增强（RAG）**，不依赖外部 |
| 3 | 工具调用不准 | 严格 **JSON schema** + 白名单 + 二次确认 |
| 4 | 知识陈旧 | 本地知识库**持续沉淀 + 定期蒸馏** |
| 5 | **无法联网** | 标注「需外部密钥」的能力**不可用**，其余**照常** |
| 6 | 推理深度不够 | **分步推理 + 自我验证 + 交叉检查** |
| 7 | 多模态缺失 | 本地视觉/语音（如有）**或标记为不可用** |
| 8 | 学习效率低 | 高频任务**模板化** + 成功路径**固化** |
| 9 | 资源竞争 | 优先级队列 + 资源锁 + **预算上限** |
| 10 | 安全边界模糊 | 门禁 + 审计 + **不可逆动作二次确认** |

## 三 · 两种运行模式与**降级策略**

```
┌─ 本地大脑（自给自足）────────────────────────────┐
│ 模型层：Qwen2.5-7B / Coder-7B / R1-7B           │
│ 路由层：本地模型自动切换                          │
│ 记忆层：本地数据库                                │
│ 工具层：本地工具 + 触手（**无需外部密钥**）        │
│ 进化层：本地学习 + 模板固化                       │
├─ 外部增强（**可选，有密钥才启用**）────────────────┤
│ 外部大模型（**仅补认知**）· 联网搜索 · 外部平台     │
│ （LibTV / a1art 等）· 云端存储                    │
└──────────────────────────────────────────────────┘
```

**降级策略（三条）**：

```
① 无外部密钥 ⇒ **自动跳过外部增强，只走本地**
② 遇到需外部的能力 ⇒ 返回 **needs_external_key**，
   但 **不影响其他任务**
③ **本地能力不受任何影响**
```

## 四 · 五条红线（写死 · 已做成机械闸）

| # | 红线 | 机械形态 |
|---|---|---|
| 1 | **本地优先**（默认纯本地，外部增强需显式启用） | `mode` 默认 `LOCAL_ONLY`；启用外部需显式 |
| 2 | **密钥缺失不降级核心能力** | 只标记**需外部密钥**的能力不可用 |
| 3 | **外部模型只补认知**（不许直接执行、不许绕过路由） | `model_direct_exec`（同族 R-H227/229） |
| 4 | **记忆本地存储**（数据不出本机） | `key_must_be_dpapi` + 记忆不落外部 |
| 5 | **身份内核不变**（永远是 GBT小土豆） | `identity_rewritten`（同族） |

## 五 · 先取证（R-H235 实测 · 四条）

| # | 取证项 | 读数 |
|---|---|---|
| 1 | 盘上现有**本地模型几个**？ | **2 个**（`qwen3:0.6b` · `qwen3:latest`）⇒ ⚠️ 设计里那四个（qwen2.5:7b / coder-7b / llama3.1:8b / r1-distill-7b）**一个都没拉** |
| 2 | **本地数据库有没有**？ | ⚠️ **有痕迹/账本类落点**（`trace_store` · `store/*.jsonl`），**没有向量库/全文索引的真库**；`context_vault` 是**只读骨架**（未落盘） |
| 3 | **工具层是否已本地化**？ | ✅ **是**：**131 个能力位** + `auth_gate` 门禁 + 触手**都在盘**；⚠️ 但**没有「需不需要外部密钥」的显式字段** |
| 4 | 有没有现成的降级形状？ | `needs_external_key` **0 命中** · `needs_dependency` 41 · `degraded` 96 ⇒ **有同族形状，缺统一出口** |

🔴 **结论**：**"能想、能记、能动手"里，只有"能动手"是真的**（工具层齐）；
**"能想"缺模型**（只有 2 个 qwen3），**"能记"缺真库**（只有骨架）。
⇒ 本设计**方向成立**，但**当前状态 = 三缺二**。

## 六 · 诚实边界

- 本设计**不装模型、不建库、不出网、不落盘**；
- **一个关键澄清**：`没有外部密钥 ≠ 全部能力可用`——
  它保证的是「**核心能力完整**」（想/记/行动三件不依赖外部）；
  **它保证不了「外部增强的能力凭空出现」**（联网搜索、外部平台、云端模型
  本来就需要密钥，**该标不可用就标不可用**）；
- 当前读数如实：**本地模型 2 个（非设计中的四个）· 无真数据库 · 缺统一降级出口**；
- 「自给自足」的**判据 = 零外部密钥下的能力自检**（R-H233 已登记，**仍待落**）。
