## 一 · 核心定位（逐字）

ComfyUI 是一个**节点式 AI 工作流引擎**，把 Stable Diffusion、FLUX 等模型的推理过程，拆解成一个个可视化的「节点」，用户通过连线来构建复杂的生成流程。

**秋叶整合包**由 B 站 UP 主「秋葉 aaaki」制作，是**中文优化整合版**：把繁琐的环境配置、依赖安装、插件管理**全部打包好**，实现「解压即用」。

> 这契合既定的**能源观**与**原生优先**原则：让「强大的本地生成能力」成为可以**立即接入**的**现成能源**。

## 二 · 三层架构蒸馏（逐字）

| 层 | 名称 | 职责 |
|---|---|---|
| 第一层 | **启动器层（绘世启动器）** | 可视化界面：管理虚拟环境、更新依赖、修复报错、调整显存优化模式（如 `--lowvram`，适用于 8G 以下显存）—— 相当于给后台操作套上「遥控器」 |
| 第二层 | **节点层（工作流核心）** | 每个节点单一功能：加载模型 / 输入提示词 / 设置尺寸 / 采样 / 解码 / 保存图片…用户连线把模型、参数、输入输出串成一条**流水线**；整合包预装 90%+ 常用节点 + 内置大量成熟工作流模板 |
| 第三层 | **模型层（燃料）** | 决定「能生成什么」；**整合包本身通常不含大模型** ⇒ 需自行下载并放入 `ComfyUI\models` 下对应子文件夹 |

## 三 · 核心功能与模型支持（逐字）

| 方向 | 能力 | 逐字登记的模型 / 功能 |
|---|---|---|
| **AI 生图** | 文生图 / 图生图（最成熟） | Stable Diffusion · FLUX · Krea-2；文生图、图生图、局部重绘、高清修复、人脸修复 |
| **AI 生视频** | 文生视频 / 图生视频（可带音频） | Stable Video Diffusion · AnimateDiff · Hunyuan Video · Wan 2.7/3.0 · LTX-2 |
| **AI 生音乐 / 音频** | 文生音频 / 文生音乐 | Stable Audio · Ace-Step · Seed Audio 1.0；声音克隆、多说话人对话 |

## 四 · 硬件门槛（逐字）

```
最低门槛   4GB 显存可运行，但体验局促；8GB 显存可较流畅玩转真人风格文生图
视频门槛   更吃资源：4060 8G + 32G 内存，生成 5 秒 536x736 视频 ≈ 6 分多钟（「尝鲜」级）
存储       整合包本体约 2–8GB；完整模型库（大模型 / LoRA / ControlNet 等）需预留 200GB–1TB+
```

## 五 · 与 GBT小土豆V8 的融合设计（逐字）

- **能力位登记**：`comfyui_local`（`domain=creative`，`type=internal`）
- **五原语**：

| 原语 | 作用 |
|---|---|
| `LOAD` | 加载模型与工作流 |
| `GENERATE` | 执行生成任务（文生图 / 视频 / 音频） |
| `CONTROL` | 通过 ControlNet 等节点控制生成结果 |
| `POST` | 后处理（超分、修复） |
| `EXPORT` | 结果落盘 |

- **融合路径**：
  - 作为「**手**」：接收大脑（本地模型）的指令，调用 ComfyUI API 执行具体生成任务
  - 作为「**眼**」的延伸：生成的图片/视频回传给「眼」（视觉触手）做质量审核
  - **结果落盘**：产物必须下载到本地或飞书仓库，并写入 `trace_store`，`source_kind="comfyui"`
