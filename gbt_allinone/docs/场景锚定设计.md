# 场景锚定系统（Scene Anchor）· R-H185 · 2026-09-20

> **核心**：不是"伤感歌曲要伤感"，是 **"人在失恋、伤心、无助的时候，才会去找这首歌"**。
> **钩子必须钩住触发场景——场景不是背景，是钩子的真正落点。**

## 二 · 三层贯通模型

### 第一层：场景分类层（所有作品通用）

| 大类 | 细分场景 | 对应情绪 |
|---|---|---|
| **失去** | 失恋 / 亲人离世 / 朋友走散 / 梦想破碎 | 伤感、哀、无助 |
| **重逢** | 老友相聚 / 久别重逢 / 破镜重圆 | 喜、爱、温暖 |
| **挣扎** | 加班深夜 / 备考 / 创业 / 复读 | 疲惫、不甘、倔强 |
| **突破** | 毕业 / 拿到 offer / 第一次登台 / 手术成功 | 喜悦、激动、感激 |
| **孤独** | 一个人吃饭 / 深夜回家 / 异地漂泊 | 孤独、想念、温柔 |
| **愤怒** | 被辜负 / 被误解 / 被不公对待 | 怒、不甘、反抗 |
| **治愈** | 撑不下去 / 想放弃 / 需要有人陪 | 疲惫、渴望、温柔 |
| **怀旧** | 翻旧照片 / 回老家 / 听老歌 | 想念、温柔、感慨 |

🔴 **这张表是骨架，不是答案**：每个作品要找到**自己的具体瞬间**，不是泛泛的类别。

### 第二层：灵魂锚定层（每个作品一个灵魂）

**灵魂 = 触发场景 + 情绪反应 + 共鸣点 + 留白**（四要素缺一不可）

```
例：伤感歌曲《杯子》
  触发场景：分手三个月后，整理房间，翻到对方送的杯子
  情绪反应：不是嚎啕大哭，是手停了一下，然后把它放进柜子最深处
  共鸣点：每个人心里都有一个"不知道该怎么处理的东西"
  留白：副歌结束后的那几秒静默——不是让人哭，是让人想起自己的那个"杯子"
```

**没有灵魂锚定的作品 = 情绪标签的排列组合。**

### 第三层：钩子匹配层（**钩子锚场景，不锚情绪**）

| 内容类型 | ❌ 错误钩子（锚情绪） | ✅ 正确钩子（**锚场景**） |
|---|---|---|
| 伤感歌曲 | "这首歌太伤感了" | "分手后半夜翻到旧照片的人，别听这首歌" |
| 治愈歌曲 | "治愈系音乐推荐" | "加班到凌晨三点的人，这首歌给你" |
| 励志歌曲 | "励志神曲，燃爆了" | "面试失败第 7 次，我还在投简历" |
| 快乐歌曲 | "快乐歌曲合集" | "和最好的朋友重逢那天，我们放了这首歌" |

## 三 · 四条红线（写死 · 已做成机械闸）

| # | 红线 | 机械形态 |
|---|---|---|
| 1 | **先找场景，再做作品** | 四要素缺任一 ⇒ 拒绝（没场景不许开工） |
| 2 | **场景必须具体** | 只填类别词（"失恋"/"挣扎"）⇒ 拒绝；要具体到"**分手后第 37 天翻到旧照片**" |
| 3 | **钩子锚场景，不锚情绪** | 钩子出现纯情绪/夸张词（"太伤感了"/"燃爆了"/"合集"/"推荐"）或没有场景标记 ⇒ 拒绝 |
| 4 | **灵魂必须能被说清** | `soul()` 必须四要素齐全，说不清就是没灵魂 |

## 六 · 顺序与诚实边界

- **顺序**：排在**钩子矩阵之后**、**编排内核之前**。
- **不碰**：面板 8765 · 信号环 · 写路径 · 出网。
- **诚实边界**：
  · 骨架期**只有分类骨架，没有任何真实场景数据** —— 细分场景要按作品逐步填，**不假装有**；
  · "场景够不够具体"只能靠**标记词机械判**（数字/时间/动作），**够不够打动人是人判**；
  · 四模块的贯通**本刀只登记、未接线**（避免一锅端）。
