## 零、一句话与边界

P0 只在维度里长**一面只读镜**：**独立进程 → 前置双门 → 三级锚点 → 第 1 档结构比对 + 第 2 档颜色采样

| 做 | 不做 |
| --- | --- |
| 独立进程（`selfvision/main.py`）· `--once` / `--selftest` / `--status` | **不做常驻 5 s 循环**（P2）；P0 只承载「事件后立刻自检」这一档语义 |

| 第 1 档结构比对（UIA 读回）+ 第 2 档颜色采样（ΔE CIEDE2000） | **不上第 3 档**（`_ahash` / `diff_regions`）· 不生成基准图（P1） |

## 三、能力规格

### 3.1 前置双门（跑任何采集之前）

```text
门 1 会话门：capture_environment.status()["desktop"] 不以 "CodexSandbox" 开头
门 2 交互门：capture_environment.status()["interactive_desktop"] == True

任一不过 → state = SELFVISION_BLIND · reason_code = non_interactive_desktop
           退出码 12 · 落一条 self_vision_diff（state=SELFVISION_BLIND, verdict=n/a）
```

门 1 的指纹来自本轮实测（沙箱桌面名 `CodexSandboxDesktop-…`）；门 2 是兜底——**即使沙箱改了名，门 2 仍拦得住**。
两门都过才继续，**不许拿「后端 import 成功」当可见性证据**（本轮铁证：后端全 true、照样抓不到）。

### 3.2 三级锚（逐级收窄，找「我那一扇窗」）

| 级别 | 锚 | 用什么 | 过不了怎么办 |
| --- | --- | --- | --- |
| L1 进程锚 | `pid` → 命令行含 `holo_pet_w3` / `electron` + shell 路径 | `_enum_windows()` 的 `pid` + 进程查询 | 退 L2 |
| L2 窗口锚 | `hwnd` + 标题命中 `windows.json` 的 `title` + `rect` | `_enum_windows()` / `_find_window()` | 退 L3 |
| L3 像素锚 | **色板占比**（见 §5.2）命中品牌色分布 | 窗口级抓帧 + 直方图 | `NOT_RUNNING` + `identity_mismatch` |

**身份表唯一真相源**：`holo_pet_w3/shell/windows.json`（现只登记 `godview` 一扇）。
P0 **登记四扇、只量已施工的那一扇**——
主控台 / 云电脑 / 克劳德 → `NOT_RUNNING` + reason **`not_in_batch`**（W4 / W5 未施工，
**显示「未施工」而不是「故障」**，否则就是系统性假红）。

### 3.3 三态判定（第一段互斥 · P0 实现）

| 情形 | 第一段状态 | 退出码 | 原因码 |
| --- | --- | --- | --- |
| 双门过 + 进程在 + 窗口在 + 像素锚命中 | `IDENTIFIED` | → 进第二段（0 / 10） | —— |
| 进程不在 / 窗口不在 | `NOT_RUNNING` | `11` | `panel_down` |
| 该窗未施工（云电脑 / 克劳德 / 主控台） | `NOT_RUNNING` | `11` | `not_in_batch` |
| 照到了但像素锚全否 | `NOT_RUNNING` | `11` | `identity_mismatch` |
| 身份门 / 桌面门不过 | `SELFVISION_BLIND` | `12` | `non_interactive_desktop` |
| 窗口被遮挡 / 最小化抓不到 | `SELFVISION_BLIND` | `12` | `occluded` |
| 三个采集后端全失败 | `SELFVISION_BLIND` | `12` | `backend_failed` |

第二段（仅 `IDENTIFIED`）：`PASS` → `0`；`FAIL` → `10`。

> **11 与 12 必须分开**（同 W2.5 的 20/21）：「面板没起」与「镜子瞎了」是两件事，混码就没法诊断。

### 3.4 第 1 档：结构比对（UIA 读回，**不要求被测者配合**）

- 数据源 = **UIA 定向穿透读回**：`omni_domain.domain_read(window)`（`omni_domain.py:218`；按窗口标题匹配 → 遍历子控件 →
  返回 `{ok, window, count, texts[{text,type}]}`），**不是** W3 前端 dump DOM。
  理由：镜子**不许要求被观察者配合**——若镜子靠 `window.js` 吐 DOM，被观察者一挂镜子就跟着瞎。
  实现里已内建「**无视遮挡**」（同 `:219` docstring）→ 正好是 B2 遮挡情形的兜底。
- **三个不能挂的**（本轮核过）：`read_text_fast(scope="active")` 读的是**前景窗**，不是目标窗 → 不能当锚；
  `read_console` 是 conhost 专用 → Electron 用不上；`domain_act` / `domain_type`
  （`:108` / `:183`）是**动作路径**（`:212` 内含 `SetForegroundWindow` 还原逻辑）→ **巡检禁调**。
- 读回内容 → 匹配 §4.1 的**结构断言**（元素存在性 + 文案 + 关键几何）。
- UIA 初始化按既有线程安全范式（`omni_domain.py:28` 的 `UIAutomationInitializerInThread`），**不抢前台、不激活**。
- 兜底：UIA 读不到（Electron 未开可访问性）→ 结构档记 `unavailable` + 原因码，
  判 **`SELFVISION_BLIND` + `structure_unavailable`**，**不许**当成「结构全过」
  —— 这就是「读不到 ≠ 不存在」。

### 3.5 第 2 档：颜色采样（ΔE CIEDE2000）

**算法**：`sRGB → 线性 → XYZ(D65) → Lab → ΔE00`，**自己实现**（纯算术）。判据：

| ΔE00 | 处置 |
| --- | --- |
| `< 2` | 放行（不记差异） |
| `2 – 5` | 观察（只落盘） |
| `≥ 5` | 警告 |
| `> 10` | 严重（如状态灯色错、品牌色丢失） |

**算法自身的已知对**（《扫描器自证律》要求「先证明自己不瞎」）：用 **Sharma–Wu–Dalal 的 CIEDE2000 官方测试数据**
做已知对，例如第 1 行 `Lab(50.0000, 2.6772, −79.7751)` 对 `Lab(50.0000, 0.0000, −82.7485)` → `ΔE00 = 2.0425`。
施工时把官方表**前 10 行整表**落进测试（数值以官方表为准，不用这份方案里的记忆值）。

### 3.6 差异分级

| 级别 | 判据 | 动作 |
| --- | --- | --- |
| 严重 | 用户可见文案含品牌词 · 关键元素缺失 · 窗口不可见 / 尺寸为 0 · 状态徽章取色 ≠ 四态任一 | 立即上报 + 落审计 |
| 警告 | 关键几何超容差 · 位置漂移 **> 20 px** · 采样色 **ΔE00 ≥ 5** | 汇总上报（5 min 窗口） |
| 观察 | 措辞差异 · 非固定带像素变化 · `2 ≤ ΔE00 < 5` | 只落盘 |

### 3.7 独立审计通道

```text
事件：self_vision_diff
字段：time / target / state / verdict / severity / frame_hash / baseline_hash(n/a@P0)
      / diff_regions[] / color_delta_e[] / reason_code / evidence_path / ttl_s
落点：store/health/self_vision/*.jsonl        ← 独立通道，不混 store/audit.jsonl
锁  ：文件锁，防重入（抄 W2.5 探针的互斥做法）
超期：窗口读到的最后一条若 now - ts > ttl_s → 显示「未启用」（假绿防线，同 W2.5 §3.4）
```

`frame_hash` 只落**指纹**，不落图像字节（《凭据不离屏律》）。

### 3.8 自证四臂（**镜子自己的《扫描器自证律》** · `--selftest`）

合成帧与合成元素树**在内存里生成**（事实 2：二进制不进镜像）：

| 臂 | 喂什么 | 必须得出 | 退出码 |
| --- | --- | --- | --- |
| **A 正对照** | 合成帧（按 §5.2 的色板占比拼）+ 合规元素树 | `IDENTIFIED` + `PASS` | 0 |
| **B 负对照** | **纯色帧**（只有品牌色，没有结构/占比分布） | 不是我的面板（`identity_mismatch`） | 11 |
| **C 盲臂** | 身份门不过 / 解码失败 | `SELFVISION_BLIND` | 12 |
| **D 判定层** | 正对照帧**塞违规**（缺底栏带 / 徽章色 ΔE00 > 10 / 文案含品牌词） | `FAIL` | 10 |

**判别要求**：A 与 B 结果必须不同；A 与 D 结果必须不同。**两条都成立才叫可判别**——
只有 A 会「把任何图都认成自己」（假阳），只有 B 会「把任何图都否掉」（假阴）。
**`--selftest` 退出码**：全部相符 → `0`；任一臂不符或合成帧解码失败 → **`13`（自证未过 / SCANNER_BLIND）**，
**不许报 0**。

### 3.9 退出码总表（退出码即结论）

| 码 | 含义 |
| --- | --- |
| `0` | `IDENTIFIED` + `PASS`（或 `--selftest` 四臂全过） |
| `10` | `IDENTIFIED` + `FAIL` |
| `11` | `NOT_RUNNING`（`panel_down` / `not_in_batch` / `identity_mismatch`） |
| `12` | `SELFVISION_BLIND`（`non_interactive_desktop` / `occluded` / `backend_failed` / `structure_unavailable`） |
| `13` | **自证未过**（`--selftest` 任一臂不符 / SCANNER_BLIND） |
| `22` | **本次没有结论**（互斥锁占用 / 配置或落点不可用 / 未指定动作 / 记录超期判灰） |

## 五、本轮新发现：透明窗口的采样陷阱（**P0 必须按这个写，否则必假红**）

### 5.1 事实

W3 的上帝视角窗口是 **`transparent: true` + `frame: false`**（`shell/windows.json`），
而配色 token 大量是**带 alpha 的**：

```text
--gbt-bg    : rgba(5, 7, 17, 0.74)      --gbt-panel    : rgba(12, 16, 34, 0.62)
--gbt-line  : rgba(124, 77, 255, 0.38)  --gbt-line-soft: rgba(0, 229, 255, 0.18)
（window.css:18-21）
```

### 5.2 三条口径

1. **半透明区域的采样色 = token × α + 背后桌面 × (1 − α)**，背后是什么**未知**。
   所以**半透明区域不做「等于某 token」的断言**——那会随机假红。
2. **身份锚（L3）用色板占比，不用单点取色**：对窗口帧做直方图，
   要求「品牌金 / 赛博青 / 深空紫 三种 token 在容差内的像素占比」落在**预期区间**（阈值按 §6.1 的合成帧标定）。
   这样既不依赖背后桌面，也不会被单点噪声带偏；**纯色帧的占比分布天然不符** → 负对照臂成立。
3. **半透明底唯一可靠的断言是亮度上限**（C3）：即使背后纯白，`0.74×token + 0.26×255` 也远远够暗。
   **色相断言一律不做**——真实反例：背后若是亮红，`0.74×(5,7,17) + 0.26×(255,0,0)` 算成 `(68, 5, 13)`，
   红 > 蓝，色相断言当场假红。

### 5.3 顺带纠正一处口径

设计稿 §3.3 引用的「底栏 104px」是**主控台**（`holo_pet_UI规格.md`）的规格；
W3 的上帝视角窗口自带的底栏是 **28px**（`window.css:220`）。
断言表按**被测对象自身**的规格写（§4 的表已经这么做）——**拿别处的规格量本窗，就是系统性假红**。

## 八、红线

- **先设计，不动手**——本文件只是方案；拍板前不建目录、不写代码。

- **不抢焦点**——巡检路径禁调 `_focus_window` / `SetForegroundWindow` / `win.activate()` / `win.show()` / `alwaysOnTop`；
  施工时加**静态闸门**（对 `gate.py` / `compare.py` 做 AST 检查，命中即判红），黑名单本轮已具体化：
