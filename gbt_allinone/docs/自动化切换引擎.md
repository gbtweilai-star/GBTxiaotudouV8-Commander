# GBT小土豆 · 自动化切换引擎

> **这套设计的核心不是"更聪明"，是"更不容易误解"。**
> **意图错了 → 一切白费。**

---

## 一 · 全链路五层

```
① 意图分析层（**最关键**）→ 输出结构化意图
     ↓
② 任务分级层（难度 + 类型）→ 输出任务画像
     ↓
③ 模型切换层（自动选能源）→ 输出选中的模型 + 参数
     ↓
④ 原生执行层（走触手）→ 输出结果
     ↓
⑤ 验证 / 审计层（对账 + 留痕）→ 输出最终读数
```

**每一层独立可测；每一层的输出都是下一层的输入。**

---

## 二 · ① 意图分析层（防误解的核心）

「意图分析装最好的」—— 单独设计成**三层**：

| 层 | 动作 | 防的是什么 |
|---|---|---|
| **L1 直接解析** | 主模型输出意图 JSON | 基础理解 |
| **L2 交叉验证** | **第二个模型独立复述意图** | 单模型幻觉 |
| **L3 置信度判定** | 两次一致 → 高置信；不一致 → 问主人 | **误解** |

```
两次一致     => confidence 高（0.95）
两次不一致   => confidence 低（0.5）+ needs_clarification = True
🔴 置信度低于阈值 => **不执行，先问主人。绝不硬猜。**
```

---

## 三 · ② 任务分级层

| 维度 | 判据 | 举例 |
|---|---|---|
| **类型** | 代码 / 推理 / 创意 / 多模态 / 执行 | "写个脚本" = 代码 |
| **难度** | 步骤数 / 依赖深度 / 不确定性 | "修 bug" = 高难度 |
| **可逆性** | 只读 / 可逆写 / **不可逆** | "删文件" = 不可逆 |
| **时限** | 实时 / 可等待 | "查天气" = 实时 |

---

## 四 · ③ 模型切换层（自动选能源）

| 任务画像 | 默认能源 | 备选 |
|---|---|---|
| 简单意图 / 实时 | 本地 7B | 本地 8B |
| **复杂推理** | 本地 R1-Distill | 云端 Agnes |
| **代码** | 本地 Coder-7B | 云端 |
| 多模态 | 云端（**本地无视觉**） | — |
| 高难度 / 长上下文 | 云端 Agnes | 本地兜底 |

🔴 **切换由大脑决策，不由模型自选。**

---

## 五 · ④ 原生执行层 + ⑤ 验证/审计层

```
意图 JSON → 能力注册表 → 门禁 → 触手 → 结果
🔴 **模型不许直接执行系统命令**
```

| 动作 | 落点 |
|---|---|
| 每次执行 | `trace_store` |
| **每次切换** | 记 **`model_used`** |
| 每次拒绝 | 记 `reason_code` |
| 每次降级 | 记 `degraded=true` |

---

## 六 · 接线点**只有一个**

```
本地大脑（7B-8B）↕ **Intent JSON** ↕ 能力注册表（129 能力位）↕ 触手（弹性池）↕ 执行结果 ↕ 回到大脑解释

🔴 **接线点只有一个：Intent JSON。**
   大脑不管底层是哪个模型，触手不管上层是哪个大脑。
```

---

## 七 · 五条红线（写死 · 已做成机械闸）

| # | 红线 | 机械形态 |
|---|---|---|
| 1 | **意图置信度低于阈值 → 先问主人** | `gate_intent` → `low_confidence_ask_owner` |
| 2 | **模型不许直接执行** | `check_no_direct_exec` → `model_direct_exec` |
| 3 | **每次切换必须记 `model_used`** | `must_log_model_used` → `no_model_used_logged` |
| 4 | **不可逆动作二次确认** | `gate_irreversible` → `irreversible_needs_confirm` |
| 5 | **身份内核不许被模型改写** | `check_identity_text` → `identity_rewritten` |

## 九 · 顺序与诚实边界

- **顺序**：排在**本地原生脑之后**、**编排内核之前**（已满足）。
- **落地即接线**：同刀进编排内核只读派发表 ⇒ 不制造新孤儿。
- **不碰**：面板 8765 · 信号环 · 写路径 · 出网。
- **诚实边界**：
  · 本骨架**不调模型、不起服务、不出网、不落盘**；L2 交叉验证**结构就位、模型未接**；
  · 「自动化切换」保证的是**全链路可测、错在意图时能先问主人、错在执行时能留痕回滚**；
  · 它**不保证"永远不会误解"** —— 但保证**误解不会被静默执行掉**。

# 附：v2.0 —— 蒸馏 + 补 19 条短板（R-H232 · 2026-09-20）

## 一 · 蒸馏：五层 → **四层 + 一回灌**

```
旧版五层里，「任务分级」和「模型切换」其实是一件事 —— **分级是为了切换**。合并。

① 意图层（解析 + 交叉验证 + 置信度 + **歧义分类**）→ Intent JSON
② 调度层（**分级 + 选能源 + 定执行链**）→ Dispatch Plan
③ 执行层（注册表 + 门禁 + 弹性池 lease + 触手）→ Raw Result
④ 校验层（结果对账 + 审计 + 回传）→ Verified Result
        ↺ **回灌意图层**（更新偏好模型）
四层 + 一个回灌循环 = **闭环**。
```
