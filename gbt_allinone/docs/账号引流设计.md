> **唯一公理**：**内容不是目的，钩子是。每条内容必须有一个让人"非点不可"的理由。**
> 排队：排在本簿最后——净化刀 → 导演情绪 → 音乐发布 → 调研 AI → 细节清单 → **本件**。

## 一、四层钩子模型（缺一层，转化断一节）

| 层 | 钩什么 | 作用 | 缺了会怎样 |
|---|---|---|---|
| **L1 停留钩** | 眼睛 | 前 3 秒不划走 | 只有 L1 ⇒ **划走** |
| **L2 好奇钩** | 脑子 | 想知道后续 | 只有 L2 ⇒ **看完就走** |
| **L3 情绪钩** | 心 | 想转发 / 评论 | 只有 L3 ⇒ **点赞不关注** |
| **L4 行动钩** | 手 | 关注 / 收藏 / 进群 | 只有 L4 ⇒ **像广告** |

## 二、五类内容源（**素材从盘上取，不编**）

| 类型 | 素材来源 | 钩子形态 | 平台适配 |
|---|---|---|---|
| **进展型** | 每天的工作日志（DD 板读数） | "第 N 天：AI 终于学会 ___" | 抖音 / B站 / 小红书 |

| **金句型** | 坑册 / 纪律（一路踩出来的） | "做 AI 一年，我总结出这 10 条血泪教训" | 全平台 |

## 三、钩子生成的机械规则（**不靠灵感，靠模板**）

```
停留钩 = 数字 + 反差 + 悬念       例：50 个 AI · 只花了 1 块钱 · 干完了一个月的活
好奇钩 = 结果前置 + 过程后置       例：AI 自己写了一首歌 → 但它干了件更离谱的事
情绪钩 = 具体场景 + 真实反应       例：凌晨三点它突然开始写歌 → 我听完没睡着
行动钩 = 低门槛 + 高价值 + 紧迫感   例：评论区扣「工作流」→ 我发你整套（限今天）
```

**每条内容至少带一个钩子**，格式写死（上表四种形状）。

## 六、引流闭环（**没有落点的钩子 = 空钩**）

```
内容 → 钩子 → 落点（评论区 / 简介 / 私信）
                  ↓
            沉淀（微信群 / 知识星球 / 公众号 / 邮件列表）
                  ↓
            回流：用户说想看什么 → **调研 AI**
```

**每个平台必须配一个明确落点。**

## 七、❤️ 第四钩 · **信任**（前三个管"钩过来"，这个管"留得住"）

> 前三个钩子（**好奇 / 爱热闹 / 自私**）是流量公式：好奇＝信息缺口（Loewenstein）；
> 爱热闹＝社交认同 + 从众；自私＝损失厌恶 + 互惠。**但它们只管"钩过来"。**

| 钩子 | 底层机制 | 对应内容形态 | 管什么 |
|---|---|---|---|
| 好奇 | 信息缺口理论 | 揭秘型 / 悬疑型 / 反转型 | 钩过来 |
| 爱热闹 | 社交认同 + 从众 | 追热点 / 站队型 / 争议型 | 钩过来 |
| 自私 | 损失厌恶 + 互惠 | 教程型 / 工具型 / "扣1发你" | 钩过来 |
| **信任（第四钩）** | **长期主义** —— 你说的是真的，我就一直跟着你 | 真实账本 / 坑册 / 护照 / 七栏读数 | **留得住** |

**状态对照**：

| 状态 | 结果 |
|---|---|
| 只有前三个钩子 | **短期爆量，长期掉粉**（一次性收割） |
| 前三个 + 信任 | **稳步增长，口碑复利** |
| 前三个 + 信任 + AI 真实工作流 | **别人抄不走**——素材是每天真跑出来的 |

## 八、四条红线（写死）

1. **内容素材必须能从盘上追到出处** —— 不许编故事；
2. **钩子不能骗** —— 说"扣 1 发你"就**必须真发**；
3. **引流落点必须真实存在** —— 不许建假群；
4. **「自私钩」可以用，但必须真兑现** —— 它是最容易被滥用、也最危险的一格：

| 可以做 | 必须满足 | 🔴 不可以 |
|---|---|---|
| 教你省钱 / 教你赚 | **必须真教** | "9.9 教你月入过万" ⇒ **那是诈骗** |
| 扣 1 发你 | **必须真发** | 发过去是一坨垃圾 ⇒ 违规 |
| 我这里有内幕 | **必须是真的内幕** | 编内幕 ⇒ 违规 |

> **这一条不加，整个体系就从"长期资产"变成"一次性收割"。**

| 路径 | 做什么 | 独特性 | 风险 |

## 十、判断标准（一句话）

> **"你钓上来的人，愿不愿意留下来。"**

**留下来的，才是资产；钓上来又跑的，是数据噪声。**
"想钩多少人没有"的答案**不是"无限"**，是**"留下来的人有多少"**。

**我们最强的优势不是钩子设计，是素材是真的** —— 账本 · 坑册 · 护照 · DD 板 · 七栏读数，
**这些东西别人编不出来，因为那是每天真跑出来的。真实，才是抄不走的那一钩。**
