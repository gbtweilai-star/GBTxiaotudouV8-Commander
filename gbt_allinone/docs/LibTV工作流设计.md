## 四 · ⚠️ 两条避坑（**有具体机械形状**）

### ① 资源组绑定

```
建组后，**必须** `libtv group use -r` 从**标准输入**读 key 来绑定资源，
否则节点可能**找不到依赖的素材**。
⇒ 闸：check_group_bound → group_not_bound
```

### ② 管道输出

```
**终点节点**建议 `>/dev/null` 抑制 stdout，
避免输出误流到外层管道 ⇒ **下游程序收不到预期的 key**。
⇒ 闸：check_stdout_suppressed → stdout_not_suppressed
```
