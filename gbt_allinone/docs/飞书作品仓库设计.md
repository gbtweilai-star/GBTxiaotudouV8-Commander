## 四 · 红线（写死）（逐字）

| 红线 | 说明 |
|---|---|
| 本地是源，飞书是副本 | 不许反向覆盖本地 |
| 密钥只存 DPAPI | 飞书凭据、云端能源密钥，全部走密钥池 |
| 每次操作留痕 | 写 `trace_store`，`source_kind="feishu_storage"` 或 `"video_segment"` |
| 不可逆动作二次确认 | 删除、覆盖、发布，必须确认 |
| 上传前校验 | 每个片段带 checksum，防止传坏 |
| 失败如实报 | 本地跑不动就标 `needs_cloud_energy`，不硬撑 |
