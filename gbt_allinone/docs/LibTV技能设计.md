## 四 · 与万能插系统集成

```
大脑（主机）  → 下发创作任务 + **认知包**
万能插（执行层）
  ├── 路由到 libtv 能力位
  └── 从**密钥池** lease LIBTV_ACCESS_KEY        ← 不许明文落盘、不许第二套路径
触手（执行末端）
  ├── 调用 libtv-skill 脚本
  ├── **增量轮询**查询进展
  └── 下载结果 → **落 trace_store**
结果回传大脑 → **内容审核** → 发布队列
```

**能力位登记**：`libtv_skill`（`domain=video` · **`type=external`** —— **它是门，不是内调型**）。
