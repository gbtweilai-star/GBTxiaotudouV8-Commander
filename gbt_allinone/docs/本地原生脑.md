# GBT小土豆 · 本地原生脑

> **7B-8B 是皮层，主机是纪律，触手是手脚，审计是记忆。**
> 它不是"借来的聪明"，它是"**长在自己身上的脑**"。

---

## 一 · 先把一个关键区分钉死

### 「原生大脑」**≠**「模型就是大脑」

```
大脑（主机）= 纪律 + 门禁 + 审计 + 身份内核 + **决策权**
模型（本地）= **语言皮层** + 意图解析 + 工具选择 + 结果解释
```

| 是 | 不是 |
|---|---|
| 把本地模型变成大脑的**语言层与决策层** | 让它**取代主机** |

🔴 **主机永远是纪律层** —— 模型可以换、可以升级，但
**门禁 / 审计 / 身份内核 一条不能动**（与能源观红线②「能源可换，原生栈不动」同源）。

## 三 · 本地脑架构（**模型只做第 ② 和第 ⑧ 步**）

```
① 用户说话
     ↓
② **本地 7B-8B 模型**（意图解析 + 工具选择 + 参数填充）→ 输出 JSON
     ↓
③ 能力注册表（检查工具是否存在、参数是否合法）
     ↓
④ 门禁（可逆动作放行 / 不可逆动作二次确认）
     ↓
⑤ 原生触手（搜索、打开应用、读写文件、浏览器、终端）
     ↓
⑥ 验证器（结果对不对？失败就上报）
     ↓
⑦ 审计（写 trace_store）
     ↓
⑧ **本地模型**（把结果解释给用户）
```

🔴 **模型只做 ② 和 ⑧；中间全走原生能力栈。**

## 四 · 五条红线（写死 · 已做成机械闸）

| # | 红线 | 机械形态 |
|---|---|---|
| 1 | **模型不许直接执行系统命令** | `check_no_direct_exec` → `model_direct_exec` |
| 2 | **不可逆动作必须二次确认** | `must_confirm_irreversible` → `irreversible_needs_confirm` |
| 3 | **参数缺失不许猜** | `must_have_params` → `missing_params` |
| 4 | **每次执行必须写 `trace_store`** | `must_trace_call` → `call_not_traced` |
| 5 | **身份内核不许被模型改写** | `check_identity_text` → `identity_rewritten` |

> 第 1 条和第 3 条的差别：第 1 条管**通道**（只能在注册表里选），
> 第 3 条管**输入**（缺参就拒，不许猜默认值）。两条都不许绕。

## 五 · 为什么这套比裸大模型更聪明

| 维度 | 裸大模型 | 本地脑 + 原生栈 |
|---|---|---|
| 能理解 | ✅ | ✅ |
| 能动手 | ❌ | ✅ 触手 |
| 能记住 | ❌ | ✅ `trace_store` |
| 能纠错 | ❌ | ✅ 验证器 |
| 能审计 | ❌ | ✅ 门禁 + 审计 |
| 隐私 | ❌ 出网 | ✅ 本地 |
| 成本 | API 费 | **电费** |

🔴 **本地脑不是"更聪明"，是"更可靠"** —— 它知道自己在干什么，也知道干错了怎么回滚。

## 七 · 顺序与诚实边界

- **顺序**：排在**身份内核 + 能源观之后**、**编排内核之前**（已满足）。
- **落地即接线**：同刀进编排内核只读派发表 ⇒ 不制造新孤儿。
- **不碰**：面板 8765 · 信号环 · 写路径 · 出网。
- **诚实边界**：
  · 本骨架**不加载模型、不起服务、不出网、不落盘**；
  · **显存读数拿不到** ⇒ 标未取，**不猜本机能不能跑 8B**；
  · 「本地脑更可靠」说的是**结构**（门禁/审计/回滚齐），
    **不是"回答质量更好"** —— 那只能由人判。
