# GBT小土豆V8 · AI媒体全流程自动化设计

## 三条生产线

- 短视频：选题 → 脚本 → 分镜 → 素材 → 剪辑 → 字幕/音频 → 导出。
- AI电影：概念 → 剧本 → 镜头表 → 角色/场景一致性 → 画面 → 声音 → 剪辑 → 调色 → 导出。
- AI音乐：歌词 → 编曲 → 人声/音色 → 混音 → 母带 → 封面/元数据 → 导出。

## 统一执行纪律

1. 计划和产物先进入独立镜像房间。
2. 每个阶段保存输入引用、输出引用、哈希和职业触手身份。
3. 自审覆盖完整性、版权声明、安全、品牌、质量、主人复核。
4. 自审不通过，不能排练；排练不通过，不能发布。
5. 外部平台发布属于不可逆动作，只能经统一 `run_task` 和主人授权门。
6. 默认允许生成草稿和本地导出，不默认自动公开发布。

## 已实现的编排层

`media_pipeline` 提供 `status`、`plan`、`compose`、`review`、`publish` 五个入口。它负责流程状态、镜像写入和自审，不虚构缺失的生成服务。具体图像、视频、音乐模型通过职业触手和统一 LLM/外部能力接入。

## 中文职业包

中文 `agency-agents-zh` 作为 MIT 授权资料源进入职业触手目录。短视频剪辑、视频提示词、抖音策略、多平台编排、音频工程等职业可作为独立触手参与镜像排练。中文资料正文不直接执行，发布职业的“草稿优先、人工审核”约束保留。

## 发布边界

系统可以自动完成计划、生成任务、素材整理、自审、镜像排练、草稿准备和结果汇总；公开发布、账号操作、提现和改价仍要求主人在场并留审计。
