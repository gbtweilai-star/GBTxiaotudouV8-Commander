## 八 · 主人补记（R-H470 · **逐字登记**）

### 8.1 核心定位（补记 · 逐字）

> **dsh-market 不只是插件，它是 DeepSeek Harness 整个生态的入口和心脏**，也是把「插件市场」与「平台连接」真正落地的关键。
> 它是 DSH 的「**应用商店**」：装好之后，在 **设置 → 插件市场** 里直接搜索、一键安装社区插件和主题，还能备份还原配置。
> **它不是孤立工具，而是生态的入口** —— **后面想装的任何插件，第一步都是先把它装上。**

### 8.2 安装与配置（补记 · 逐字）

```bash
dsh plugin --profile web add dshmarket
# 装完后重启 dsh web → 打开「设置 → 插件市场」
```

- **版本要求**：需要 **dsh web 0.1.0-rc.6 或更新**。
- 🔸 **优雅降级（逐字）**：宿主太旧时，市场会**自我禁用并在浏览器控制台说明原因**，
  **而不是强行渲染一个缺失的功能**；设置里若根本没出现「插件市场」，**通常就是这个原因**。

### 8.3 它能给你什么（六条 · 逐字）

| # | 能力 | 逐字要点 |
|---|---|---|
| 1 | **逛与搜（发现插件）** | 完整社区目录 **2300+ 插件，每天都在涨**；分类筛选 · star 数 · 最热/最新排序 · 描述跟随界面语言。**按宿主发现**：卡片展示插件声明的 DSH 版本要求，可选筛选只隐藏**明确不匹配**的；**未声明、格式异常、暂时取不到清单的条目仍然保持可见，不会猜成不兼容** |
| 2 | **一键安装与更新** | 一键安装：确认来源、实时进度、**多数插件刷新页面即可用，无需重启**；更新：逐插件检测版本、一键更新或全部更新，**市场自己也走同一通道升级** |
| 3 | **主题与皮肤** | 主题一键换、**装完即生效**、点一下切换、不用重启；**主题互斥**；选择**跨重启保留**；**卸载即恢复** |
| 4 | **备份与恢复** | 导出为**可读 JSON**（profile 的插件清单与配置，换机导入）；**WebDAV 每日自动备份**，或通过**私有 GitHub Gist** 跨机器同步；恢复采用**合并方式**（备份之后新装的插件会保留），**写入前校验、失败自动回滚** |
| 5 | **收藏与评论** | 收藏：书签写入 profile 的市场状态，支持搜索、排序与安装；评论：每张卡片就地打开该插件讨论，底层是 **GitHub Discussions（via giscus）**，**一个插件只有一处对话，而不是三处** |
| 6 | **中国大陆网络优化** | **多线路容错**：为 Git ref、README、头像分别维护 fallback 顺序，**记住上次可用线路**，只在传输/HTTP 状态或响应内容校验失败后换线，且**拒绝公共反代伪装成 HTTP 200 的 HTML 错误页**；**自定义加速**：内置线路全失效时，可在 **设置 → 插件 → 插件配置 → GitHub 加速** 填自定义 HTTPS 前缀 |
