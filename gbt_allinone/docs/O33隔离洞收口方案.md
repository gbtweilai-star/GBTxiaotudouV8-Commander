> 本稿只写方案。**本轮未改任何生产文件**（唯一的写入是本稿自身）。

## 〇 一句话

`root_fix.py` / `auth_gate.py` 把 store 路径硬编码成 `_BASE / 'store'`，绕开 `_paths.STORE_DIR` ——
于是 `GBT_STORE_DIR` 对它们**无效**，测试跑一次就往生产 store 写一次。
本刀 = **清干净（副作用）+ 堵死（路径来源）+ 守起来（契约）+ 修判据（脆弱性）+ 复核（零写入）**。

## 二 清生产副作用（破坏性动作先备份）

### 2.1 `pit_log.json`（保留真实条目，只删测试条目）

| 项 | 实测 |
|---|---|
| 现况 | 23,441 B · 809 CRLF · 0 裸 LF · `sha256 af9d5ffbdfc694eb…` |
| 条目总数 | 115 |
| **严格测试形态**（`pit` 以「测试坑-」开头 **且** `root_cause=="测试"` **且** `lesson=="测试"`） | **99** |
| 保留 | **16**（保留条目集合指纹 `sha16 = 40872cfa46b36ef4`，算法 = 排序 JSON 序列化取 sha256） |
| 时间跨度 | 2026-09-11T19:43:16 → 2026-09-17T20:54:22 |
| 按日 | 09-11:6 / 09-12:4 / 09-13:22 / 09-15:26 / 09-16:17 / 09-17:24 |

**判据不许用关键词匹配**：有一条真实教训叫「测试把数据写进家根 store -> 家根被污染」（09-11T19:39:11），
里面**带「测试」两个字但必须留** —— 用 `"测试" in pit` 会把它一起删掉。必须用**严格形态三元组**。

处置顺序：
1. 备份现盘 → `.scratch/_r82_o33_backup_<ts>/pit_log.json`（**先比 SHA 再动手**）；
2. 按严格形态删 99 条；保留 `{pits, note}` 结构与 `note` 原文；
3. 被删的 99 条**全量写进证据文件**（可还原，不是「删了就没了」）；
4. 删后判据：条数 115→16、JSON 合法、保留 16 条**逐条 sha 对照**未变。

### 2.2 `work_log.jsonl`（同时是第三份「混行尾」生产文件）

| 项 | 实测 |
|---|---|
| 现况 | 10,479 B · **105 CRLF + 2 裸 LF** · `sha256 e631cf3308302aa1…` |
| 行数 | 107 = **99**「测试日志」 + **2**「atomic work log」 + **6** 条真实 `done` |

**新发现（本轮 byte 级才看出来）**：那 **2 行裸 LF 恰好就是 2 条 `atomic work log`**
（2026-09-13T21:17:37 / 21:17:54）—— 与 `audit.jsonl` 那 2 行裸 LF **同源**：
写的人没走统一写入口（`locked_append_text` 开 `newline=""`），而 `work_log()` 走文本模式 `open('a')` → CRLF。
→ 这条并进 O28/O31 母题：「**行尾混用 = 谁绕开了统一写入口**」。

待拍：那 2 条 `atomic work log`（`detail="test"`）**算不算同族残留**。
- 甲（主张）：算 —— 一起清，清完该文件回到**纯 CRLF**（105 + 2 → 105，且这 2 行本来就是测试写的）；
- 乙：不算 —— 只按 `title=="测试日志"` 清 99 行，留 2 行裸 LF 另开刀。

**判别性（《扫描器自证律》：两组必须不同）**

| 组 | 做法 | 期望 |
|---|---|---|
| 正对照 | 隔离 store 里跑 `pit_record` / `work_log` / grants 保存 | 隔离目录出现产物 → 绿；不出现 = 隔离失效 |

| **反向判别** | 把 `root_fix.py` 回退到改前那份（`bf9588b17e2c75aa`）跑同一条契约 | **必须红**（红在 `pit_log` 上）；不红 = 契约是空壳 |

运行口径：跑包内测试**必须先设 `GBT_STORE_DIR`**（HEARTBEAT 已有此条）；

## 十 红线（本刀自守）

- **破坏性动作先备份** —— 三份文件先比 SHA 再动手；被删条目全量留证（可还原）；

- **全量回归必设 `GBT_STORE_DIR`**；
- **改完必须跑反向判别**（回退旧 `root_fix.py` → 契约必须红），只跑正对照不算过。
