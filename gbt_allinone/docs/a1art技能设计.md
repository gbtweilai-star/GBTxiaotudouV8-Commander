## 二 · 五原语（缺一即开环）

```
LOOKUP → UPLOAD → GENERATE → OPTIMIZE → POLL
```

| 原语 | 干什么 | 为什么要它 |
|---|---|---|
| **LOOKUP** | 获取应用基础信息与生图入参 | 图生图 / 图生视频**之前**的必调步骤（不先取入参 = 拿不准参数就发请求） |
| **UPLOAD** | 上传图片 | 图生图 / 图生视频**依赖的图片** |
| **GENERATE** | 发起生成 | 按 LOOKUP 拿到的入参契约发起，**不猜参数** |
| **OPTIMIZE** | 高清处理（精绘） | **3 积分/张**（官方口径） |
| **POLL** | 轮询结果 | 拿到结果地址后**必须立刻下载到本地** |

# 附：API 能力矩阵 + 平台口径（R-H211 · 2026-09-20）

## 一 · 5 个核心接口（官方口径 · 与五原语**逐条对上**）

| # | 原语 | 接口 | 方法 + 端点 | 备注 |
|---|---|---|---|---|
| 1 | **LOOKUP** | 获取 APP 信息 | `GET /open-api/v1/a1/apps/{appId}` | **图生图 / 图生视频前必须调用，获取依赖参数** |
| 2 | **UPLOAD** | 上传图片 | `POST /open-api/v1/a1/images/upload` | 图生图 / 图生视频依赖的图片 |
| 3 | **GENERATE** | 生成图片 / 视频 | `POST /open-api/v1/a1/images/generate` | **传入参数，得到 `taskId`** |
| 4 | **OPTIMIZE** | 图片精绘 | `POST /open-api/v1/a1/images/optimize` | 高清处理 · **3 积分/张** |
| 5 | **POLL** | 查询任务结果 | `GET /open-api/v1/a1/tasks/{taskId}` | 拿 `taskId` 换结果；**必须落本地** |

**规律**：创建类 = `POST …/images/*`；查询类 = `GET …/{appId | taskId}`。

🔴 **实证意义**：这 5 条把 R-H206 定的**五原语逐条印证**了 —— 不是猜的，是文档自己印的。

**钥匙链**：`LOOKUP`（依赖参数）→ `UPLOAD` → `GENERATE` → **`taskId`** → `POLL`
⇒ `taskId` 丢了只能**重新生成**，而**积分不再充值** ⇒ 丢了就是**真金白银**。

## 二 · 平台口径（三条，含一处**未解冲突**）

| 项 | 口径 |
|---|---|
| **定位** | **开放的内容社区**：任何人可创建并发布 APP / 滤镜；发布后其他用户可自由调 API + 消耗积分生成图/视频 |
| 🔴 **业务调整** | **不再提供 API 积分充值** + 现有积分**用完后**逐步停止服务 ⇒ 积分是**一次性存量**，不存在"续上" |
| ⚠️ **规模（冲突未解）** | **45,000+**（R-H206 那次）vs **100,000+**（本文档）⇒ **两个数并排记，不擅自合并**，报数时一起报或标来源 |

## 三 · 新增四条机械闸

```

                                `/open-api/` 之外的路径 ⇒ handmade_api_request
must_lookup_first(looked_up)    没先调 LOOKUP 就生成 ⇒ lookup_required（官方口径：必须调用）

                                （当**存量**规划，不许当长期基础设施）
```

## 二 · 参数契约

### 接口 1 · 获取 APP 信息

| | |
|---|---|
| 参数 | `apiKey`(header,必传) · `appId`(path,必传) · `language`(query,可选,**13 种语言**) |
| 返回 | `appInfo`：`id` / `versionId` / `name` / **`formArr`** / **`styleArr`** / **`processTime`** / **`cost`** |

🔴 `formArr`+`styleArr`+`cost`+`processTime` = 官方说的"**获取依赖参数**"的具体内容：
**不先 LOOKUP，就不知道表单长什么样、要花多少点数、要等多久。**

| | |
|---|---|
| 参数 | `file`（form-data，**与 imageUrl 传其一**）· `imageUrl`（form-data，**与 file 传其一**） |

| 返回 | **`imageUrl` + `path`**（生图接口依赖这两个） |

```
1. appId       | string | 必传 ✅ | 应用 id
2. versionId   | string | 必传 ✅ | 应用版本 id
3. generateNum | string | 必传 ✅ | 生成数量（1～4 张）
4. cnet        | array  | 选填    | 说明待补
5. description | array  | 选填    | 说明待补
6. styleId     | string | 选填    | 风格 id
7. size        | object | 选填    | sizeId 1-7 → 1:1 / 3:4 / 1:2 / 4:3 / 2:1 / 16:9 / 9:16
返回：{"taskId": "507b08…"}
```

### 接口 4 · 图片精绘

| | |
|---|---|
| 参数 | **`path` + `imageUrl`**（**均为上传接口返回值**） |
| 限制 | **每次 3 个点数** · 精绘尺寸上限 **2048×2048** |
| 返回 | 同生成接口（`taskId`） |

### 接口 5 · 查询任务结果

| | |
|---|---|
| 参数 | `apiKey`(header) · **`section`(header，中国区传 `cn`)** · `taskId`(path) |
| 返回 | **`state`**（0=已提交 / 10=已完成 / 20=失败 / 30=进行中） + `images` 数组 |
| ⚠️ 官方注意 | **生成的图片地址后续可能会失效，建议将结果保存在自己的 CDN 上** |

```

不可重试    => 810012 余额不足 · 324019 无权益 · 其余全部             （钱 / 根因）
"遇到错误就重试"是坑：先分清是哪一类；且退避要有**次数上限**。
```
