## 一、判据（收口标准）

**主判据（《Codex同化方案》§4.2 原文）**：**在 L0 的任何像素上，都找不到 `Codex` 这个词。**

**为什么这条判据不够用**：`_last_error` 会把**上游异常原文**直接渲染进 `#kernel-state`（见 §五），
所以「源码里没有 Codex」不等于「像素上没有 Codex」——**运行时**也能把它送上去。
本方案据此把判据补成三条（第一条是原文，后两条是本轮**建议**，待风哥拍）：

1. **品牌零残留**：用户可见文案里没有 `Codex` / `codex`；
2. **术语零外露**：同一像素上不出现 `App Server` / `app-server` / `Sandbox` / `workspace-write` / `LLM`；
3. **异常不裸奔**：异常文本可以进像素（保留可诊断性），但**必须过一遍术语表**，不许原样直出。

**不动的东西（红线）**：内部标识符与协议字段——
`id="chip-codex"` · `updateCodexStatus()` · `state.codex` · `state.codex_ready` · `event.codex` ·
`codex_path` · `--no-codex` · `raise CodexAppServerError` · 能力名 `codex_status` / `codex_tools` /
`codex_thread_new` / `codex_turn_send` / `codex_interrupt`。
**动了会牵连路由、审计与 `selfscan` 的「能力注册 ↔ 路由分发」原子单元**（《Codex同化方案》§4.4）。

## 十、红线
