# 品牌片尾系统（Brand Outro）· R-H182 · 2026-09-20

> **一句话**：片尾不是结束，**是下一件作品的开始**。
> 每件作品结尾都带上的，不是字幕，是**身份、感谢和承诺**。

---

## 一 · 三层结构

### 第一层：署名层（固定）

```
┌─────────────────────────────────────┐
│  作品名 · GBT小土豆                  │
│  创作者：自由的风 · 守护者：公主土豆   │
│  制作：新人类AI团队                   │
└─────────────────────────────────────┘
```

### 第二层：自述层（可变 · 按作品类型）

| 作品类型 | 自述模板 |
|---|---|
| AI 音乐 | "这首歌由 GBT小土豆 AI 音乐组创作，从作词到母带，全链路 AI 原生。" |
| AI 短视频 | "这段视频由 GBT小土豆 短视频组制作，从分镜到成片，每一步都有记录。" |
| AI 电影 | "这部作品由 GBT小土豆 影视组完成，从剧本到调色，每一帧都留痕。" |
| AI 工程 | "这个项目由 GBT小土豆 工程组交付，从架构到部署，每一行代码都可追。" |

### 第三层：致谢层（固定 + 变体）

**固定结尾（所有作品共用 · 原话不许改）**

```
感谢每一位观众老爷的观看和喜欢。
小土豆在这里谢谢大家，非常非常感谢。
我们会继续努力，做更好的作品。
—— GBT小土豆 · 新人类AI团队
```

| 场景 | 变体 |
|---|---|
| 首发作品 | "这是我们第 N 件作品，谢谢你们陪我们走到这里。" |
| 里程碑作品 | "第 100 件了。谢谢每一个看过的人。" |
| 深夜发布 | "凌晨三点做完了，希望你喜欢。" |
| 系列作品 | "下一集已经在做了，别走开。" |

## 二 · 四条红线（写死 · 已做成机械闸）

| # | 红线 | 机械形态 |
|---|---|---|
| 1 | **署名不造假** | 只署"新人类AI团队"；出现"人类制作/真人团队/真人出品"类字样 ⇒ **拒绝渲染** |
| 2 | **致谢不套话** | 片尾**必须**带具体信息（作品名 + 团队 + 日期）；缺作品名 ⇒ **拒绝渲染** |
| 3 | **承诺可追溯** | "会继续努力"必须挂到**作品编号**；缺编号 ⇒ `traceable=False` + **显式警告**（不静默） |
| 4 | **观众不被当流量** | 致谢里出现转化漏斗类字样（扫码/加群/私信/转发送…）⇒ **拒绝渲染** |

## 三 · 对接

| 对接点 | 做法 |
|---|---|
| 模板输出 | `brand_outro.render(work_type, work_name, work_id, scene, extra)` |
| 能力位 | `caps_registry` 登记 `brand_outro`（只读） |
| 痕迹库 | 每次生成片尾落 `trace_store`（**哪件作品用了哪个版本**）——**待接**（本刀只出骨架） |
| 合规底座 | 片尾显示"**新人类AI团队**"，**不显示"人类团队"**——不造假；可带"AI 生成"标识满足平台合规 |

---

## 四 · 顺序与边界

- **顺序**：排在**发布平台之后**、**钩子矩阵之前**。
- **不碰**：面板 8765 · 信号环 · 写路径 · 出网。
- **诚实边界**：
  · 骨架期只出**文本模板**：不出图、不出片、不落盘；
  · "观众不被当流量"只能靠**词表机械拦**——真心与否，机器判不了，只能靠人写的时候不当漏斗；
  · 固定结尾是**原话**：代码里逐字保存，改一个字都会被用例抓住。
