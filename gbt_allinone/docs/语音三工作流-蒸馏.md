## 一、先把上游的边界量清楚（这一步决定能蒸什么）

上游 README 与 `docs/speech-platform.md` 现读（2026-10-19）：

| 它有什么 | 真身 |
|---|---|
| 语音克隆 / 声音设计 / 视频配音 / 听写 / 转写 / 有声书 · 646 语言 | **Electron 应用本体**（它自己管模型与引擎） |
| Local speech platform | **只有 ASR**：`POST /v1/audio/transcriptions`（OpenAI 兼容）· `WS /v1/audio/transcriptions/stream` · `MCP /mcp/` 与 stdio `backend.mcp_shim` |
| 发现文档 | `GET :3900/.well-known/voicestudio-speech`（`voicestudio.speech.v1`，相对 URL） |

🔴 **结论（这一条最值钱）**：它的本地 API **只给「听」，不给「说」** —— 文档里**没有任何 TTS 端点**。
所以"接上它就有 ElevenLabs 同款合成"是错的读法：合成/克隆/设计都在应用里，本地 API 只做转写与 MCP。

⇒ 我们蒸馏的是**两件真东西**：
1. **接口面**（怎么连、怎么转写、怎么走 MCP）—— 已在本能力位，只读；
2. **它没做但我们三工作流缺的那一层**：角色音色台账 + 时间轴 + 时长预算 + 字幕（见第二节）。

## 二、六大能力 × 三大工作流（AI 短剧 / AI 电影 / AI 音乐）

三工作流的步骤是写死的（`media_pipeline.KINDS`）：
`short_video: script→storyboard→assets→edit→export` · `film: concept→script→shots→sound→edit→export` · `music: lyrics→arrangement→audio→master→export`。

| VoiceStudio 的能力 | 落到哪一步 | 我们怎么用（op） | 本机现在能不能跑 |
|---|---|---|---|
| **转写 / 听写** | 短剧 edit（字幕）· 电影 sound（旁白稿核对）· 音乐 lyrics（歌词↔音频对齐） | `transcribe`（要上游后端）· `align`+`subtitle`（**不要后端**） | `align`/`subtitle` **能跑**；`transcribe` 要后端在线 |
| **视频配音** | 短剧 assets · 电影 sound | 三件套：`cast`（谁的声音）→ `fit`（每句几秒）→ `align`（实际时间轴）+ `subtitle` | 编排**能跑**；真出声缺引擎 |
| **语音克隆** | 短剧多角色 · 电影主角 | `cast` 记账（留 voice 指纹）；克隆本体需上游应用 | **不能**（缺引擎 + 声纹需授权） |
| **声音设计** | 音乐人声 · 短剧配角 | `cast` 记账；设计本体需上游应用 | **不能**（缺引擎） |
| **有声书 / 长旁白** | 电影 sound | `fit` 按分镜时长分句 + `align` 量停顿 | 分句**能跑**；合成缺引擎 |
| **646 语言** | 电影/短剧出海 | 上游应用能力，Local API 不暴露 | **不能**（要走应用本体） |

**一句话**：上游把"说"锁在应用里，我们就把"说"周围那圈**自动化骨架**做成本仓的原生能力 ——
音色账、时间轴、预算、字幕。这四件是引擎无关的，换任何 TTS 引擎都直接复用。

## 三、新增的 5 个 op（真跑读数，2026-10-19）

| op | 做什么 | 真读数 |
|---|---|---|
| `cast` | 角色↔音色台账（`state/voice-cast.json`），三工作流共用 | set 两条 → list `n=2`（女主 / 旁白） |
| `align` | 音频节奏测绘：ffmpeg→20ms 帧能量→门限切段 | `voice-greet-zh-tw.mp3` → `n_segments=5` · total **9.552s** · speech **6.2s** · ratio **0.649** |
| `fit` | 台词→时长预算（CJK 字=1 / 西文词=0.5） | 4 行 / 56 字 / 目标 24s → 建议语速 **2.33 字/秒**，每行 5.78/7.56/5.56/5.11s |
| `subtitle` | 段+行→SRT，**行数≠段数就拒** | 6 行 vs 5 段 → `count_mismatch` **拒**；5 行 → 出 471 B SRT（真时间轴，见 `outputs/dh-probe/greet.srt`） |
| `brief` | 三工作流各自的语音配方 | 短剧/电影/音乐 各 `ok=true`，能给 4/4/2 项、缺 2/2/2 项 |

判据（可机检，全部 fail-closed）：
- `align` 门限写死：噪声底=帧能量 20 分位 · 说话门= max(噪声+12dB, −45dBFS) · 间隔 <0.22s 合并 · 长度 <0.18s 丢弃；
  **切不出就返回 0 段**，不退化成"全是语音"。
- `subtitle`：行数≠段数 ⇒ 拒；落盘只许 `projects/`·`outputs/`·`.scratch/`，其余拒。
- `cast`：写面自收窄在 `state/`；`voice` 字段必填（空着等于没登记）。
- 未知 op ⇒ `unknown_op` + 可用 op 列表（不猜）。

## 四、红线

1. **声纹 = 生物特征**：克隆任何人的声音必须主人授权（`privacy_read`），缺授权就拒，不绕；
2. **不出网**：默认只许回环（127.0.0.1/localhost/::1），远端要显式 `GBT_VOICESTUDIO_ALLOW_REMOTE=1`；
   拒重定向；密钥只回掩码；
3. **不下模型**：模型权重与许可留在上游；
4. **AGPL-3.0 分发边界**：自己用没事；**把上游打进对外分发的产物会传染 AGPL** ⇒ 我们只蒸馏接口，
   不分发它的代码；
5. **不编时间轴 / 不编台词**：`align` 切不出就报 0 段，`subtitle` 对不上就拒。

## 五、缺什么（下一步给主人的三选一）

| 缺口 | 影响 | 可选路 |
|---|---|---|
| 本机无 TTS/克隆引擎（Local API 只有 ASR） | 短剧/电影「真出声 + 音色一致」跑不起来 | ① 装上游 Electron（Windows 一键，约 5GB，AGPL）② 装 CPU 友好的本地 TTS（Kokoro/Piper，无克隆）③ 继续走 `hf_voice` 云端（要出网） |
| 录音端点 0 | 听写/采集类不可用（设备状态，不是没麦克风） | 主人启用输入设备 |
| 多角色一致性未验 | 只能记账，验不了 | 等引擎到位后用 `cast` + `align` 验 |

## 七、端到端闭环（2026-10-19 · AI 短剧样片「雨停之前」）

这一节是**真跑出来的**，不是设计稿。链路：台词 → 配音 → 时间轴 → 字幕 → 数字人成片。

```
cap voice_studio {"op":"cast","action":"set","who":"女主","voice":"edge:zh-TW-HsiaoChenNeural"}
cap voice_studio {"op":"say","who":"女主","lines":[...],"concat":"outputs/voice-studio/short-video/dialogue.wav"}
cap voice_studio {"op":"timeline","paths":[line00..03],"lines":[...],"wrap":13,"out":"...dialogue.srt"}
py tools/codex-scripts/dh2d-video.py --audio outputs/voice-studio/short-video/dialogue.wav --out outputs/voice-studio/short-video
ffmpeg ... -vf "subtitles=dialogue.srt" ... short-video-cc.mp4
```

真读数：

| 环节 | 读数 |
|---|---|
| `say`（4 句台词） | 4 个 audio：3.792 / 4.104 / 2.976 / 3.936 s（ffprobe 回读，不是合成器自报）；每句带 sha16 |
| 拼接 | `dialogue.wav` 14.808 s，16k 单声道 |
| `align`（对照用） | 6 段（"雨停之前，我一定要走到那栋楼"被逗号切成两段）⇒ 说明**生成的对白不该用 align 找边界** |
| `timeline`（正解） | 4 句边界 **精确**：0→3.792 / 3.792→7.896 / 7.896→10.872 / 10.872→14.808 |
| 字幕 | `dialogue.srt`，`wrap=13` 在标点后折行（"雨停之前，/ 我一定要走到那栋楼。"） |
| 成片 | `outputs/voice-studio/short-video/short-video-cc.mp4` · 720×1500 · 30fps · **14.80 s** · 371,374 B · h264+aac · 已烧字幕 + 钢印元数据 |
| 口型 | 嘴由**这句真配音的包络**驱动（不是随机动），数字人 2.5D 件出 444 帧 |

**两条口径收获（写进这里免得下次再踩）**
1. `align` 与 `timeline` 不是重复：**自己生成的对白用 timeline（边界精确），别人给的素材才用 align（能量切段猜）**。
2. 字幕折行必须自己做（`wrap`），交给 libass 自动折会在字中间断（"我一 / 定要走到…"）。

**这条链现在唯一的内存级依赖**：`edge-tts` 是**云端**合成（文字发到微软）。要"文字不出本机"就换
`engine=sapi`（本机 Windows SAPI，音色少）或装本地引擎（Kokoro/Piper）。换引擎**不动上下游**：
`cast` 里记的是音色标识，`say` 只认 engine+voice 两个字段。
