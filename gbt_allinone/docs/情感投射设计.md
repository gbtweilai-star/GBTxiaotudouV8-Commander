# 情感投射系统（Emotion Projection）· R-H183 · 2026-09-20

> **一句话**：作品最大的价值，不是"好听"，是 **"听了之后觉得那是在说自己"**。

---

## 一 · 核心：不是情绪标签，是**情绪叙事**

| 旧模式（标签） | 新模式（**羁绊**） |
|---|---|
| 伤感 = 慢歌 + 小调 | 伤感 = **有一段来龙去脉**，听的时候能代入自己的故事 |
| 快乐 = 快节奏 + 大调 | 快乐 = **有一个值得庆祝的瞬间**，让人想起自己的高光时刻 |
| 愤怒 = 鼓点 + 高音 | 愤怒 = **有一个不公的起因**，让人共情那份不甘 |

> **"羁绊"的核心是：让听众在作品里找到自己的影子。**

---

## 二 · 三层情感投射模型

### 第一层：情感叙事层（**生成前** · 四个问题）

| 问题 | 举例（伤感歌曲） |
|---|---|
| **谁**在伤感？ | 一个刚分手的人 |
| **为什么**伤感？ | 不是因为分手本身，是因为"明明还爱着，却再也回不去了" |
| **听众代入什么**？ | 每个人心里那个"如果当时…"的瞬间 |
| **留白在哪**？ | 副歌之后那几秒静默——让人自己填补 |

🔴 这四个问题的答案**必须写进生成提示词**——不是标签，是叙事。

### 第二层：情感投射层（**生成中** · 五元素）

| 元素 | 投射方式（**细节动作**，不是情绪标签） |
|---|---|
| 旋律 | 不是"悲伤的旋律"，是"在某个瞬间突然上扬又落下的旋律" |
| 歌词 | 不是"我好难过"，是"我把你送的杯子收进了柜子最深处" |
| 编曲 | 不是"钢琴+弦乐"，是"副歌前只剩钢琴，副歌后弦乐才涌进来" |
| 人声 | 不是"悲伤的唱腔"，是"第二段主歌比第一段多了半口气的颤抖" |
| 留白 | 不是在结尾，是**在最该说话的时候不说话** |

### 第三层：情感校验层（**生成后** · 四项）

| 校验项 | 判据 |
|---|---|
| **叙事完整** | 有没有"触发事件 → 情绪反应 → 共鸣点 → 留白"四段 |
| **情绪连贯** | 有没有情绪断层（喜到哀之间没有过渡） |
| **代入钩子** | 有没有一个让听众能说"这就是我"的瞬间 |
| **不套模板** | 不是"通用伤感"，是"**这一件作品的**伤感" |

🔴 **校验不过 ⇒ 打回重做，不进入发布队列。**

## 三 · 四条红线（写死 · 已做成机械闸）

| # | 红线 | 机械形态 |
|---|---|---|
| 1 | **不演情绪，真投入** | 四个问题缺任一 ⇒ 拒绝；只给标签 ⇒ 拒绝 |
| 2 | **不套模板** | 投射层五元素必须是"细节句"；出现情绪标签词（我好难过 / 悲伤的旋律 / 钢琴+弦乐）⇒ 拒绝 |
| 3 | **不操纵观众** | 出现"赚眼泪 / 带节奏 / 贩卖焦虑 / 煽动"类字眼 ⇒ 拒绝 |
| 4 | **机器能判的归机器，人才能判的归人** | 前三项机器判；**"是否身临其境"只有人能判** —— 机器设 True 会被判违规，未判则 `pending_human`（**不通过**） |

## 五 · 顺序、边界与**诚实边界**

- **顺序**：排在**品牌片尾之后**、**钩子矩阵之前**。
- **不碰**：面板 8765 · 信号环 · 写路径 · 出网。
- **诚实边界（写进图纸）**：

> 机器能保证"**叙事结构完整、情绪连贯、不套模板**"，
> 但"**是否真的让人身临其境**"，**只有人听了才知道**。
> **这条不假装能自动化** —— 所以校验层的第四项被强制标成"人判"，
> 机器一旦替人下了这个结论，就判违规。
