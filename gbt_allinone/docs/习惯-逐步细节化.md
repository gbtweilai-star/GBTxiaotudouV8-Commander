# 习惯 · 逐步细节化（Stepwise Detail Habit）

> 主人令（2026-10-09，逐字）：「给她设计一个习惯，做事细节化的习惯，每一步都要细节化。」
>
> 本仓旧训：**口号不会自己红** ⇒ 习惯必须配一道机器判据，否则它只是文档里的一句话。

## 一、习惯是什么

**每一步的产出，都必须答满五问；缺一问就算没做完。**

| 问 | 答什么 | 反例（等于没细节） |
|---|---|---|
| **输入** | 这一步吃的是什么（路径 / 上游件 / 抽屉位置） | 「拿了些数据」 |
| **动作** | 谁做的、用什么引擎或参数（可复现） | 「处理了一下」 |
| **明细** | **逐项**读数（≥1 条，逐镜/逐维/逐字段/逐标签） | 「共 8 镜」「质量良好」 |
| **判据** | 过 / 不过 + **判据出处** | 「应该没问题」 |
| **接点** | 交给下一步什么（路径或字段名） | 不说，让下一步自己猜 |

🔴 硬要求：**「明细」必须是列表**。给一个合计数字 = 没有细节——
本仓已有同族教训：*「报一个总数不算读数」*。

## 二、判据（会红的那个）

**件**：`tools/codex-scripts/detail-check.py`

```
py -3.14 -X utf8 tools/codex-scripts/detail-check.py --selftest        # 正例绿 / 5 个负例红
py -3.14 -X utf8 tools/codex-scripts/detail-check.py <报告.json>        # 查真报告
```

- 退出码：`0` 全过 · `1` 有缺（逐条列「谁缺什么」）· `2` 用法/读不动。
- 五问可以**平铺**在步骤条目上，也可以收在 `详细` 块里（原生媒体链用后者）。
- 自检 6 例：正例 1（五问齐且逐项）+ 负例 5（缺接点 / 明细只报合计 / 明细为空 / 判据没说过不过 / 报告里没 steps）。
  负例全红才证明它真能咬——**不能只有正例**。

## 三、已经落在哪儿（不是纸面上的）

`media_run` 三方向链的每一步（含 `awaiting_input` 的红步与 `prepared` 的发布步）都会吐 `详细` 块：

```
"详细": {"输入": {...}, "动作": "ffmpeg.lavfi（逐镜渲染 + 钢印）",
          "明细": [{"镜": 1, "秒": 5.0, "景别": "特写", "运镜": "推近", "情绪": "好奇", "调色": [...]}, ...],
          "判据": {"过": true, "出处": "drama.parse_timed"}, "接点": "projects/.../03assets.mp4"}
```

实测（`醒来-ep01`，6 步）：`script 4 条 · storyboard 12 条 · assets 4 条 · edit 4 条 · export 9 条 · publish 4 条`，
`detail-check` → `ok=true rc=0`。

## 四、为什么这条习惯值得长牙

- **细节是唯一能被人复核的东西**。「做了、还行」无法复核；「第 3 镜 5.0 秒、中景·横移·压抑、调色 #140A1C/#3A1030」可以。
- **合计会骗人，逐项不会**。8 镜全绿也可能第 5 镜是黑帧——只要你不逐镜报，它就一直藏着。
  实测：调色/QC 接进链之后立刻照出 `black=1 freeze=3`——那是合计视角永远看不见的。
- **红步也要答**。没拿到输入的步，明细就是「缺哪些字段」——这比一句「待输入」有用得多。

## 五、与其它习惯的关系

| 习惯 | 件 | 管什么 |
|---|---|---|
| 卡点三查与能力自知 | `tools/codex-scripts/blocker-research-check.py` | 说「做不到」之前必须查三次并留痕 |
| 新增即清旧 | `tools/codex-scripts/supersede-check.py` | 造新的同时把旧的送回收站 |
| **逐步细节化**（本件） | `tools/codex-scripts/detail-check.py` | 每一步都要答满五问，明细必须逐项 |

## 六、怎么用它

1. 任何多步任务，产出报告时**每步**带上 `详细` 块（平铺五问也可以）。
2. 交活前跑一次 `detail-check.py <报告>`；红了就补，不许把红的报告交出去。
3. 新增能力/工序时，**同时**想清楚这一步的五问怎么答——答不出来说明这一步还没设计完。
