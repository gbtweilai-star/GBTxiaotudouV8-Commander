# 短剧专业化规程（把已有的专业件拧成一条流水线）

> 开发者：自由的风 · GBT小土豆V8 · 本署名不可删除、不可篡改归属
>
> 主人令（2026-10-13）：「**短剧专业化啊**」+ 早先「剪辑一定要拼接好……必须以专业导演职业来做」。
> 本文**不新造零件**：下面每一步都点名**现读到的能力位**（`omni.py caliber` 现算），
> 缺的写进「缺口栏」，不许拿"我大概能做"糊过去。

---

## 0. 一句话口径

**专业化 = 三件事**：① 镜头语言有**表**（不是感觉）② 每一步有**机器判据**（不是"我觉得好"）
③ 每一步落在**已注册的能力位**上（不是临时脚本）。

---

## 1. 工序链（七步，每步点名能力位）

| 步 | 干什么 | 现读到的位 | 判据（机检） |
|---|---|---|---|
| 1 | **剧本 → 镜头表**：景别·运镜·时长·情绪·角色位置·描述 | `drama` | 字段齐全度 + Σ镜长 ≈ 目标时长（±5%） |
| 2 | **运镜语法展开**：把「推/摇/跟」翻成可执行拍子表（10 种动作语法 × 4 机位角） | `actioncam` | 每镜有 move 类型 + 起止值 + 缓动；不得出现空运镜 |
| 3 | **出图/出片**：每镜首帧 + 运动 | `filmkit`（manifest 唯一真相）· `comfy_native` / `tentacle_comfy_bridge` | 每镜真落件（字节+sha）；缺件即红 |
| 4 | **剪辑**：轨道→片段→目标/源区间→变速/音量/转场/文本 | `edit_pipeline` | **切点与拍差 ≤0.15s**、音画同长（≤0.2s）、字幕条数=句数 |
| 5 | **调色**：全片同一条曲线 | `look_grade` | 每镜中间帧 RGB 均值与全片均值偏差 ≤8/255 |
| 6 | **混音母带**：对白/BGM/音效三轨 + 闪避 | `audio_mix` | 人声 > BGM ≥8dB（量**闪避后**床电平） |
| 7 | **钢印 + 许可 + 发布准备** | `media_stamp` · `media_license` · `media_publish` | 钢印**回读校验**过；每件素材有许可登记；发布**永远 blocked**，等主人的门 |

> 编排器：`media_run`（一次调用走完整链，每步落真件 + 同批登记许可）。

## 2. 导演口径（专业判据，机器能验的部分）

§1 表里是"每步自己的判据"；下面这组是**跨镜的导演判据**，也是"专业"和"业余"真正分界的地方：

| # | 判据 | 为什么 |
|---|---|---|
| D1 | **景别不许连续 ≥3 镜相同** | 连续同景别＝呆板；专业片子靠景别递进推情绪 |
| D2 | **景别要成组递进**（远→全→中→近→特，或反向） | 观众靠景别变化读"近了/远了" |
| D3 | **特写占比 15%–35%** | 太少没情绪、太多没信息 |
| D4 | **同场内不许跳轴**（`axis_side` 一致） | 180° 轴线规则，跳轴观众会瞬间迷失方向 |
| D5 | **`淡黑` 只允许出现在场景边界** | 场景内淡黑＝断裂感 |
| D6 | **切点落在拍上**（≤0.15s） | 观众用耳朵感受节奏 |
| D7 | **每镜必须有"主体在做什么"** | 没有动作的镜头是废镜 |
| D8 | **首尾呼应**：开场最后一镜与结尾第一镜要有呼应关系 | 短剧 60 秒也要有闭环 |

🔴 **D1–D8 是我定的口径，不是行业法律** —— 每条都能改，但**改之前必须说清为什么**，
而且要**保持可机检**（"有节奏感""有电影感"这种词不许当判据）。

## 3. 分镜表 schema（`drama` 的产出，短剧版）

```json
{
  "title": "…", "logline": "一句话故事", "genre": "…", "total_sec": 60,
  "scenes": [{"scene_no":1,"location":"…","time_of_day":"…","dramatic_purpose":"…"}],
  "shots": [
    {"shot_no":1,"scene_no":1,"sec":3.0,
     "shot_size":"远景|全景|中景|近景|特写|大特写",
     "camera_move":"固定|推|拉|摇|移|跟|升降|手持",
     "angle":"平视|仰拍|俯拍|荷兰角",
     "subject":"谁在做什么",
     "dialogue":"台词（可空）",
     "sfx":"音效",
     "transition_out":"硬切|叠化|淡黑",
     "axis_side":"A|B"}
  ]
}
```

## 4. 缺口栏（如实）

1. **"模型自己摇镜头"还没有**：SVD 没有相机参数，现在的运镜都是**后期 zoompan 加的**
   （已实测：SVD 片段背景区 PSNR 11.9dB ≈ 整帧 11.2dB ⇒ 它连背景一起重画，不是镜头动）。
   要模型级运镜得换带相机控制的模型（CameraCtrl / MotionCtrl 一类）。
2. **跨镜一致性（同一个人/同一件衣服）** 目前只能靠固定 seed + 同一张参考图，没有身份锁定。
3. **D1–D8 的机检器还没写**（这一版先落口径；判据件随 `drama` 的短剧档一起补）。

---

## 5. 下一步（按序）

1. 用**我们自己的模型**按 §3 的 schema 出一张短剧分镜表（CPU 可跑，不占 GPU）⇒ 过 D1–D8。
2. 把 D1–D8 写成判据件（跟 `drama` 的短剧档同批）；`media_run` 的 short_video 链挂上这组判据。
3. 出 30–60 秒短剧样片，按 §1 七步走完，**每一步都留读数**。
