## 四、吸附字段形状缺陷 · 定性结论（已拿到，待拍）

**结论：错在调用方 `main.cjs`；`layout.cjs` 契约自洽。**

契约证据（`layout.cjs` 自带，非推测）：

| 位置 | 内容 |
| --- | --- |
| `layout.cjs:4-5` | 头注明写「主进程 `main.cjs` **只是调用方**」 |
| `layout.cjs:123` | `module.exports` 同时导出 `toBrowserBounds`（内部→Electron）与 `fromBrowserBounds`（Electron→内部），**转换由调用方负责** |
| `layout.cjs:22-33` | `normalize()` 接受外部形状并转内部形状 |
| `layout.cjs:97/106/107` | `snapBounds` 按契约**只读 `o.w / o.h`** |

根因链 `main.cjs:363-370`：`:365`（others）与 `:366`（自身）都直接喂 `getBounds()`；
`:368` 只比较 `x/y` → 尺寸错**静默放行**（《静默失效律》形态）。

**三个症状（离线实测 `.scratch/_r27_snap_proof.cjs`）**

| 症状 | 现状（直接喂 getBounds） | 转换后（正确） |
| --- | --- | --- |
| A 吸其他窗口右边缘失效 | 停在 1004，**不吸** | 吸到 1000 ✓ |
| B **尺寸被默认值改写**（比首报更严重） | `setBounds` 收到 `1120×720` → 把真实 400×300 改掉 | `400×300` ✓ |
| C 吸屏幕右/下边缘失效 | 1516 不吸（`b.w` 被默认成 1120 → 目标算成 800） | 吸到 1520 ✓ |

**修复方案（草案 · 待风哥拍）**

1. 只改 `holo_pet_w3/shell/main.cjs:363-370`：两处 `getBounds()` 都经 `layout.fromBrowserBounds(...)`
   转成内部形状后再传；`snapBounds` 出参再经 `toBrowserBounds` 回 Electron 形状。
2. **不改 `layout.cjs`**（不许加"兼容两种形状"）。
3. 契约测试 `test_snap_bounds_field_shape`：传 `{x,y,w,h}` → 断言吸附正确；传 `{x,y,width,height}` →
   断言**可判别地错**（不是静默算对）。落 `holo_pet_w3/tests/`（被测对象是 JS 纯函数，用 `node --test` 跑）。
4. **待拍点**：`main.cjs:368` 是否把 `x/y` 比较扩到 `width/height`（转换后尺寸恒等，扩了是防御，不扩是纯 bug 修）。

## 五、R27 实证：《结果通道律》四组对照

原始数据 `.scratch/_r27_trap_results.json`（跑法 `.scratch/_r27_trap_collect.py` + `_r27_trap_parent.cjs`）。
条件：造出「调用方不等它」＝ 读端立刻关闭；环境 Electron 43.0.0。

| 组 | 条件 | 写入方式 | 实测 |
| --- | --- | --- | --- |
| a | 断管 | 完全不写（阴性对照） | 无任何 error |
| b | 断管 | 纯 `try/catch`（现代码形态） | **出现未捕获异常 `uncaught_exception`**（错误框的成因）；**同步 catch 从没被触发** |
| c | **断管** | 先挂 `process.stdout.on("error")` | **显式捕获 `EPIPE: broken pipe, write`**，无未捕获异常 |
| c | **读端开着** | 同一写法（阳性对照） | 无任何 error |

**判别成立**：c 组两种条件唯一差别是读端开/关 → 一个出 EPIPE、一个不出 ⇒ 故障来自**断管**，
不是来自写法；b 与 c 唯一差别是兜底挂哪 → ⇒ **同步 `try/catch` 对异步 EPIPE 无效**。
**未复现「框」本身**（四组都注册了 `uncaughtException` 记录器）——不写成已复现。

## 十、环境事实与判例级踩坑（新线程直接照做）

- **解释器**：框架代码一律 `py -3.10`（`C:\Python310`）。默认 `python`（312）有 V5 遗留门禁
  `sitecustomize.py` → 全量红项从 9 涨到 34，极易误判成逻辑回归。
- **Electron**：`holo_pet/node_modules/electron/dist/electron.exe`（43.0.0）；
  起面板 `py -3.10 holo_pet/launch_panel.py --no-browser --no-codex`（端点 `127.0.0.1:8765`）。
- **GUI 程序的 stdout 不能当结果通道**：PowerShell 不等 GUI 程序（命令秒回），stdout 是断管；
  结果必须落文件；兜底要挂 `process.stdout.on("error")`（第十五章）。
- **沙箱内 `tasklist` / `Get-NetTCPConnection` / `Get-CimInstance` / `os.walk` 会静默失败** →
  判「活着」必须端点探测或提权查询（第十四章）。
- **`apply_patch` 的 update hunk 正文不能出现空行**（会被判非法 hunk）→ 大改动用 Python 脚本写文件。
- **工作区 `.ps1` 一律 UTF-8 带 BOM**；无 BOM 时 PowerShell 5.1 按 ANSI 读，中文路径静默变乱码。
- **`import` 维度内 `.py` 会落 `__pycache__`** → 探针须 `sys.dont_write_bytecode = True`。
- **写文件前先备份**到 `.scratch/`（`bak-<tag>-<stamp>`）。
- **入档三处** = 生命档案（`life_archive.record_event`，`dedupe_key` 必须唯一）+ `CHARTER.md` + `HEARTBEAT.md`；
  脚本要带唯一 marker 做幂等，批量落库后**复核条数**。
- **`mirror_status` 要用 `from gbt_allinone import mirror_space`**（根目录那份副本 `_BASE` 指错，会返回 0 文件）。
- **凭据脱敏**：只留前 4 位（`sk-a1b2****`）；DPAPI 落盘必须以真实用户身份执行（沙箱身份解不开）。
