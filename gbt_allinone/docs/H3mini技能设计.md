> 一句话：**官方仓库里它就已经是技能了** —— 我们只做三件事：**引用它 → 接进万能插 → 过门禁留痕**。

## 一 · 四原语（视频生成的四种入口）

| 原语 | 名字 | 输入 | 备注 |
|---|---|---|---|
| **T2VA** | 文生视频 | 文本提示词 | 最基础入口 |
| **I2VA** | 图生视频 | 一张参考图 + 提示词 | — |
| **FL2VA** | 首尾帧 | 首帧 + 尾帧（+ 提示词） | 两端锚定 ⇒ 中间由模型补 |
| **Ref2VA** | 参考生视频 | 参考图/参考物 + 提示词 | 保对象一致性 |

> 📌 **四原语只是"视频入口"**；模型**输入侧**还有一整行维度（含视频输入与音频输入）
> —— 见文末 **§九 · 维度表**（R-H251 补登记）。

## 二 · 三条带牙用例（都做成了机械闸）

| # | 判据 | 闸名 | 咬谁 |
|---|---|---|---|
| ① | **密钥不走明文** | `plaintext_key` | 返回值/参数里出现像密钥的长串 ⇒ 拒 |
| ② | **结果必须落盘** | `result_not_localized` | 落点全是 `http(s)://` / `oss://` ⇒ 拒（链接会失效）；空落点也拒 |
| ③ | **提示词必须走官方六段式** | `prose_prompt_rejected` / `prompt_sections_incomplete` | 散文式一整段 ⇒ 拒；分段不足 6 段或有空段 ⇒ 拒；**两个都没给也拒** |

🔴 **六段的「段名」我们没有**（官方技能包未装、出网受限）⇒ 判据只判「**有没有按段给**」，
**不编段名**。段名以官方 `h3-prompt-writing` 为准 —— 这与 LibTV 那条
「拿不到 schema 就不许凭记忆写键」是同一条纪律。

## 三 · 五条红线（写死）

| # | 红线 | 形态 |
|---|---|---|
| ① | 密钥只存 DPAPI | `MINIMAX_API_KEY` 走密钥池，不许明文落盘、不许进返回值 |
| ② | 结果必须落盘 | 生成结果必须下载到本地，不许只留远程链接 |
| ③ | 不绕官方入口 | 走官方技能 / 官方 API（白名单三选一），不许自己拼请求 |
| ④ | **硬件门槛先验** | 本地要 32GB+（峰值 31.7GB）；**验不到就不许说「能本地跑」** |
| ⑤ | 每次操作留痕 | 写 `trace_store`，`source_kind=h3mini` |

## 9.27 「8 秒片段耗时」**填值** + 新行「32GB 显存」+ 🔴 **全数字记账**（R-H286）

主人这轮给到：

```
32GB 显存                            ← 第五行行名（值仍截断）
```

### 🔴 本刀修的是**我上一刀自己留下的漏洞**

R-H282 我立了一把「独立数字」尺子（`_standalone_numbers`），为的是**躲开 `INT8` 里的 8**。
可这一格的数是：

```
0.3MP 约 2 分钟 / 1.0MP 约 13 分钟
└┬─┘                └┬─┘
 0.3、1.0 都**黏在单位 MP 上**

那把尺子的实测输出：_standalone_numbers(...) = [0.0, 2.0, 1.0, 13.0]
                                              ↑ 0.3 被截成 **0.0**

🔴 **不是「漏了」，是「错了一个数」** —— 假读数比漏读数更糟：
   漏了还能看出少东西，错了会被人当成真的用。
```

**修法不是再改那把尺子**（改了它又会把 INT8 的 8 放回来），而是**换成记账**：

```
④ 逐字里**每一个数都要有交代**：
   主数 + `extra_numbers` + `ignored_numbers`（**豁免必须写理由**）
   ⇒ 双向对账，漏一个就红 `hw_row_number_unaccounted`
⑤ `ignored_numbers` 非空 ⇒ `ignored_reason` 必须非空，否则红 `hw_row_ignore_without_reason`
```

于是两个用途都被满足：**INT8 的 8 被明确豁免（带理由）**，
**0.3 / 1.0 / 2 / 13 四个数一个不落、一个不错**。

### 单位记号扩到 MP / 分钟

`_UNIT_RE` 从 `GiB|GB|MiB|MB|KiB|kB` 扩到再加上 `MP|FPS|kHz|分钟|秒`
（去掉 `\b`，中文没有词边界；交替顺序保证 `GiB` 先于 `GB` 匹配）。
⇒ 这一格的单位记成 `("MP", "分钟", "MP", "分钟")`，**不许把 0.3MP 改写成 0.3 万像素**。

### 新增第 ⑨ 条：**每行都要写 `scope`（这行说的是哪个量）**

表里现在**已经有两行都在说「显存」**（第一行「峰值显存 31.7 GB」+ 第五行「32GB 显存」），
加上红线④「本地要 32GB+」就是**三处**。三处都在说显存、**说的却不是同一个量**：

```
峰值显存 31.7 GB   = **实测峰值**（跑满时吃到多少）
32GB 显存          = **预定规格 / 门槛**（要多少）
红线④ 32GB+        = 门槛判据
```

所以每行必须写 `scope`，否则红 `hw_row_scope_missing`。
第五行「32GB 显存」的 scope 写死了：**它与第一行不是同一个量；三者关系待主人定，不擅自合并**。
